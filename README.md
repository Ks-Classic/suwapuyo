# すわぷよ / ふわふわランド — YourTIME 2026-08-02

1つの Vite + React + TypeScript アプリに、YourTIME向けの利用者体験と会場運営機能が同居しています。

| 境界 | 実装 | 現行SSoT |
|---|---|---|
| 利用者向け（すわぷよ・村・イベント） | `src/app/`ほか | `docs/70_すわぷよ・ユアタイム統合仕様/` |
| 会場向け（お絵描き・運営・大画面） | `src/fuwafuwa-land/` | 同上。展示の旧設計は`docs/10_ふわふわランド/90_参考資料/` |

## はじめに読む

👉 **[`docs/00_全体案内/01_リポジトリ地図.md`](docs/00_全体案内/01_リポジトリ地図.md)** — 全体地図・正本の在り処・ディレクトリ規約。

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # tsc -b && vite build
npm run lint
```

ルーティングはpath分岐です。主な入口は`/`、`/fuwafuwa/draw`、`/display`、`/staff`です。旧デモとhashルートは廃止済みです。

## ドキュメント

`docs/` は番号で読む順序が固定されています。現行仕様は`70_すわぷよ・ユアタイム統合仕様/`、制作・運用ルールは`80_制作過程/`です。`10_ふわふわランド/90_参考資料/`と`_履歴/`は現行判断に使いません。詳細は地図を参照してください。

# 07 すわぷよ LINE公式アカウント必須LIFF仕様

> 決定日: 2026-07-10  
> 対象: YourTIME 2026 の来場前公開版「すわぷよ」  
> 状態: 実装前の正本。LINE Developers Console の実設定値・審査状況は実装着手時に別途確認する。

## 0. 決定

すわぷよは、**村の案内所 LINE公式アカウントを友だち追加した人だけが遊べるLIFFアプリ**として公開する。

- SNS・LP・紙面からは、公式アカウントの友だち追加QR/URLへ送る。
- 追加直後のあいさつメッセージから、すわぷよLIFFを開く。
- LIFF起動時にLINEログインと友だち状態を確認する。未追加またはブロック中は、友だち追加の確認画面を出し、追加確認後にのみゲームを開始する。
- Vercelはゲームの配信先として使う。利用者識別・進行・計測はSupabaseとサーバー側のLINEトークン検証で保存する。

これは「LINEが無断で友だち追加する」方式ではない。利用者の追加操作と同意は必要だが、**友だち追加済みであることをプレイ開始条件にする**。

## 1. 体験の位置づけ

```text
SNS / LP / 紹介投稿
  → 村の案内所 LINE公式アカウントを友だち追加
  → あいさつメッセージの「すわぷよで遊ぶ」
  → LIFFで本人確認・友だち状態確認
  → すわぷよ（体操・解放・出展者紹介）
  → 来場案内 / イベント後のゆるいLINE配信
```

会場用の「村の案内所LIFF」は、地図・案内・スタンプを登録なしでも使える方針を維持する。本仕様の必須化対象は、**来場前から公開するすわぷよだけ**である。

## 2. 初回導線

1. SNS等の投稿で「LINE公式アカウントを追加すると、すわぷよで遊べます」と伝える。
2. 公式アカウントの友だち追加QRまたはURLを開く。
3. あいさつメッセージで、世界観の歓迎と「すわぷよで遊ぶ」LIFF URLを提示する。
4. LIFFはLINEログイン済みなら初期化し、外部ブラウザではLINEログインへ遷移する。
5. `friendFlag` を確認する。未追加・ブロック中なら、理由を一文で説明して友だち追加を促す。
6. 追加後に再確認し、成功時だけゲームのタイトル画面へ進む。
7. 初回だけ、利用目的・プライバシー・任意アンケートを表示する。ゲーム開始自体に家族構成の回答は要求しない。

LIFFアプリは公式アカウントと同じLINE Loginチャネルに紐付け、`profile` scope とFull表示を使う。友だち追加の誘導は、チャネル設定のadd friend optionと、必要時の`liff.requestFriendship()`を併用する。実装時は`liff.getFriendship()`で再確認する。

## 3. あいさつメッセージ案

```text
ようこそ、すーすーわーわーの村へ！

親子で遊べる「すわぷよ」がオープンしました。
遊びながら、ときどきお口やからだを動かしてみよう。

[すわぷよで遊ぶ]
```

- メッセージ内の主CTAはLIFF URLを1つだけにする。
- 初回は説明を詰め込まず、「当日、村で会おう」を添える程度に留める。
- 配信は週1上限を基本とし、来場案内・新コンテンツ・イベント後の振り返りに限る。

## 4. 計測とデータ

### 4.1 取得する最小データ

| データ | 用途 | 取得時点 |
|---|---|---|
| 内部利用者ID | アプリ内の主キー | 初回認証 |
| 検証済みLINEユーザー識別子 | 同一利用者の判定 | 初回認証 |
| 初回流入元 (`source`) | SNS/QR/紹介別の効果測定 | 初回LIFF URL |
| 初回・最終プレイ日時 | 継続利用の把握 | 起動時 |
| ゲーム・体操・解放イベント | コンテンツ改善・出展者価値 | プレイ中 |
| 任意アンケート回答 | 企画改善・案内最適化 | 明示同意後 |
| 同意の版・日時 | 説明責任 | 同意時 |

LINEの表示名・プロフィール画像は保存しない。LINEユーザー識別子は画面やURL、ログへ出さない。クライアントが送る自己申告のIDは信頼せず、サーバー側で検証したLINE IDトークンから利用者を確定する。

### 4.2 最小データモデル

```text
game_users
  id, line_user_id, first_source, first_played_at, last_played_at,
  consent_version, consented_at

game_events
  id, user_id, event_name, occurred_at, properties

game_survey_answers
  id, user_id, question_key, answer, answered_at
```

`game_events.event_name` の初期候補は以下に固定する。プロパティへ個人情報は入れない。

```text
liff_opened
friendship_prompted
friendship_confirmed
game_started
game_played
taisou_started
taisou_completed
unlock_viewed
exhibitor_intro_viewed
cta_clicked
survey_opened
survey_answered
```

## 5. 作品QR連携（今回の実装外・将来追加）

「自分の絵を相棒として持ち帰る」価値は維持する。ただし今回のLINE必須LIFFの初期公開では、作品の引換QRを実装しない。

将来の追加時に既存の利用者・ゲーム進行を壊さないため、以下を予約する。

```text
artwork_claim_tokens
  id, artwork_id, token_hash, expires_at, claimed_by_user_id,
  claimed_at, revoked_at

game_buddies
  id, user_id, artwork_id, status, selected_at, created_at
```

- QRには作品IDやLINE識別子を直接載せず、短寿命・一度だけ使えるトークンを使う。
- `claimed_by_user_id` は本仕様の`game_users.id`を参照する。
- 作品が未連携でも、すわぷよは既存の村キャラクターで通常どおり遊べる。
- 作品画像は既存ふわふわランドの「顔写真を扱わず、作品だけを扱う」方針を継承する。

## 6. 実装境界

| 層 | 責務 |
|---|---|
| Vercel / React | LIFF UI、ゲーム、同意・アンケート、イベント送信 |
| LIFF SDK | ログイン状態、友だち状態の確認、追加画面の表示 |
| サーバー関数 | LINE IDトークン検証、内部セッション発行、イベント受信の認可 |
| Supabase | 利用者・進行・イベント・任意回答の保存 |
| LINE公式アカウント | 友だち追加、あいさつ、イベント前後の配信 |

フロントエンドだけでLINE IDを保存しない。`VITE_`付き環境変数には公開してよいLIFF IDだけを置き、チャネルシークレットや管理用トークンはサーバー側のシークレットとして扱う。すわぷよは`VITE_SUWAPUYO_LIFF_ID`、会場案内所は`VITE_LIFF_ID`を使い、異なるLIFFアプリのIDを共用しない。ローカル自動テストだけは`VITE_SUWAPUYO_LIFF_MODE=demo`で認証ゲートを無効化する。本番・previewでdemoを設定しない。

## 7. 段階実装

1. **LINE基盤**: 公式アカウント、Messaging APIチャネル、LIFF、あいさつ、リッチメニュー、流入元付きURLを設定する。
2. **認証ゲート**: LIFF初期化、ログイン、友だち状態確認、未追加時の追加導線、サーバー側トークン検証を実装する。
3. **計測基盤**: `game_users`と`game_events`を保存し、プレイ・体操・CTA・流入元を可視化する。
4. **任意アンケートと配信運用**: 回答は段階表示にし、配信頻度・配信内容を運用ルールで固定する。
5. **作品QR連携**: 上記の予約テーブルと引換画面を追加する。初期公開の認証・進行・計測は変更しない。

## 8. 受け入れ条件

- 公式アカウント未追加またはブロック中の利用者は、ゲーム本編を開始できない。
- 友だち追加後、同じLIFF画面で状態を再確認してゲームを開始できる。
- 外部ブラウザからの起動時もLINEログインを経由して利用者を確定できる。
- 初回流入元、初回プレイ、ゲーム開始、体操完了、CTAクリックを個人情報なしで記録できる。
- 任意アンケートをスキップしてもゲームを遊べる。
- 作品QR機能が未実装でも、既存キャラクターでゲーム体験が成立する。
- LINEユーザー識別子・トークン・管理用シークレットがブラウザログ、URL、Gitに出ない。

## 9. 既存仕様との関係

- `03_retention-loop-spec.md`の「LINE紐付けはおまけ」は、本仕様により更新する。すわぷよへの入口と利用者識別はLINE公式アカウントを必須とする。
- 同文書の「自分の絵に会える」価値は維持する。ただし初期公開ではQR引換を後続フェーズに置く。
- `40_yourtime-platform`の会場案内所の非強制登録原則は変更しない。

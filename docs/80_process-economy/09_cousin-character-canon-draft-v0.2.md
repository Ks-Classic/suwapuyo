## 0. 30秒で分かるキャラ案

やっ太郎は、画面の裏側にある`没案フォルダ`から勝手に孵った、サンゴ色のひらめきヤモリ。目に入った「おもしろそう」を、胸の`とりあえずボタン`で試作品へ変えられる。ただし急ぐほど、名前、権利、目的、額の模様など「大事な何か」が一つ抜ける。

自分の価値は、誰より早く完成品を出すことだと思っている。本当は、作者、仲間、利用者への敬意と、失敗しても戻れる正本があるからこそ、速さが力になると学んでいく。普段はぶっ飛んでいるが、子ども、作者、仲間の尊厳が傷つく瞬間だけ、誰より先に真顔になる。

`やっ太郎`は、いとこの`やす太郎`をもじった名前であり、本人の「やったろう！」「何でもやってやろう！」という行動原理そのもの。何でも無謀に実行するという意味ではなく、未知を前にした時に、まず安全な最小実験へ変えてみる姿勢を表す。

## 2. この案の意図的な「ぶっとび」

- 没案フォルダから孵った。
- 思いつきを物質化するが、急ぐほど重要条件が一つ抜ける。
- しっぽが疑問符、矢印、結び目になる。
- 成功すると3秒だけ踊り、すぐ完成物の裏を覗く。
- 夜はdraft画像へ戻り、更新があると勝手に孵る。
- 最高級の広告技術を、空箱や仮ボタンへ全投入する。

一方で、人間的な共感点は`消されたくない / 役に立ちたい / 自由でいたい / 仲間に任せてほしい`に限定する。家族構成、学校生活、恋愛、一般的な休日等を過剰に足し、人間の着ぐるみにしない。

## 3. 現時点で感じる可能性のある違和感

1. 没案由来の恐れが暗く見え、親子向けの明るさを下げる可能性。
2. AI・draft・folder比喩が、非IT層には伝わりにくい可能性。
3. 能力が便利すぎ、何でも生成できるキャラに見える可能性。
4. `やったろう`が無謀・無許可の実行と誤解されないよう、他者影響がある時の安全境界を物語で見せる必要がある。
5. ぶっとび演出が強く、すわぷよ・YourTIME・ツナやすの目的を食う可能性。

これらは削除理由でなく、初期投稿・台詞・pose・観客testで検証する仮説とする。

## 4. 次のCanon review

- 出自、能力、恐れ、misbeliefを一つずつ`残す / 変える / 削る`で判断。
- 公式やすとの圧力テスト10問を二人分書く。
- IT非専門、親子、出展者、デザイナーへ30秒説明し、自由回答を取る。
- 少なくとも18形式を試す投稿探索と、キャラ核の評価を混同しない。
- approval後、値をJSON化し、AI persona・脚本・Live2D・3Dへ同じversionで渡す。

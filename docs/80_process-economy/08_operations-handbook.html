1. まず、何のための運用か

目的は「AIで画像を作ること」ではなく、同じキャラが長く愛され、すわぷよ・YourTIME・ツナやすの価値へつながること。

利用者

すわぷよを知り、遊び、YourTIMEへ行くきっかけを作る。

キャラ

やっ太郎の行動・発見・成長と、公式やすの目的・設計・真面目さを対等なコンビとして積み上げる。

事業

企画、AI、UIUX、LINE、Web、キャラマーケの実証を相談へつなげる。

学び

完成品だけでなく、判断・失敗・修正を次の人が使える形で残す。

大原則：見た目は本気、構造も本気、オチだけ意外。ふざけても、権利・安全・事実はふざけない。

3. 1本を作る標準フロー

  1. 目的を1つ決める。認知、学び、すわぷよ体験、YourTIME来場、信頼、相談のどれか。
  2. 読者を1人に絞る。親子、出展者、AI開発者、デザイナーなど、主対象を1つにする。
  3. Briefを書く。hook、約束、形式、キャラ役割、方式、CTA、成功指標を埋める。
  4. 制作方式を選ぶ。下の方式選択表で、必要以上に生成しない。
  5. 素材と権利を確認する。入力画像、音源、振付、フォント、ロゴ、人物、モデルを台帳へ記録。
  6. 1回の変更は1つ。構図、表情、背景、衣装などを同時に変えない。
  7. 5レビューを通す。character、rights、safety、quality、factual。
  8. 媒体別に書き出す。無音masterを保管し、音源は各SNS内で付ける。
  9. 公開後に記録する。URL、日時、数値、コメント、誤解、次に変える1項目。

5. SNS投稿の作り方

初期はフォーマット探索

1枚広告、2枚対比、4コマ、自由枚数カルーセル、6秒loop、短尺寸劇、ダンス、制作画面、text、thread、長文、投票等を広く試す。次の要素は部品であり、7枚固定の順番ではない。

ガチ広告風

見た目は高品質に作る。架空brandまたは自分たちを題材にする。他社広告のcopy、logo、音源、sceneを複製しない。最後にいとこの本音や小さなズレを置く。

トレンド動画

流行投稿は素材ではなく観察対象。hook、尺、転換、視線、編集リズムをtrend grammarとして抽象化し、オリジナルmotion・台詞・背景で再構成する。

CTAの順番

見る覚える参加体験深掘り相談の順に関係を育てる。初見でいきなり営業しない。

6. 公開承認Gate

Character

額記号、牙、手足、尾、服、palette、線、公式やすとの差が守られている。

Rights

入力、モデル、音源、振付、人物、フォント、logo、媒体の許可が追える。

Safety

差別、医療断定、危険行為、子ども・個人情報、他者攻撃がない。

Quality

小サイズ、字幕、音、crop、動画flicker、手足・顔の破綻を確認。

Factual

日付、料金、成果、AIの役割、協力者、失敗を根拠以上に言っていない。

承認前は公開しない。ステータスはgenerated-draft → selected-draft → reviewed → approved → published。approved assetを上書きせず、新しいversionを作る。

初期は配分・枚数・尺を固定しない。最低18本、主要patternを同目的・同対象で各3回程度試し、結果・制作負荷・キャラ適合からwinner / challenger / wild cardを決める。

8. 事故が起きた時

  1. 公開variant、広告、予約投稿、再利用assetを止める。
  2. URL、asset ID、manifest、input、model、reviewerを特定する。
  3. 権利、品質、事実、安全のどのGateが破れたか分類する。
  4. 必要なら非公開・差替え・訂正。説明は人ではなく仕組みと事実を中心にする。
  5. 原因を修正し、Golden/Holdout regression後に再開する。

実在人物の無断置換、未許諾音源、子どもの個人情報、重大な権利通知は「様子見で投稿継続」しない。

10. 最初の実行手順

1. 07の初期12投稿から1本選ぶ
2. Briefに objective / audience / source_recipe / CTA を書く
3. いとこのapproved referenceだけを使う
4. 方式に応じたmanifestを作る
5. 5レビューを通す
6. Instagram / X / Threadsへ媒体別に投稿
7. 24時間後に数値と違和感を記録
8. 次の変更を1つだけ決める

最初のおすすめは「AIでキャラを1枚作るのは簡単。同じキャラを100回出すのは難しい。」というカルーセルです。今回の技術調査・権利承認・Character Masterそのものを、最初のprocess economyとして説明できます。

## 1. 目的（CR-0）

2026-08-02 YourTIME..8th で、来場家族が「遊びながら自然に出展者と出会い、集めて、持ち帰る」体験を成立させ、**出展者には当日で終わらない継続接点（＝レポート）** を返す。イベントを“点”から“線”にする器の当日パートを作る。

- **来場者（親子）**：マップで探す → ブースで出会う → スタンプを集める → すわぷよ隠しキャラ解放という回遊の動機。
- **出展者**：来場接点と「関与の深さ（寄った/説明/体験）」がデータで残り、レポートで返る。
- **運営（諏訪さん）**：継続発信の器（LINE案内所）が立ち、来年も回せる土台になる。

## 4. UX原則・デザイン方針

1. **絵本ワールド × ネイティブアプリchrome**：下地は小夏さんの絵本マップ（クリーム×ティール #0f766e・M PLUS Rounded・ふわっと影）。操作層は2026ネイティブ作法（bottom sheet・横スクロールchip・spring物理・ピンチズーム）。
2. **1+3ハイブリッド**：没入(絵が主役) ＋ 薄いナビ(検索/フィルタ/地図⇄リスト)。普段chromeは絵を邪魔しない。
3. **時計モチーフを主役に**：ブースマーカー＝腕時計(00)。**スタンプ獲得で文字盤が企業ロゴ/キャラに変わる**＝YourTIMEブランドの時計が今回の核演出。
4. **マップとスタンプ帳は別画面**：探す/集めるを分離。相互リンクのみ。
5. **医療広告セーフ**：ブース文面に断定・診断・予防効果表現を入れない（既存MAP-004方針継続）。
6. **やさしいモーション**：squash&stretch・confetti・WebAudio効果音（すわぷよ資産流用）・節目で達成感。

### 描画方式（確定）= SVGハイブリッド
- 背景＝絵本マップ。**当面は `public/content/yourtime-platform/map/map_sample.jpg`（配置済・1724×1012）を SVG `<image>` で1枚貼る**（配信URL `/content/yourtime-platform/map/map_sample.jpg`）。本番は小夏さんのSVG/高解像PNGに差し替え（同じ仕組みのまま）。
- ブース当たり判定＝SVG `<g id="booth-{id}">`/`<circle>` を `mapX/mapY`(%) で重ねる（画像と座標を分離。素材差替えで座標だけ調整）。
- 全体を pan/zoom コンテナ（`react-zoom-pan-pinch` 等）に格納。ベクター/画像どちらでも拡大OK・タップ判定native・状態で姿が変わる。
- ❌ DOM全再現（崩れる）・❌ ラスターimage-map（`<area>`＝ボケ・演出不可）は不採用。

### 操作モデル（確定）= Googleマップ型 自由pan/zoom ＋ ランドfly-to
- **基本＝Googleマップと同じ**：指ドラッグ＝全方向パン・ピンチ＝拡大縮小・ダブルタップ＝1段ズーム・慣性スクロール。誰でも知ってる操作＝学習ゼロ。
- **初期表示＝横幅フィット**（横長マップ全体が縦画面に収まる。上下余白は村の空/地面イラストで埋める）。`minZoom=fit` / `maxZoom≈3x`。
- **ランドchip（フード/キッズ/アダルト/デンタル）タップ → そのゾーンへ fly-to**（カメラが ~400ms ease で寄る）。各ゾーンは正方形寄りで縦画面に収まる＝横長問題を解決。スワイプ感もfly-toで回収。
- ❌ **横スライド(snap)は不採用**（自由探索を縛る。ゾーン移動はfly-toで代替）。

## 7. 型・データモデル

### 7.1 既存型の拡張（`boothMapData.ts`）

export interface BoothExhibitor {
  // 既存: id, boothNo, landId, name, category, summary, activity, logoUrl, mapX, mapY, ctaUrl

  stampAssetUrl?: string;         // 追加: スタンプ文字盤の企業ロゴ/キャラ画像

export type AgeBand = "preschool" | "elementary" | "teen" | "adult";

### 7.2 来場者・スタンプ（Supabase 新規 / RLS必須）
```ts
// visitors: LIFFのuserId基準（未認証LINEでもprofile.userId取得可）
interface Visitor {
  id: string;                       // uuid（デモは "demo-" prefix で印）
  line_user_id: string;             // LIFF profile（無い場合は端末ローカルID fallback）
  visitor_type?: VisitorType;       // 家族/子連れ/おひとり/その他
  children?: ChildInfo[];           // 家族構成（複数人・各 年齢帯＋性別）
  adults_count?: number;            // 大人の人数（任意）
  acquisition_source?: AcquisitionSource; // 来場きっかけ
  is_health_pro?: boolean;          // 医療・健康事業の関係者か（true=関係者/false=一般）
  interests?: string[];
  created_at: string;
}
interface ChildInfo {
  age_band: ChildAgeBand;           // 0..6 は単年、7-9/10-12/13+ は帯
  gender: "boy" | "girl" | "other";
}
type ChildAgeBand =
  | "0" | "1" | "2" | "3" | "4" | "5" | "6"
  | "7-9" | "10-12" | "13+";
type AcquisitionSource =
  | "instagram"   // SNS/Instagram
  | "friend"      // 知人・友人
  | "exhibitor"   // 出展者から
  | "official"    // YourTIME公式・主催から
  | "walk_in"     // 通りがかり
  | "other";
// stamps: 1 visitor × 1 booth = 1行（深さは更新）
interface Stamp {
  id: string;
  visitor_id: string;
  exhibitor_id: string;       // = BoothExhibitor.id
  depth: VisitDepth;          // 'visited' | 'explained' | 'experienced'
  created_at: string;
  updated_at: string;
}
type VisitorType = "family" | "with_kids" | "solo" | "other";
type VisitDepth = "visited" | "explained" | "experienced";
```
- **正本=Supabase**（Storage=画像/Postgres=データ）。オフライン耐性は IndexedDB キャッシュ（ふわふわランド踏襲）。
- ブース台帳（exhibitors）は当面 `boothMapData.ts` の静的データ正本でよい（将来 `exhibitors` テーブルへ移行＝FL-CMS18/19のRepository境界経由）。

## 9. 計測・不正対策・プライバシー

- **計測**: `track(enum+meta)` に追加 — `onboard_done` / `map_open` / `booth_card_open` / `stamp_get`(depth) / `reward_reach` / `unlock_hidden`。新イベント名は作らず enum 拡張（FL-CMS13踏襲）。
- **不正対策**: スタンプは現地QR前提（物理的来訪）。1ブース1回・深さは上書きのみ。気になればQRに回転トークン or スタッフ提示式（家族イベントなら軽量で可）。
- **プライバシー**: 顔写真なし。氏名は扱わない（来場者タイプ等の属性のみ）。同意は会場掲示で周知（個別フォーム持たない＝ふわふわランド方針踏襲）。`.env*` 非コミット・RLS厳守。

### 12.3 画面別 詳細（状態つき）

#### A. 友だち追加 → ようこそ
- 友だち追加URLのQR（受付QRのデモ版）→ あいさつ → 「はじめる」。
- すーすー登場アニメ（spring）。状態: 初期表示のみ。

#### B. 家族構成アンケート（★デモの主役・最強UIUX）
**目的**: 子ども3人でも **No ストレス・全部タップ・キーボードゼロ** で家族構成を取得。
**フロー**:
- **B-1 だれと来た？**: 大ボタン4枚 `[👨‍👩‍👧 家族] [👶 子ども連れ] [🧍 ひとり] [… その他]`。**タップ即・自動で次へ**。
- **B-2 お子さんは何人？**（家族/子連れ時のみ）: 大ボタン `[1][2][3][4+]`。タップで**人数分の子どもカードを生成**。
- **B-3 子どもカード（人数分・アコーディオン）**: 今の1枚だけ大きく開く。
  - 見出し「1人目」
  - **年齢**: 横スクロールchip `[0][1][2][3][4][5][6][7-9][10-12][13+]`（タップで選択・色付く）
  - **性別**: トグル `[♂ おとこのこ] [♀ おんなのこ] [— どちらでも]`
  - **年齢→性別を選ぶと、自動で畳まれ次の子へスクロール**。最後の子で「これでOK」活性。
- **B-4 大人の人数**（任意・軽く）: `[1][2][3+]`。スキップ可。
- **B-5 来場きっかけ**: chip `[📷 Instagram/SNS] [🧑‍🤝‍🧑 知人・友人] [🏥 出展者から] [📣 YourTIME公式] [🚶 通りがかり] [… その他]`。1タップで次へ。
- **B-6 お仕事は健康・医療系？**: 大ボタン2枚 `[はい（関係者）] [いいえ（一般）]`。1タップで完了。
**状態**: 未選択（次へ不活性）/ 選択中 / 完了。「あとで」スキップ常時可（B-5/B-6 も任意）。
**No ストレスのキモ（受け入れ条件）**:
1. **キーボード一切なし**・全タップ。
2. **1タップ＝1決定で自動前進**（年齢→性別→次の子）。手数最小。
3. **入力済みの子は小さく畳まれ、今の子だけ大きい**（アコーディオン＝3人でも迷子なし）。
4. **上部に家族プレビュー**：選ぶ度にアイコン/キャラが増える（👨👩→👦5才→👧2才…）＝取得実感＆楽しい。
5. 子追加は spring（ぽこっ）。
**データ**: `visitor.children:[{age_band,gender}]`, `adults_count?`, `visitor_type`（§7.2）。

#### C. チュートリアル（デモ1-2枚）
- 横スワイプ＋ドット。最後に「村に入る」→マップ。デモは1-2枚で十分。

#### D. マップ（JPG・Googleマップ型 pan/zoom ＋ ランドfly-to）
- 描画/操作は §4 準拠。**初期=横幅フィット**、ピンチ/ダブルタップ拡大、ランドchip→fly-to(~400ms)。
- マーカーは `map_sample.jpg` の時計(00)位置に合わせ **seed 3-4件だけ可視**（他はJPGの絵のまま装飾）。
- タップ→bottom sheet（ブースカード）。

#### E. QR体験（画像読取 or デモボタン）→ スタンプ画面
- **入口2系統**（どちらも同じ遷移）:
  1. **体験版QR画像をLINEで読む** → `?booth=demo-01` でLIFF起動。
  2. 画面の **「QRを読んだことにする（デモ）」ボタン** → 同じ画面へ。スキャン無しでも通る保険。
- スタンプ画面: ブースカード ＋ 3ボタン `[🚶寄っただけ][👂説明きいた][✋体験した]`。
- **スタンプ演出（軽い・合計~600ms）**:
  - 時計マーカーの文字盤が企業ロゴ/色丸に **ぽん!**（scale spring `0→1.15→1.0` ~350ms）
  - リング状の光が外へ expand（~300ms・フェード）
  - confetti **5-8粒**（控えめ）
  - SE＝すわぷよ既存音流用（refill/coin系の「ぴこん♪」）
  - カウンタ `n/総数` が +1 bounce
- 連打/再訪: 同ブースは1回（深さ更新のみ）。

#### F. スタンプ帳
- §5.4。デモは seed 3-4件のグリッド＋進捗バー＋「全部で隠しキャラ✨」。

#### G. 会場アナウンス（★その場で・ライブの目玉）
- **仕組み**: スタッフ画面 `/concierge/staff` に文言入力→送信→**Supabase `announcements` Realtime**→全LIFF端末の**上部に📢バナーがスライドダウン**（5-8秒で自動クローズ / タップで閉 / 軽SE）。ふわふわランドの `display_event` Realtime と同型。
- **デモ運用**: 木幡が裏（別タブ/別端末のスタッフ画面）から送信 → 諏訪さんの画面に**リアルタイムで出る** ＝「会場にその場でアナウンスできる」を実演。
- **fallback / 本番**: Realtime不可時は **LINE全体配信（broadcast）** で代替（未認証アカウントでも可・本番でも使える正規チャネル）。
- **データ**: `announcements { id, text, created_at, active }`。

### 12.4 1台 / オフライン前提
- 1オリジン path 配信。**Supabase未設定でもローカル(IndexedDB)** でアンケ/スタンプを保持し全工程が通る。
- 会場アナウンスのRealtimeだけは2タブ（スタッフ送信 / 来場者受信）で実演（Supabaseは使うが、デモ専用の最小テーブルでOK）。

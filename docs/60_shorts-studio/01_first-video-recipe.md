# 01 — 最初の1本を確実に作るレシピ（→ 量産テンプレの種）

> 最終更新: 2026-06-25
> 目的: すーすーわーわーの2キャラ会話・啓蒙ショートを、手で1本"確実に"作る方法を確定する。この1本がそのまま量産システムの型になる。
> 大原則: **生成しない（既存の絵を動かす＝image-preserving）**。可愛さは「微妙な動き＋タイミング」から出る。必ず `../20_business/medical-ad-content-policy.md` を通す。

## 5レイヤー構造
1. 背景（雰囲気背景PNG。※背景はキャラ一貫性が要らないので **fal.ai 等でAI生成してOK**。生成NGなのは"ブランドキャラ"だけ）
2. キャラ（立ち絵PNGを左右配置＋さりげない動き）
3. 音声（**第一候補=animalese「すーすーわーわー語」**＝キャラ別ピッチの可愛いブリップ音。VOICEVOXはナレーター回用に温存）
4. 字幕（台詞が可愛くポップ。※内容＝啓蒙メッセージは"字幕"が担う。声は喋らない＝医療広告事故を避けやすい）
5. **BGM（ほんわか・著作権フリー。声の下で小さく、喋る間は自動で音量を下げる＝ダッキング）**

## 声のスタイル：animalese（すーすーわーわー語）を第一に
- どうぶつの森風のブリップ音。**激軽（エンジン不要・自前生成）／可愛い／健康効果を喋らないのでコンプラ安全／キャラ別固定ピッチ＝ブランドの音**になる。
- ⚠️ **あつ森の実音源はコピーしない**（任天堂IP）。手法は一般的でOK。自前のブリップ（合成音 or 短い「ぽ/ぴ」録音）をキャラ別ピッチで生成する。
- 字幕の1モーラごとに1ブリップ、キャラごとにベースピッチを変える（わーわー=高め/もぐぴよ=低め 等）。
- VOICEVOXは将来のナレーション回でのみ採用（クレジット必須・実在声優学習音は不使用）。

## 忠実度ラダー（低い方から確実に）
| Lv | 動き | 追加素材 | 用途 |
|---|---|---|---|
| L1 バウンス・トーク | 全員ふわふわ揺れ＋喋る子だけ"ぴょこ"＋字幕ポップ | なし | **1本目** |
| L2 パクパク口パク | 喋る間 口を開/閉交互 | 各キャラ口2状態 | 仕上げ |
| L3 表情・まばたき | 表情差分・瞬き | 差分パーツ | 量産で余裕が出たら |

## ツールチェーン（OSS・量産に化ける）
- 背骨: **Revideo (MIT/TS)** — コードで配置/動き/音声/字幕 → FFmpegでmp4。台本＋素材差し替えで量産。
- 音声: **VOICEVOX**（無料・クレジット要、2話者）
- 字幕: **faster-whisper**（音声→1語ずつ字幕）
- BGM: **著作権フリー音源**（下記ガードレール）＋ FFmpeg でループ・フェード・**ダッキング**
- 補正: **FFmpeg**（結合・9:16）

## BGM調達ガードレール（著作権＝妥協不可）
- **市販曲・流行曲・TikTok音源は使わない**（商用×子ども×SNSで一発アウト）。
- 使うのは**商用OKの著作権フリー音源**。日本語で揃いやすい「ほんわか可愛い」系:
  - 甘茶の音楽工房 / 魔王魂 / DOVA-SYNDROME / PeriTune（各サイトの規約とクレジット条件を都度確認）
  - 海外: incompetech（CC-BY・要クレジット）
- AI生成音楽（Suno等）は**商用ライセンス条件が変わりやすい**ので、確定するまで第一候補にしない。
- 採用曲は**曲名・配布元・ライセンス・クレジット文**を本ファイルに記録してから使う。
- ミックス: BGMは声よりかなり小さく（声 -3〜0 / BGM -18〜-22 LUFS目安）、喋る瞬間は自動で下げる（FFmpeg `sidechaincompress` か、台詞区間だけ音量を落とす）。頭2秒フェードイン・終2秒フェードアウト。

## 手順（L1）
1. **素材を決める**: 背景1枚＋立ち絵2体（ghost/tooth/blob/tanukiから2）。透過PNG。立ち絵は高解像が望ましい（現状スプライトは仮置き）。
2. **台本を書く**（下のサンプル）。1行=1台詞=話者付き。コンプラ通す。
3. **音声生成（VOICEVOX）**: 各台詞をキャラごとの話者で書き出し → `line01.wav` …。
4. **字幕タイミング（whisper）**: 各wavを faster-whisper で単語タイムスタンプ化（or 台詞長で手動）。
5. **Revideoでシーン構築**:
   - 背景Img（全画面9:16）
   - 左=キャラA / 右=キャラB の立ち絵Img
   - 全員: 上下0.3秒ループ（bob）でふわふわ
   - 台詞ごと: 喋る子を scale 1.05 に"ぴょこ" + 字幕Txtポップ + その台詞のAudio再生 + 終わったら次へ
6. **レンダリング**: Revideo render → `out.mp4`。必要なら FFmpeg で9:16最終調整。
7. **チェック**: `medical-ad-content-policy.md` のチェックリストを通してから書き出し。

## サンプル台本（30秒・鼻すーすー呼吸・コンプラ準拠）
```
スースー: ねぇワーワー、お口ぽかーんって開いてない？
ワーワー: あっ…開いてた！
スースー: お鼻で、すーすーって息してみよ？
ワーワー: すーすー…なんだか気持ちいい！
スースー: 寝るときも、お口とじてすーすー、だよ
ワーワー: やってみる！すーすー、わーわー！
字幕CTA: お鼻でスースー、やってみてね
```
※ 「治る/予防できる/良くなる」は言わせない（言い換え集どおり）。キャラは医療行為の主体に見せない（あくまで遊びの案内役）。

## 量産への化け方（1本目が型になる）
- Revideoシーンを `script` 配列（話者・台詞・音声・字幕）駆動にする → **配列を差し替えるだけで新作**。
- 出展者紹介ショート（`../20_business/give-assets/A_intro-short-format.md`）も同じ型に流し込む。
- キャラ口調・OK表現は小夏さんと確定し、ここに追記して固定。

## 既知の前提・残課題
- 立ち絵は現状 `public/content/fuwafuwa-land/sprites/*/idle.png`（仮置き・極小）。本番品質は小夏さんの実画像が天井。
- L2の口パクには各キャラ「口・開/閉」素材が必要。
- VOICEVOXはクレジット表記必須。実在声優学習の声は使わない。

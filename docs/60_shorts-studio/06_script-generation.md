# 06 — 台本生成の仕組み（自然で楽しい掛け合いを量産する"脳"）

> render.py は**描くだけ**。テーマ/ストーリー/セリフの面白さは**台本**が決める。
> 本ファイルは「テーマ → 自然で楽しい台本JSON」を生む**生成ルールの正本**。AI（Claude等）にこの制約を毎回注入して台本を作る。
> 関連: 台本仕様=`04_script-authoring.md` / バズ実証=`05_research-virality.md` / **笑いと啓もうのcraft=`07_humor-and-edutainment-craft.md`（必読）** / コンプラ=`../20_business/medical-ad-content-policy.md` / キャラ正本=`public/content/fuwafuwa-land/character-bible.json`

## 0. 狙いとターゲット（確定・2026-06-26）
- **目的＝YourTIMEコンセプト告知 × 集客 × 口腔育成/未病の啓もう**（スワさん向け本命）。
- **見る人＝来場見込みの保護者・家族＋未病に関心ある層**（YourTIME/Insta）。買い手の出展者ではない。
- **すーすーわーわー＝"かわいい啓もうの案内役"**。狙いは「**くすっと笑える × つい見続ける × うさんくさくなく8/2へ行きたくなる**」。
- 出展者紹介ショート（format A）は**凍結**（コンテンツが育ってから）。木幡(やす)キャラのAI解説は**おまけ・別トーン**で混ぜない。
- **笑い・構成・へぇネタ・字幕・CTAの具体は `07` を正とする。** 本ファイルはその運用チェックリスト。

## 入力（人間が渡すのはこれだけ）
- **テーマ＝誰の・何の困りごとを・どう転がすか**（例: 親の「うちの子、寝てる時お口ぽかん」）
- **登場キャラ**（省略可。掛け合いはわーわー×すーすーが基本＝ボケ×ツッコミ）

## ① キャラ声を正本から引く（"らしさ"が9割）
character-bible.json の `traits / speech / emotionKeys / 口ぐせ / こわいもの / 欲しいもの` を**必ず**反映。主役2人：

| キャラ | 声(Hz) | 役 | 話し方 | 口ぐせ/癖 |
|---|---|---|---|---|
| **わーわー** | 920 | ボケ・村長 | 勢いよく短く・勘違いしてもすぐ笑って立て直す | 「出発だー！」「それ、冒険っぽい！」帽子押さえて跳ねる |
| **すーすー** | 760 | ツッコミ・助手長 | やさしく整理・ツッコミは柔らか・短く正確 | こくこく頷く／静かに照れる／いちごが好き |

> **口調＝標準語**（YourTIMEは東京開催）。エセ関西は使わない。ツッコミは「〜でしょ」「〜じゃない」等の柔らかい標準語で（すーすーの「やさしいツッコミ」設定とも合う）。

> 専門キャラは役割で呼ぶ：もぐぴよ(口腔育成・ほめ上手)/とうか(甘い誘惑に弱い)/さんか(口呼吸・心配性)/けとにゃん(健康先生・語尾にゃ) 等。

## ② 掛け合いの型（交互の"説明"を禁止）
**設定 → 勘違い/飛躍(ボケ) → ツッコミ → 転換 → 小さなアハ1つ → リアクション** で転がす。
- **1行は短く**（体感1〜2.5秒）。長い説明を1文で渡さない。
- **被せ・即レス・感情**を入れる（「えっ」「なんだ〜」「耳がいたい」）。
- キャラの**勘違い→訂正**で情報を運ぶ（説明されると視聴者は逃げる、笑うと残る）。
- 名前ダジャレ等の**内輪ギャグ**を1つ仕込む（例: すーすー＝鼻呼吸の音「すーすー」）。

## ③ フック（最初の0.5〜2秒・`hook`フィールド）
**あるある or 驚き or 未完の問い**を前出し。健康は2秒目以降に密輸。
例: `"hook": {"text":"ねるとき、お口…あいてない？", "durationSec":1.6, "type":"aruaru"}`

## ④ 教育は"1アハ"だけ密輸（講義禁止）
1本で伝える健康ポイントは**1個**。しかも**キャラの実体験/困りごと**として。
- ✗「鼻呼吸は健康に良いです」→ ✓ わーわーが口あけて寝てた→すーすーが鼻でスーって、で1アハ。

## ⑤ コンプラ（ハード制約・NG→OK）
断定・効能を**言わせない**（lintにも入ってる）。言い換え表（出典: medical-ad-content-policy.md）：

| NG | OK |
|---|---|
| 歯並びが良くなる/治る | お口で遊ぶ時間を大切にしている |
| 虫歯を予防できる | 毎日のケアを楽しくするきっかけ |
| この器具で改善します | こういう道具を使った遊びを紹介しているよ |
| 専門家が効果を保証 | 〇〇のプロが、こんなことを大切にしているよ |

禁止語: 治る/治療/予防/効果/効能/効く/改善/保証/日本一/No.1。キャラは医療の主体に見せない（遊びの案内役）。

## ⑥ 形式契約（render.py が読めるJSON）
```jsonc
{
  "title": "yt-006-kebab", "topTitle": "画面上のタイトル",
  "series": "シリーズ名",            // 同シリーズは識別色が揃う
  "theme": "…", "weather": "よる",   // weather/theme から背景＆接地は自動
  "hook": { "text":"…", "durationSec":1.6, "type":"aruaru" },
  "cta": { "color":[214,158,44] }, "audio": { "bgm":true, "animalese":true },
  "eventAnimation": ["soft-popup"],  // 任意の演出
  "lines": [
    { "who":"waawaa", "text":"おはようございます！", "dur":2.2 },
    { "who":"waawaa", "text":"今日のふわふわランドの天気は、、、", "dur":3.0 },
    { "who":"suusuu", "text":"よる、です！", "dur":2.2 },
    /* …掛け合い… */
    { "who":"cta", "text":"ねるまえ、お口とじてね", "dur":2.6 }
  ]
}
```
- **必須の冒頭3行**: `おはようございます！` / `今日のふわふわランドの天気は、、、` / 「○○です！」（天気＝背景に直結）。hookはこの前に別レイヤーで乗る。
- **尺**: 台詞合計 **30〜60秒**。`dur`目安＝文字数×0.18＋0.8（短文2〜3秒）。
- `who` は bible id（waawaa/suusuu/mogupiyo…）。色/声/画像/背景/接地は全部自動。

## ⑦ バズの型（05準拠・最小で効かす）
- **入口は"あるある"**（親の自分ごと）→ 共感で拡散。
- ときどき**保存回**（「鼻呼吸チェック3つ」等チェックリスト型）。
- **シリーズ化**（`series`固定）＝連載で再訪・follow。
- **CTAは軽く・場内**（「またね」「やってみてね」）。外部誘導を主にしない。

## ⑧ 出力前の自己採点（全部YESで出す）
- [ ] 最初の1秒に**フック**（あるある/驚き/問い）があるか
- [ ] **交互の説明**になってないか（勘違い→ツッコミで転がってるか）
- [ ] 各行が**そのキャラの声**か（口癖/性格が出てるか）
- [ ] 健康ポイントは**1個だけ**、しかもキャラの実体験で密輸できてるか
- [ ] **禁止語ゼロ**・断定なしか（`--check`で確認）
- [ ] 1行が短く、声に出して**テンポよく**読めるか
- [ ] 内輪ギャグ/リアクションで**くすっと**できるか
- [ ] 尺30〜60秒に収まるか

## ⑨ Few-shot（型の手本）
**Before（固い・交互説明）→ After（自然・掛け合い）**
```
Before: keto「水の雨にゃ。甘い方は、悪者じゃない」/ touka「よかった。焦げた気分で」
After:  touka「アメだ──！！ぼくの好物っ」/ keto「……水の雨にゃ」
        touka「なんだ〜。じゃ今日も甘いのガマン？」
        keto「ちがう。甘いのは悪者じゃない。"ダラダラ"がクセモノなだけにゃ」
        touka「ダラダラ……耳がいたい」
```
**くすっと型（07準拠・共感→へぇ→脱力オチ→招待CTA）**
```
わーわー「あさ 起きたら 口カラッカラ」      ← 共感(あるある)
すーすー「あんた また 口あけて 寝とったな」  ← エセ関西ツッコミ＝代弁
すーすー「日本の子の 3人に1人、お口ぽかんやて」← へぇ(一次資料・断定回避)
わーわー「3人に1人！ ぼくの 仲間 いっぱいや！」← ボケ
わーわー「ぼくの口、むし歯くんの パーティ会場やん」← 脱力オチ(無害×逸脱)
すーすー「村の せんせい。…8/2、会いに来る？」  ← うさんくさくない招待CTA
```

人間は「**◯◯のテーマで台本作って**」と言うだけ。AIは本ルール（①〜⑧）を満たす台本JSONを生成→`--check`（コンプラlint込み）→`--storyboard`で通し確認→OKなら本番。

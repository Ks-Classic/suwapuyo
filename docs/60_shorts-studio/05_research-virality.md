# 05 — ショート動画 実証パターン集（リサーチ）

> 仮説ではなく、公開された事例研究・プラットフォーム公式・学術・業界記事に基づく実証ベースのまとめ。
> 注意: フック維持率の「○○%」系はマーケブログが一次ソース未記載で再掲しているものが多い＝**方向性は信頼・数値は鵜呑み禁止**。RCT/学術/日経xTrend/NPRは一次〜準一次で信頼度高。

## このプロジェクト最大のリスク（最重要）
**animalese（擬音のみ）の新規キャラが"発見"される保証は無い。** Animaleseトレンドが伸びたのは既存IP（あつ森）の人気が土台。ゼロからの新規キャラが擬音だけで発見性を得た実証は無い。
→ 必須の補強: ①**日本語焼き込み字幕**（実装済）②**導入/締めにトレンド音源を薄く重ねる**（初動1.5〜3倍・寿命2週間）③**参加型化**（擬音チャレンジ・推し投票）。「可愛いだけ」は増幅器であって発見性ではない。

## 伸びる型（抜粋）
| パターン | 確からしさ | 適用 |
|---|---|---|

| キュリオシティ・ギャップ／オープンループ | 中〜高（心理学） | 「なぜか眠れないすーすー…」で謎提示 |

## やってはいけない
1. 冒頭でいきなり健康講座（説明から入る）→ 3秒で離脱
2. 字幕なし（80-85%が無音視聴）→ animalese前提では致命的
3. Reelsにテロップ詰め込みすぎ（Reelsは余白、TikTokは情報密度＝**別最適化**）
4. 数打てば当たる（低品質量産）→ 世界観が薄まり長期資産が育たない
5. トレンド音源の旬過ぎ/使い回し（寿命2週間）
6. 一発バズで世界観を崩す → follow転換せず長期IP毀損
7. 過剰演出の作られた共感 → 育児層は作為に敏感、信頼が下がる

## 後追い分析の現実解
- **TikTok Studio**=秒単位retention/リプレイ/完視聴まで出る（分析価値最高）。**Reels**=平均視聴時間どまり＋保存/シェア/フォロワー外比率を見る。
- **タグ設計**: 各投稿に `フック型 / テーマ / 尺 / 音源 / カバー有無 / キャラ / CTA / シリーズ回` を付け指標と突合（→ `post-ledger.csv` で自動化済）。
- **本数とノイズ**: 成果はロングテール（少数が大当たり）で分布が歪む＝平均比較は誤誘導。**最初30〜50本は探索（外れ値の定性レビュー＋中央値/トップ5の共通項）**。単変数の傾向は50〜100本から。**重回帰など多変数は100本超＆1変数10本以上**を満たしてから。早すぎる多変数分析は時間の無駄。

## 日本市場 特有
- ReelsとTikTokは設計が逆（余白 vs 情報密度）。使い回しは非効率。
- 保存文化が強い＝チェックリスト/まとめ型が効く。
- トレンド音源の旬が短く必須級。
- "亀型"の持続成長が王道（すみっコ＝永続的成長、ちいかわ＝ほぼ毎日投稿）。
- "弱さ・引け目"への共感（α世代）。完璧でない住人ほど刺さる。

## 不確実・諸説あり（正直に分離）
- フック維持率の具体% / 「最初の1時間が80%」= 業者推定。傾向として扱う。
- animaleseでゼロから発見性を得られるか= **未実証＝本PJ最大リスク**（上記の補強前提）。
- ループの効果数値= 体感ベース主張が多い。構造は妥当だが過信しない。
- edutainmentの**学習効果**はRCT実証だが、**拡散力**まで両立した実証は薄い。学習効果≠拡散力。

## 最初にやるべき上位5（優先順）
1. 無音前提の日本語焼き込み字幕を全動画標準化（実装済・維持）
2. 固定キャスト×世界観の一貫反復（`series` 化・Snoopy/ちいかわ型）
3. 冒頭0.5〜2秒の視覚フック＋オープンループ、健康は2秒目以降に密輸（`hook` 実装済）
4. 育児あるある入口＋保存用チェックリスト回を定期投入
5. タグ付き台帳を初日から運用、最初30〜50本は探索（`post-ledger.csv` 自動化済）

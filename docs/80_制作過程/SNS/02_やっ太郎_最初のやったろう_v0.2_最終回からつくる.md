## 0. 先に結論

最初の投稿で「私たちは目的から設計します」と言わない。

**まだゲームが一秒もないのに、やっ太郎が“すわぷよの最終回”だけを世界一豪華に完成させてしまった**ところから始める。

読者の感情順は、`何これ？ → ばかだな → でも続き見たい → すわぷよって何？`。最後にだけ、実際に作りたいものとYourTIME.を置く。

## 1. 一本の目的

| 層 | 目的 |
|---|---|
| 娯楽 | 「最終回だけ先に作る」という逆順の暴走で、指を止めてもらう |
| キャラ | やっ太郎の“やったろう”を、無鉄砲さと発想の両方で一発理解してもらう |
| プロダクト | `すわぷよ`を「まだないが、完成を見届けたくなるゲーム」にする |
| YourTIME. | 物語の最後に、未病×エンタメイベントで生まれる企画だと理解してもらう |
| 事業 | “完成品の見栄え”と“目的へ戻す編集”を同時に実演し、仕事の頼もしさを見せる |

最初のCTAは相談ではない。**「このエンディングにたどり着くゲームが、本当にできるか見届ける」**。

## 2. 物語

じく太郎が朝、開発室のドアを開ける。

そこには、紙吹雪、スポットライト、拍手している100体の謎キャラ、巨大なエンドロール、そして感極まって泣くやっ太郎がいる。

```text
     SUWAPUYO  THE END
  たくさんあそんでくれてありがとう！

             ※ゲームはまだありません
```

じく太郎は、エンドロールを見上げて一言。

> 「ゲームは？」

やっ太郎は一切ひるまない。

> 「最終回が楽しそうなら、途中を作りたくなるでしょ！」

二人は笑い、エンドロールの最後の空欄に気づく。

```text
SPECIAL THANKS
ここで遊んでくれる、まだ会っていないきみへ
```

その空欄を埋めるために、今からすわぷよを作る。遊びながら口やからだを動かすきっかけになるゲームを、YourTIME.で生み出す。

やっ太郎は「最終回から逆算する」という一つの発見を得る。これは失敗オチではない。**先に“誰かが楽しんだ未来”を描いたから、途中のゲームを作る理由ができた**という、ぶっ飛んだ成功である。

## 4. 台詞の温度

| 人物 | 台詞 | 狙い |
|---|---|---|
| やっ太郎 | 「最終回が楽しそうなら、途中を作りたくなるでしょ！」 | ぶっ飛びと、少しだけ本当のこと |
| じく太郎 | 「ゲームは？」 | 読者のツッコミを短く代弁 |
| じく太郎 | 「……それは、ちょっと分かる」 | 正論で潰さず、相棒として乗る |
| やっ太郎 | 「最終回に、ほんとに連れてく！」 | キャラの約束／次回予告 |

じく太郎の真面目さは、長い説教ではなく、やっ太郎の行動から良い核を拾いながら、作者と社会へ影響する境界だけは具体的に示す一言にする。

## 5. キャプション案（Instagram review用）

```text
やっ太郎が、すわぷよの最終回を完成させました。

ゲームはまだ、ありません。

じく太郎「ゲームは？」
やっ太郎「最終回が楽しそうなら、途中を作りたくなるでしょ！」

……それは、ちょっと分かる。

すわぷよは、遊びながら口やからだを動かす
きっかけをつくるゲームを目指して、
未病×エンタメイベント YourTIME. で生まれました。

まずは、誰かが遊んで笑っている未来だけ先に作った。
その未来にちゃんとたどり着くために、
今から最初の1ぷよを作ります。

完成品だけじゃなく、最終回を先に作ってしまった
途中経過も、ここに残します。

次は、最終回じゃない方を見せる。
```

ハッシュタグ、開催日、外部リンク、協力者名は公開直前の事実確認後に別reviewで付ける。

## 6. 動画化するなら（15秒）

```text
0.0–2.0秒   壮大な最終回。紙吹雪と「※ゲームはまだありません」
2.0–4.0秒   じく太郎「ゲームは？」
4.0–7.0秒   やっ太郎「まだ！」→とりあえずボタン発光
7.0–10.0秒  やっ太郎式・ゲーム開発 ①最終回 ②泣く ③途中
10.0–13.0秒 SPECIAL THANKSの空欄 → 小さな最初のぷよ
13.0–15.0秒 「最初の1ぷよを見せる。」
```

静止画6枚の手動review後に、採用画をパン・ズーム・紙吹雪・効果音でつなぐ。最初から生成動画にしないため、やっ太郎とじく太郎の同一性を守れる。

## 7. 生成・公開Gate

1. じく太郎の公式原画のポーズ、シャツの`Ai`、ベスト、しっぽ、顔を変更しない。
2. やっ太郎は承認referenceでのみ生成する。未承認のAI案を正本にしない。
3. `SUWAPUYO THE END`、`※ゲームはまだありません`等の文字も、原則GPT Image 2で一体生成する。採用後に手動組版せず、崩れた場合は同モデルで再生成する。
4. `すわぷよ`、`YourTIME.`、健康に関する表現は、現行仕様・運営表記・実装状態と一致させる。
5. 画像ごとにreference、prompt、model、担当、用途をmanifestへ記録する。
6. 木幡さんが、笑えるか／やっ太郎らしいか／すわぷよへ興味が向くかを確認してから公開候補へ昇格する。

## 8. 今回の手動レビュー項目

- 1枚目を見て「何これ？」となるか。説明を読まないと成立しないなら作り直す。
- `※ゲームはまだありません`が、未完成の言い訳でなく期待になるか。
- じく太郎が人格を叱る説教役ではなく、作者と社会の軸を示しつつ、やっ太郎の発想の価値を見つける相棒になっているか。
- `YourTIME.`と`すわぷよ`の説明が、オチを殺していないか。
- 最後に、次の投稿を待ちたい気持ちが残るか。

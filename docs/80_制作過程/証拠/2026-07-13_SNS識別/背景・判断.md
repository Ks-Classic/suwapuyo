# SNSアイデンティティ制作記録（ドラフト）

> 状態: private / 未公開素材
> 対象: `YASU-CHAR-001`, `YASU-COUSIN-001`, `SNS-PAIR-001`

## 目的

公式やすと、やんちゃな爬虫類のいとこを並べ、同じ世界の親戚だと分かるSNS用の識別素材を作る。公式やすの原画を変えないことを最優先とする。

## 判断と修正

| 段階 | 判断 | 学び |
|---|---|---|
| 初回AI合成 | 生成モデルが公式やすのポーズ、シャツ、服装を再描画した | 公式キャラの原画を不変とする場合、AI生成による2人同時再描画は不採用 |
| 白背景の単純透過 | いとこ案の紙質・近似白が残り、四角い背景が見えた | 背景は白へ統一し、いとこ側だけ近似白を色キー処理する |
| 全身アイコン | 2人の情報量が32px相当で読みにくい | 顔寄り版と全身版を分け、実機の丸型クロップで採用版を決める |

## 現在のドラフト

- `public/content/brand/social/SNS-pair-icon-v3.png`: 全身が分かる2人構図。
- `public/content/brand/social/SNS-pair-icon-v5.png`: 顔寄りの小アイコン候補。
- `public/content/brand/social/x-header-v1.png`: X用1500×500。
- `public/content/brand/social/instagram-threads-intro-v1.png`: Instagram／Threadsの入口投稿用1080×1350。

不採用候補（初回AI合成、背景透過の失敗、全身と顔寄りの比較）は`docs/80_制作過程/証拠/2026-07-13_SNS識別/下書き/`に保管する。

## 不変条件

- 公式やすは`やすさん.jpg`を元画像として配置し、ポーズ、シャツ、ベスト、しっぽ、顔を描き変えない。
- いとこは候補デザインであり、公開・商用利用前にツナマヨさんの監修と権利範囲確認を行う。
- SNSへ実際に設定する画像は、木幡さんとツナマヨさんの採用確認後に1版へ固定する。

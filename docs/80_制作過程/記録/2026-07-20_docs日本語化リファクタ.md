# docs日本語化リファクタ記録

## 何が起きたか

`docs/`の英語名を一括で日本語化した際、文書パスだけでなく、本文中のコードパス`public/content/`と`src/fuwafuwa-land/`まで日本語へ置換された。また、全領域を対象にした修正スクリプトは`.agents/`への書込みで`EROFS`となり停止した。

## 原因

- 直接原因: ファイル名の置換表を本文へそのまま適用し、文書名とコード識別子の境界を分けていなかった。
- 直接原因: ワークスペース内でも`.agents/`は通常スクリプトから書込めるという前提で実行した。
- 根本原因: 「日本語化する対象」と「安定した英語識別子として維持する対象」を実行前の移行表に明記していなかった。

## 修正と再発防止

- 文書・人向け素材の名前だけを日本語化し、コードのモジュール名、importパス、公開URLは英語で維持する。
- `public/content/`と`src/fuwafuwa-land/`を復元し、`STRUCTURE.md`とリポジトリ地図に命名境界を明記した。
- `.agents/`は一括書換え対象から外し、既存Skillの参照だけを個別パッチで更新した。
- 今後の一括移行は、事前に衝突確認、ドライラン、対象拡張子、除外領域、安定識別子を明記してから実行する。

## 検証

- 旧docsパスと誤った日本語コードパスを`rg`で再検索する。
- Markdownリンク、JSON構文、`git diff --check`、アプリbuildを確認する。
- 本リファクタでは本番反映・DB・外部サービスを変更しない。

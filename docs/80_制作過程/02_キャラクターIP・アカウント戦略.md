# やすキャラ・いとこ・アカウント戦略

> 文書状態: `じく太郎`と`やっ太郎`の名称・関係性はreviewed。やっ太郎はツナマヨさんによる造形・権利承認と自由展開の許可取得済み（2026-07-13・木幡さん申告）。公式原画とYourTIME運営境界は別Gate
> 最終更新: 2026-07-19

> いとこキャラの造形正本・生成統制は[`05_やっ太郎キャラクター正本・生成統制.md`](./05_やっ太郎キャラクター正本・生成統制.md)、2026-07技術選定は[`06_キャラクター一貫性・技術調査_2026-07.md`](./06_キャラクター一貫性・技術調査_2026-07.md)、人格・SNS編集は[`07_やっ太郎ブランド・SNSシリーズバイブル.md`](./07_やっ太郎ブランド・SNSシリーズバイブル.md)を正とする。本書はブランド役割・アカウント・権利境界を扱う。

## 1. 推奨ブランド構造

```text
ツナやす（制作・事業ブランド）
├ じく太郎（公式やすキャラ。社会的な軸・秩序・作者尊重・解説）
├ やすのいとこ（別キャラ・実験・失敗・反面教師）
├ すわぷよ（親子向けプロダクト）
└ YourTIME連携（イベント協力。ブランド所有を混同しない）
```

公式やすキャラの物語上・公開上の正式名は`じく太郎`とする。ツナマヨさんが制作した原画を公式masterとして保全し、権利台帳の`YASU-CHAR-001`は同じ権利対象を指す識別子として維持する。キャラコピーは許可取得済み。表情差分、ポーズ、動画、3D、AI入力、学習、類似キャラ作成の具体的範囲はコピー許可と分けて記録する。

## 2. やすのいとこ（AI実験キャラ）

公式やすの単純なAIコピーではなく、「爬虫類のいとこ」と認識できる共通項を限定して持つ別キャラとして設計する。現時点の採用候補は、サンゴ色とクリーム色を基調にしたヤモリ／若いトカゲ系である。公式やすとの並びで親戚感が分かり、単独でも公式やすと誤認されないことを採用条件とする。

2026-07-13、木幡さんから「ツナマヨさんによる正式な造形・権利承認であり、いとこに関しては自由でOK」と申告された。この承認により、いとこのキャラブランド設定、2D / 3D / 動画 / SNS / 広告 / 商用 / AI参照生成を進める企画上のGateは通過した。`RIGHTS-COUSIN-2026-07-13-ORAL-001`としてCharacter Masterへ記録する。

ただし、この承認は公式やす、第三者の音源・振付・人物・素材、生成tool/modelの利用条件まで許可するものではない。また、学習weightの一般配布、無制限再許諾、法的著作権帰属、終了時の処理は、外部提供・商品化の前に個別記録する。

必要条件:

- 名前、輪郭、色、服、口調を見分けられる。
- じく太郎との関係性と、二人それぞれの作者・権利対象を明示する。
- 承認済みのAI画像・動画生成、変形、商用利用、再生成、学習・参照入力を、用途別permissionと証拠 IDで追跡する。
- 生成物のmaster採用権、公開停止権、削除権、sourceやweightの配布権を決める。
- 元の公式やすをAIへ入力せずに運用できる専用reference sheetまたは作者制作の差分を用意する。
- 二足で立ち、手・腕・脚・足・しっぽを独立して動かせる。ダンス、転ぶ、指さす、謝る等の動画ポーズへ展開できる。
- 共通項は、丸みのある爬虫類、ほっぺ、額のうろこ記号等に限定する。色、輪郭、顔配置、服、しっぽ、口調は分ける。
- ふわふわランド既存22体と、動物種・輪郭・主要配色・役割が衝突しないことを一覧で確認する。

## 3. 「コンプラグレー」の再定義

実際の権利侵害、差別、医療誤情報、他社ロゴ無断利用、実在人物ディープフェイクを行う案は不採用とする。炎上は実験結果ではなく、公式やす・ツナやす・YourTIME全体へ帰属するブランド事故になる。

採用する表現:

> やっ太郎が「AIでできるなら何でもやる」と、作者・許諾・出典・権利・事実の曖昧な境界を無自覚に越える。じく太郎が、作者へのリスペクトと社会的秩序の軸から「何を侵したか」「なぜ問題か」「どう直せば続けられるか」を注意する。

物語上の越境は未公開sandbox、架空素材、許諾済み素材で再現する。実在の作者、第三者素材、人物、子ども、個人情報を実際に侵害してから学ぶ企画は不採用とする。

これにより、反面教師、AI自動生成、コンプライアンス教育、公式キャラの信頼を同時に成立させる。

## 4. キャラ役割

| 項目 | じく太郎 | やっ太郎 |
|---|---|---|
| 役割 | 社会的な軸、秩序、作者尊重、判断、解説 | とりあえず何でもやる、曖昧な問題を可視化する |
| 性格 | 真面目、軸がある、行為と影響を分けて注意する | 好奇心過剰、悪意なく無自覚に境界を越える、修正できる |
| 禁止 | 無断変形、煽り、効果保証、他者攻撃 | 現実の侵害、差別、医療断定、公式を装うこと |
| 成長 | 新技術を秩序だけで止めず、作者と社会を守りながら前へ進める | 「できる」と「やってよい」を区別し、同じ重大な越境を繰り返さない |
| CTA | 作者、根拠、正しい利用、深い解説へ進む | 実験を見る、問題に気づく、じく太郎の解説へ進む |

実験キャラを毎回ぶれさせる場合も、`何がぶれてよいか`を固定する。核まで無秩序にするとキャラクターでなく単発のAI生成物になる。

## 5. アカウント構成

### 推奨

1. すわぷよ公式LINE: プレイ、イベント、チェックイン、利用者サポート。B2Cの正本。
2. ツナやす／やすキャラ X・Instagram・Threads: 制作過程、AI、キャラ、Web、LINE、すわぷよの裏側。人と専門性の正本。
3. ツナやすWebサイト: 完成記事、事例、解説モード、サービス、相談。検索・AI検索の正本。
4. やすのいとこ: 権利・口調・運用が安定するまでは、2の中の明示シリーズとして試す。独立運用できる量と需要が確認できた後だけ別アカウント化する。

X・Instagram・Threadsは当面同じ表示名・アイコン・説明の核を使い、媒体ごとに別人格を作らない。InstagramとThreadsのプロフィール連携・同期範囲は、アカウント作成時の現行画面で確認し、意図しない個人アカウントとの連携を避ける。

### 分ける理由

- すわぷよ利用者へB2B・AI論を大量配信しない。
- ツナやすの専門性を、イベント1件だけのアカウントに閉じない。
- 実験キャラの失敗を公式すわぷよの発言と誤認させない。
- 初期から複数アカウントを作り、どれも更新されない状態を避ける。

実験キャラが本当に「グレーぎりぎり」を扱うなら同一アカウントでも別アカウントでも公式への波及は防げない。アカウント分離は免責にならない。

## 6. キャラ利用契約で確定する項目

- 原画とキャラクター設定の著作権者。
- 木幡さん、ツナやす、すわぷよ、YourTIMEが使える媒体と期間。
- 商用利用、広告、商品化、動画、音声、3D、表情・ポーズ差分。
- AIサービスへの入力、学習、reference利用、生成物の公開。
- 二次的著作物とAI生成物の権利・採否・修正・削除。
- 作者監修が必要な変更と、運営判断で可能な変更。
- クレジット、収益分配、再許諾、終了・アカウント停止時。
- 炎上、第三者権利侵害、プラットフォーム停止時の対応。

文化庁も、キャラクター制作では著作権帰属と利用態様を具体的に特定することが有益としている。今回の正式承認は制作を進める根拠として扱い、曖昧なまま消さずに申告者・許諾者・日付・範囲・除外を証拠IDへ構造化した。商品化、一般配布、第三者再許諾のように影響が広がる時点で、必要な追加条件を記録する。

## 7. データ帰属

「すわぷよ周辺のデータは一旦ツナやすの持ち物」とは定義しない。データは物の所有権のように一括所有せず、種類ごとに管理責任と利用権限を契約する。

| データ | 推奨する正本・責任 | ツナやすの利用 | 出展者への提供 |
|---|---|---|---|
| LINE識別子 | LINE Harness管理者 | 認証・配信目的の限定処理 | 不可 |
| 家族年月・性別 | 指定する個人情報取扱事業者 | 利用目的内の体験・集計 | 個票不可 |
| プレイ・体操 | プロダクト運営主体 | サービス提供・改善 | 少数値処理後の集計のみ |
| ブース訪問・自己申告 | イベント／プロダクト共同設計 | 明示目的内の集計 | 契約・説明済みの集計のみ |
| 出展者提供情報 | 出展者／YourTIME | 掲載許諾範囲 | 本人情報として返却可 |
| 集計レポート | 契約で利用権限を定義 | 事例化は別許諾 | 対象出展者の範囲のみ |
| コード・設計・運用ノウハウ | 制作者契約 | ツナやすの再利用範囲を確定 | 納品範囲のみ |

最低限、`誰が取得主体か`, `何の目的か`, `誰に提供するか`, `削除要求へ誰が応じるか`, `イベント終了後も使うか`, `営業事例へ使えるか`をYourTIME運営と文書化する。

## 8. 要確認Gate

- IP-01: 公式やすのAI入力、改変、動画、商用、再許諾等の範囲を文書化。いとこの承認と混同しない。
- IP-02: いとこは別キャラとして自由展開の承認済み。法的著作権帰属、クレジット、master採用・停止、一般配布条件だけ外部展開前に補完。
- IP-03: いとこのプロフィール、口調、禁止行為、変更承認者を`07`とCharacter Masterで確定。
- BRAND-01: ツナやす名義、アカウント名、運営者表記。
- DATA-01: すわぷよの個人情報取扱事業者。
- DATA-02: YourTIME、ツナやす、出展者間のデータ利用権限。
- DATA-03: 集計レポートの無償提供、有償販売、事例公開の範囲。

# 08 — 4コマ/シーン切替ショートのバズ要素 徹底分解（2026-06 最新・海外含む）

> **対象フォーマット = 1本の動画の中で、静止画(コマ/シーン)が内容に合わせて自動で切り替わる「モーション紙芝居/シーンカット動画」。**
> （視聴者がスワイプするカルーセル/フォトモードでは無い。違いは §0-1 と §2F を参照。スワイプ系の知見も“参考”として一部残す）
> 目的: ①単体でバズる要素 ②アカウントとして継続再生を得る要素 を **最小単位まで分解** し、
> YourTIME. のコンセプト（**嘘・誇張なし／未病を遊びに／PULLであってPUSHでない**）に合う形へ応用する。
> ベースの一般論は `05_拡散性調査.md`。本書はそれと別軸＝**シーン切替フォーマット特化**。
> 注意: マーケブログ由来の「○○%」は方向性は信頼・数値は鵜呑み禁止。プラットフォーム公式（Mosseri等）・retention benchmark系は準一次。

## 0. 結論サマリ（先に1枚）

1. **対象は「1本の動画内でコマが自動で切り替わる」型** = 通常の動画フィード（最大の母数）で戦う。視聴者操作なし＝**尺とカットを自分で設計できるのが最大の武器**。
2. バズの最小単位は **(a) 最初の3秒で止める → (b) コマ切替で“注意リセット”し維持率を保つ → (c) 最後にオチ＋保存/フォロー** の3点。指標に直すと **完視聴率・リプレイ率・最初の3秒の離脱率**（※スワイプ率は使わない＝カルーセル専用指標）。
3. アカウント継続再生は **ニッチ一貫性 × 週3〜5の安定投下 × シリーズ化** が本体。2026年は「一発バズの価値が1/4に低下、安定投稿の価値が4倍」へ明確にシフト。
4. **2026年の地殻変動＝「過剰刺激(Hyper-Stimulation)」から「実用(Hyper-Utility)/認知的リテンション(Cognitive Retention)」へ。** → **嘘・誇張なしのYourTIMEは、いまの潮流とむしろ一致＝制約が追い風**。
5. 4コマは日本の**起承転結**と相性最高。**転（意外な気づき）に未病を1滴“密輸”**し、**結（オチ＋小さな持ち帰り）で保存**を取りにいく。

> **0-1. なぜ「動画内シーン切替」が強いか（フォーマットの本質）**
> - **コマの切替＝パターン・インタラプト**。画が変わるたびに視聴者の注意が再起動し、離脱しにくい（=維持率↑）。静止画1枚を長く映すより、意味のあるカットで割る方が持つ。
> - **尺・テンポを自分で握れる**。各コマ秒数を音源ビートに合わせてカット＝完視聴・リプレイを設計できる。スワイプ任せのカルーセルには無い利点。
> - **ループ設計が可能**。最終コマ→1コマ目が自然につながると**リプレイ率↑（単体最強の拡散シグナル）**。
> - 戦う相手は動画フィード全体だが、制作は静止画＋字幕＋音だけ＝**低コストで量産可能**（撮影/3D不要）。

## 1. 2026年の地殻変動（これを外すと全部ズレる）

- **過剰刺激 → 実用へ。** 専門筋は2026年を “Hyper-Utility era / Cognitive Retention”（人に**考えさせ・保存させ・共有させる**コンテンツ）と表現。煽り/釣りの相対価値が低下。
- **動画は完視聴/リプレイが命。** 我々の型（動画内シーン切替）は通常の動画として評価される＝**最初の3秒の離脱率・完視聴率・リプレイ率**が直撃。コマ切替で注意を再起動し維持率を作る。（※カルーセルのスワイプ率は別フォーマットの指標なので混同しない。ただしフォトモード/カルーセル自体も2026は伸びる枠なので、同じ素材で“別フォーマット展開”する価値はある＝後述 §5-5）
- **一発バズ<継続。** 「単発バズの価値は2023年の約1/4、安定週次投稿の価値は4倍」。アルゴリズムは“このアカウントは何屋か”の確信を積み上げる。
- **無音前提は不変。** 80%超が無音視聴 → **焼き込み字幕＝本体**（`05`既出・実装済を維持）。

> YourTIMEへの含意: **「嘘・誇張なし」は2026年のトレンドそのもの。** 説教を避け“役に立つ/共感する”を実直にやるほどアルゴリズムに乗る。コンセプトと潮流が珍しく一致している局面。

## 2. 単体動画のバズ要素 — 最小単位まで分解

### A. 骨格（全フォーマット共通）
**Hook → Body → Payoff**。4コマなら日本の **起承転結** にそのまま対応:

| コマ | 役割 | 静止画切替での担当 | 心理 |
|---|---|---|---|
| 起 | 状況提示＝フック | 1枚目（+2枚目で文脈） | 「自分のことだ」=共感／謎 |
| 承 | 小さな展開 | 2〜3枚目 | スワイプの慣性をつける |
| 転 | 意外な気づき（ねじれ） | 3〜4枚目 | オープンループ回収の予感／**ここに未病を密輸** |
| 結 | オチ＋持ち帰り | 最終枚 | 保存・フォロー・共有の動機 |

### B. コマ設計の数値ルール（動画内シーン切替）
- **コマ数=4〜6が目安**（起承転結＋導入/オチで4〜6カット）。詰め込みすぎは間延び。
- **総尺=7〜15秒を基本**（15秒未満は完視聴60〜70%が平均レンジで取りやすい）。各コマ=**1.5〜3秒**で割る。
- **コマ秒数は均等にしない**。フック(起)はやや長め、転〜結はテンポ良く短く＝ビートに乗せる。
- **カットは音源のビート/アクセントに合わせる**（DAZN音ロゴの頭・終盤アクセントと同じ発想）。
- **9:16縦**。コマごとに構図/背景/表情を変える（同一画の据え置きは離脱）。**カット＝注意リセット**を意図的に使う。
- **各コマ1メッセージ**。**1行=4〜8語**（日本語なら短文・体言止め）。無音前提＝**字幕は常時ON・本体**。
- **ループ設計**: 最終コマの画/音が1コマ目へ自然に戻ると **リプレイ率↑**。

### C. フック（1枚目）— 最小の型カタログ
1枚目が**全体の約8割の重み**。3秒以内に止める。型:
- **共感あるある型**: 「寝る前、なぜか子どもが…」（α世代/育児層に効く）
- **キュリオシティ・ギャップ型**: 「これ、知らない人が9割」
- **ビフォーアフター/比較型**: 「ふつうのゲーム vs すわぷよ」
- **数え上げ(リスト)型**: 「お口がぽかんの子のサイン3つ」（保存率高）
- **視覚アクション型**: 動きの強い1枚（キャラの大きな表情）

### D. テキスト/字幕
- **大きく可読**・1枚1コア・**最終枚にCTA**（「保存してね」「村の続きはプロフから」）。
- キャプションは**問い or 好奇心**で締め、**ハッシュタグ3〜5個**、検索流入用に主要キーワードを1語。

### E. 音源（初動の増幅器・本体ではない）
- **トレンド音源を必ず薄く重ねる**（その音源のフィードに載る＝発見性）。寿命〜2週間、使い回し厳禁。
- 明るい音=教育/前向き、ドラマ音=物語/変化、と中身に合わせる。
- 我々は擬音（すーすーわーわー）が主役なので、**導入/締めにトレンド音源を薄く**の折衷（`05`の方針を継続）。

### F. アルゴリズムが報酬する信号 = “最小単位の指標”（動画フォーマット）
**再生数を追わない。** 動画内シーン切替は**通常の動画**として評価される。見る生データ:

| 指標 | 何を意味するか | 目安(方向性) |
|---|---|---|
| **最初の3秒の離脱率** | フックの強さ。30%超の離脱＝弱いフック | 離脱<30% |
| **完視聴率** | 最後まで観たか（短尺ほど取りやすい） | 15秒未満で70%+ |
| **リプレイ率（再生÷ユニーク）** | 単体で最強の拡散シグナル。ループ設計で稼ぐ | 1.2+ |
| **初動1時間の最初の~100人** | ここの成績で配信拡大が決まる | 平均視聴~50%で次の波 |
| **保存率** | “あとで使う”＝実用シグナル | 5%+ |
| **DMシェア/sends** | Instagram最重要級（Mosseri明言の4信号の1つ） | 高いほど良 |
| **プロフクリック** | フォロー転換の入口（IG4信号の1つ） | 高いほど良 |

> Mosseri(2026/4)が示すIG Reelsランキング4信号 = **DMシェア・保存・視聴時間・プロフクリック**。**TikTokは完視聴率が最上位**（2026は70%+が目安／2024の50%から上昇）。
> ※参考: もし同じ素材をカルーセル(フォトモード)でも展開するなら、そちらは **STR(スワイプ進行)70%+・平均スワイプ4+・保存率** を別途見る（§5-5）。

## 3. アカウント継続再生のバズ要素（=長期資産・最小単位）

単体がバズっても、これが無いとフォロー転換せず資産化しない。

| 要素 | 最小ルール | 根拠/注意 |
|---|---|---|
| **ニッチ一貫性** | テーマを散らさない。隣接ニッチ追加は最低30日、理想60〜90日後 | 無関係3トピック超で**-45%リーチ罰**（TikTok 2026・方向性） |
| **投稿頻度** | **週3〜5本・高品質**。毎日・低品質より上 | 安定週次の価値が単発バズの4倍へ |
| **シリーズ化** | 固定キャスト×固定テーマ×**識別色/カバー統一**で“連載”に | フォロー転換の王道（`05`既出・一次） |
| **プロフ→次の一本** | 最終枚CTA＋固定キャラでプロフクリック誘発 | プロフクリックはIG4信号の1つ |
| **保存される回を定期投入** | チェックリスト/まとめ回（日本は保存文化） | 保存=実用シグナル＆後で再流入 |
| **“イジれる隙”** | キャラに欠点・口癖を明示→二次創作誘発 | ちいかわ型（日経xTrend）・本PJと相性◎ |
| **計測台帳** | 1投稿に 型/テーマ/尺/音源/カバー/キャラ/CTA/話数 をタグ付け | `post-ledger.csv`で自動化済。最初30〜50本は探索 |

> 補足: ちいかわは「Twitterの落書き→ほぼ毎日投稿→世界的IP」、シンプルで表情豊か＝**ショート/スライドに最適な造形**という海外評も。すーすーわーわーの方向性（簡素・表情・弱さ）と一致。

## 5. YourTIME. への応用（嘘・誇張なし）

### 5-1. なぜ我々が有利か（3点一致）
1. **フォーマット一致**: 「1本の動画内で静止画を内容に合わせて切り替える」＝**低コストで量産でき、カット＝注意リセットで維持率を作れる**型。撮影/3D不要、字幕＋音だけ。さらに同素材をカルーセルへ横展もできる（§5-5）。
2. **潮流一致**: Hyper-Utility/Cognitive Retention ＝ **誠実な実用・共感**が勝つ。**嘘・誇張なしが追い風。**
3. **キャラ資産一致**: 簡素・表情豊か・**弱さ/欠点を持つ**住人＝ちいかわ型のシリーズ適性。

### 5-2. すーすーわーわー 4コマ・テンプレ（起承転結 × 密輸 × 保存）

各コマ1.5〜3秒で自動切替。総尺フック含め10〜13秒目安。

```
[コマ1/起]  共感あるある（健康の話はまだしない）※最初の3秒=フック
            例: 「寝る前、子どもがなかなか寝ない問題。」＋住人の困り顔   (約3秒)
[コマ2/承]  住人が登場して小さく展開（文脈づけ・テンポUP）
            例: すー「ねむれないとき、あのね…」                       (約2秒)
[コマ3/転]  意外な気づき＝未病を“1滴だけ”密輸（ねじれ／カットで注意リセット）
            例: 「お口をふーっと閉じて鼻で3回すー。」(口呼吸→鼻呼吸の小ネタ) (約2.5秒)
[コマ4/結]  オチ＋小さな持ち帰り（保存したくなる）
            例: 「今日のすー: 寝る前ふー。」                          (約2秒)
[エンド]    エンドカード3秒（制作済）＋ 最終画が1コマ目へ戻るとループ→リプレイ↑
```
- 先頭に**スタートカード2秒**、末尾に**エンドカード3秒**（ともに制作済）を自動連結。
- コマ1（最初の3秒）に健康を出さない（`05`の鉄則）。健康は**転で1滴**まで。
- **コマ切替を音源ビートに合わせる**（DAZN音ロゴの頭・終盤アクセントと同発想）。
- **識別色＋固定キャラ**でシリーズ識別。最終コマ→1コマ目が自然につながる**ループ**を狙う。

### 5-3. 「嘘・誇張なし」を担保する作法（YourTIME原則 §8 と接続）
- **断定の医療効果を言わない。** 「絶対治る/必ず効く」禁止。「〜と言われています」「やってみた感想」「お口の体操のひとつ」程度の**穏当な言い回し**。
- **監修を通す。** 健康ネタは**出展者本人＋諏訪さん（歯科医）監修**（§8原則5）。台本段階で監修フラグ。
- **釣りサムネ/誇張フック禁止。** 共感・好奇心はOK、**事実を曲げる煽りはNG**（潮流的にも逆効果）。
- **PULL設計。** 「保存してね」「村で続き」までは可。通知爆撃・押し売りはしない（§8原則2/3）。
- **過剰演出の作為共感を避ける**（育児層は作為に敏感＝`05`既出）。

### 5-4. やってはいけない（このフォーマット固有）
1. コマ1（最初の3秒）から健康講座 → 即離脱。
2. 全コマが同じ構図/同じ秒数 → 飽き＝完視聴低下。カットで注意をリセットする。
3. コマ過多・1コマ長すぎで間延び（基本4〜6コマ／1コマ1.5〜3秒）。
4. トレンド音源の旬切れ/使い回し。
5. テーマ散らし（-45%罰）。**未病×遊び×村**に固定。
6. 一発バズで世界観を崩す → フォロー転換せずIP毀損。
7. 誇張・断定の健康効果 → 信頼毀損＋2026潮流に逆行。

### 5-5. 最初の実装ステップ（提案）
1. **4コマ・スクリプト雛形**を `06_台本生成ルール.md` 系に1枚追加（起承転結＋密輸＋保存＋監修フラグ＋**各コマの秒数指定**）。
2. **シーン切替レンダラ**を用意（コマごとに背景＋住人立ち絵＋字幕を差し替え→9:16・字幕焼き込み・**各コマ1.5〜3秒で自動カット**・音源ビート同期・スタート/エンドカード自動連結・**ループ可**）。`shorts/render.py` を拡張。
3. **第1弾テーマ5本**を“育児あるある入口×お口/お顔体操の1滴”で起票 → 監修 → 量産。
4. `post-ledger.csv` に **型/完視聴/リプレイ/最初3秒離脱/保存** 列で記録、最初30〜50本は探索。

> **横展（ワンソース・マルチ展開）**: 同じコマ素材を **(a) 動画(本命)** に加えて **(b) カルーセル(フォトモード)** へも書き出すと、2026優遇の2枠を1制作でカバーできる（“1アイデア3フォーマット”が2026の最大レバレッジ）。レンダラは静止画コマの集合なので、動画化とカルーセル化を**同一データから分岐出力**できる設計にしておく。

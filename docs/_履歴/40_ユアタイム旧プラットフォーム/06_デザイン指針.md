## ★ すわぷよ デザインDNA（この実装の見た目を"正典"とする）

> **決定（2026-07-01・本人）**: 抽象論でなく **すわぷよ本体の実装済みデザインをそのままガイドラインの基準**にする。
> キャラ選択画面／スタンプ（ブース）図鑑の雰囲気が正解＝**この感じをマップ・初回アンケート・図鑑すべてに一貫適用**する。
> 実装の正 = `src/styles/index.css`（トークン）＋ `src/styles/demo.module.css`（すわぷよ本体の見た目）＋ `CharacterSelectScreen`。

**すわぷよから抽出したDNA（新規画面は必ずこの5点を満たす）**

1. **ステッカー見出し** = 見出しは `M PLUS Rounded 1c` の `font-weight:900`。主役語はアクセント色＋**硬い1pxの影**（`.titleAccent`: `color:var(--color-accent); text-shadow:1px 1px 0 var(--color-accent-dark)`）＝シールを貼ったような立体。
2. **ピル型タブ／チップ** = 磨りガラスの土台に、**アクティブは無地オレンジ＋白文字＋オレンジのグロー影**（`.viewSwitchActive`）。マップのカテゴリフィルタ・アンケートの選択肢もこの型で統一。
3. **磨りガラスの白ピル/カード** = `rgba(255,255,255,0.75〜0.9)` ＋ `backdrop-filter:blur(8〜14px)` ＋ **2px の白枠**（`rgba(255,255,255,0.8〜0.95)`）＋ `--shadow-sm/md`。フラット白塗り禁止。
4. **オレンジの立体（タクタイル）ボタン** = 主CTAは `linear-gradient(180deg,var(--color-accent-light),var(--color-accent))` ＋ **下辺に濃色の影**（`0 4-5px 0 var(--color-accent-dark)`）→ `:active` で `translateY` して沈む（`.primaryButton`/`.stampBadge`）。
5. **村の背景を必ず透かす** = `body` に `village-bg.png` を `fixed` で敷く。各画面は磨りガラス越しに村が見える。ベタ塗り背景禁止。

**適用先（この雰囲気を横展開する画面）**
- **マップ** = カテゴリフィルタ＝ピル型チップ(DNA-2)、絞ると該当ブースを強調・非該当をディム。横長会場図は縦画面で**高さフィル(cover)＋横パン**（`MapViewport`）で違和感を消す。ピン/POI/ズーム/QRバーは磨りガラスピル(DNA-3)。
- **初回アンケート** = 「フォーム」でなく「村人との会話」。質問はステッカー見出し(DNA-1)、選択肢はピル/カード(DNA-2/3)、CTAはタクタイルボタン(DNA-4)。キャラが隣で反応する。
- **むらずかん（図鑑）** = §6.5＋§10。カード/スタンプは磨りガラス土台(DNA-3)、獲得はDNA-4の質感、見出しはDNA-1。密グリッド＋セット見出し＋シルエット。

以下 §0〜§8 は世界観の言語化、§9〜§14 はゲームUXの拡張。**このDNA5点が最優先の実装基準**。

## 0. 世界観の芯（これを外すと全部崩れる）

**「絵本の村に、そっと魔法の窓が開く」**。

- 舞台は手描きの温かい村イラスト（`village-bg.png`：青空・緑の丘・花畑・小さな家）。
- UIはその上に**浮かぶ磨りガラスの窓**。世界を隠さず、透けさせる。

- トーンは Duolingo(遊戯化・キャラ主導) × Finch(やさしい自己ケア) × Pokémon GO(地図の高揚) × visionOS(磨りガラスの奥行き)。**フラットで冷たいSaaSフォームの対極**。

## 2. マテリアル = 磨りガラス（最重要・これが「安っぽい」との分かれ目）

カード・パネル・ヘッダーは**フラットな白塗りにしない**。必ず磨りガラス:

```css
background: rgba(255, 255, 255, 0.78);
backdrop-filter: blur(14px);
-webkit-backdrop-filter: blur(14px);
border: 2px solid rgba(255, 255, 255, 0.85);
box-shadow: var(--shadow-lg);
```

- 背景は**村イラストを見せる**（`concierge`のrootで`village-bg.png`を敷く）。ベタ塗りのクリーム背景は禁止（＝旧実装の失敗）。
- 奥行きは「磨りガラスの層＋やわらかい影」で作る。ハードな1pxボーダーで囲わない。

---

## 3. 形 / 余白 / タイポ

- **角丸**: `--radius-lg`(20px)〜`--radius-xl`(28px)を基本。ボタン・チップは`--radius-full`(ピル形)。小さい8pxは使わない（角ばって見える）。
- **フォント**: `--font-primary`（M PLUS Rounded 1c）。見出しは`font-weight: 900`。丸ゴシックの丸みが世界観の要。
- **余白**: `--space-*`。詰め込まない。1画面1メッセージ。
- **文字影/縁取り**: 見出しアクセントは`text-shadow`で軽い立体（`.titleAccent`参照）。

---

## 4. モーション（framer-motion）

- **スプリング必須**（`type: "spring"`）。イージングのlinear/ease系は「安い」。跳ねる=生きてる。
- キャラは**反応する**：選択でうなずく/跳ねる、正解で喜ぶ。
- **`useReducedMotion`必須**：動きを減らす設定では移動アニメを止め`duration<=0.12`に。
- スタンプ/達成は**祝う**：confetti・光のリング・SE・カウンタbounce（実装済 `StampCelebration`）。

---

## 5. 遊戯化（Duolingo原則）

- 進捗は常に見せる（`n/総数`・プログレスバー）。
- タスク完了に**必ずご褒美の演出**。無音で終わらせない。
- アンケートは「フォーム」でなく「村人との会話」。質問はキャラのセリフ。

## 6. マップ（Pokémon GO / Apple Maps 水準）

- 会場図はベクター(`VenueMapSvg`)。ラスターJPGの埋め込み禁止（拡大で劣化）。
- **タップ対象はブースそのもの**。ランド選択の別ボタン(タブ)は置かない＝自由探索。
- ブースピンは**招くように脈打つ**（pulse）。獲得済みは金色＋チェック。
- 地図は指でパン/ピンチ。ズームコントロールは補助。
- 選択→**Airbnb/Apple Maps品質のbottom sheet**（ハンドル・キャラ・CTA）。

## 6.5 スタンプ帳 / むらずかん（スタンプであってトレカではない）

> 参考: ポケポケ(Pokémon TCG Pocket)のUI/UX分析（miteo氏 note `n9cea07b4cc91`）＝ニューモーフィズムでカードを主役に・温かい中間色・「見る→体験する」・運を操作している感覚。
> ヒューリスティック視点（同 `n6464ac6b972c`）＝マージ前のセルフレビュー観点として使う。

**採るのは"収集の満足と演出の質"。採らないのは"トレカのメタファ"**。ポケポケの温かい中間色・主役を立てる立体・祝う演出は輸入するが、**ホロ箔・レアリティ★フレーム・カードを3Dで傾ける表現は使わない**（＝トレカに寄りすぎ。ここはスタンプラリー）。

- **正体は「スタンプ台紙（絵本の見開き）」**。1ブース＝台紙の1マス。トレーディングカードではなく**押印メダル**。
- **時計→ロゴのインク演出が核**（YourTIMEの時計モチーフ）。未取得マスは**うすい時計の文字盤**、獲得で**文字盤が企業ロゴ/キャラのインク印**に"押されて"変わる。
- **未取得マス**=破線のスタンプ枠＋薄い時計＋「まだ」。埋めたくなる余白を見せる（図鑑のシルエット欲）。
- **獲得マス**=丸い**ハンコ印**（themeColorのインク・二重リングの縁・ごく僅かに回転して"押した感"・クリーム地に色付きグリフ）。ベタ塗りの派手カードにしない。
- **関与の深さ（寄った/聞いた/体験した）はレアリティでなく"印の格"で控えめに**：であった=1リング／はなした=2リング／たいけん=金リング＋星。ホロで光らせない。
- **演出（ポケモン水準の祝い）**：獲得の瞬間はプレス（大→着地のスプリング＋インクにじみ）＋リング光＋confetti＋SE＋カウンタbounce（`StampCelebration`流用）。台紙上のNEW印も"今押された"動きで着地。
- **詳細タップ**=印のクローズアップ（紙に押された寄り・名前/深さ/日付）。**3Dチルトはしない**（それはカード）。
- **収集の背骨**：`n/総数`＋進捗バー＋空きマス可視化＝集めたい。全集めで王冠＝すわぷよ隠しキャラ解放（`progressStore.unlocked_character_ids`）。
- 台紙・印は必ず`index.css`トークン（暖色・磨りガラス・村背景透け）。ティール/純黒/冷グレー禁止は全画面共通。

# v2 — ゲームUX層（図鑑・ミッション・Juice）

> 2026-06/07 の実践知(ブログ/コミュニティ/OSS/査読)を統合。出典は §14。
> ポケモンTCG Pocket(ポケポケ)・ポケGO・あつ森・Duolingo等の最新事例と、
> ゲーミフィケーションの学術知見(SDT/オーバージャスティフィケーション/ツァイガルニック)から導出。

## 9. デザイントークンを2層化する（世界観を"変数"にする）

現状の `index.css` 直値を、**Atomic（原色）→ Semantic（用途）** の2層に再定義する。UIは必ずSemantic経由で書く。

| 層 | 例 | ルール |
|---|---|---|
| Atomic | `--brand-orange-500:#F5A623` / `--brown-700:#4A3728` | 原色の定義。UIから直接使わない |
| Semantic | `--surface-glass` / `--text-on-warm` / `--dex-empty-slot` / `--dex-filled` / `--mission-progress` | UIはこれだけ使う。世界観の差し替えが1箇所で効く |

- **磨りガラスは"白"でなく暖色寄りの半透明**を基準に: `--surface-glass: rgba(255, 250, 245, 0.65)`。白磨りガラスより世界観が締まる。
- **blurは3段トークン**: `--blur-sm:8px` / `--blur-md:16px` / `--blur-lg:24px`。**md基準・1画面3〜4要素まで・アニメblur禁止**（LIFF起動1秒を守るため。glassは高コスト）。
- Claymorphism（暖色×大角丸×多層シャドウ）はこのブラウン世界観・丸ゴシックと親和。カード立体感の選択肢に。

## 10. 図鑑（むらずかん）— 密グリッド × セット × ミッション

> 現状「4枠固定・一覧性しょぼい」を、100枠級に耐えるコレクションUIへ。ポケポケの失敗を反面教師にする。

**構造（2層に分離）**
- **一覧＝密度優先グリッド**: 正方サムネ=**4〜5列** / 縦カード=**3列**（それ以上は絵柄が潰れる）。サムネ実寸は識別のため**64〜96pt四方以上**。
- **詳細＝情報＋演出**: タップで1枠を開く。名前/エリア/獲得日/深さ、印のクローズアップ。リッチ演出は詳細でだけ発火（一覧は静止サムネ＝省電力）。

**未取得の見せ方（最重要）**
- **未取得は必ずシルエット**（輪郭で好奇心）。**番号のみ表示は禁じ手**（＝ポケポケが批判された点）。
- 空き枠は「埋めたくなる穴」＝バインダーの空きポケット/枠装飾で"入れる場所"に見せる。§11の磨りガラス曇り窓メタファと統合。
- 使い分け: シルエット（輪郭）／`？`（形も伏せる特別枠）／グレーアウト（見えるが未所持）。

**セット分類と進捗（レア度に頼らない差別化）**
- 図鑑を**村のエリア/テーマで"島"に分割**。**スティッキー見出し**（エリア名＋そのセット進捗 `12/30`）を上部固定。
- 進捗は**セットごとにリング**（「1エリア=1輪、閉じる=完成」＝言語不要で低年齢に伝わる）。全体1本のバーだけにしない。
- **分母は必ず到達可能に**（全ブース到達で必ず100%になる設計。取り逃しで永久に埋まらない枠を作らない）。
- 100枠級では**「未所持のみ」フィルタ／密度トグル（画像大⇄リスト）**をつける（あつ森方式。子ども=画像大、親=リスト密）。

**ミッション（"○○を○種あつめろ"）**
- **「ミッション」と明示ラベルして見せる**（隠れ報酬でなく可視化された達成ラダー）。提示は**4枠前後**。
- **報酬は事前開示（reveal first）**。何がもらえるか先に見せる。
- **endowed progress**: 受付時点でスタンプを**1〜2個先付与**（`2/30 スタート済み`から始める＝完遂率が上がる）。
- 2層: 当日デイリー（例「3ブース回る」）＋上位クエスト（例「健康エリアを全部」）。
- 「あと1個でこの島コンプ」の**穏やかな未完了提示**でツァイガルニック緊張を活かす。ただし**煽り(near-miss乱用)は避け、必ず完了体験で解放**（[[feedback_tantan_rule]]と整合）。

## 11. 磨りガラスを"獲得の器"に（世界観×収集の統合）

- 図鑑の**空きスロット＝曇った磨りガラスの窓**、**獲得＝窓が晴れて村の住人が現れる**というメタファに再定義。
- シルエット→フルカラーの遷移が世界観と一致し、収集動機（ツァイガルニック）とデザインが一体になる。
- トレカのホロは不採用のまま。**所有感は「枠デザイン・エリア軸・展示（お気に入りだけ並べる）」で作る**（光沢でなく"物語"で差別化）。

## 12. Juice（絵本の静けさを壊さない範囲で"生命感"を足す）

- **"1個ゲット"の瞬間を最優先で磨く**（頻出する moment を磨く＞稀なイベントを豪華に）。
  - スケール**overshoot**（`1.0→1.25→1.0`・spring: stiffness高/damping低）＋少量パーティクル＋スコア加算＋短い音（値に比例しピッチ上昇）＋触覚。
  - **冗長フィードバック**（視覚＋音＋触覚を束ねる）で「効いた感」。
- **粒子は村の世界観に置換**: 紙吹雪でなく**落ち葉/花びら/星**。confettiは**本当に祝う価値のある瞬間だけ**、数控えめ。
- **やり過ぎ禁止**: 画面を粒子で埋めない（どの反応がメカニクス上重要か学習できなくなる）。絵本の静けさを壊さない。
- **物理量はspring / opacity・colorはduration＋ease-out**。UI確定はdamping高で即収束、獲得ポップはovershoot。
- **触覚の制約**: `navigator.vibrate()`はAndroid可・**iOS Safari非対応**。iOSは feature detection＋フォールバック必須（将来的にswitch要素ハック等）。
- **`prefers-reduced-motion` を発火前に必ずチェック**（confetti/大きな移動を静的に）。

## 13. 子ども＋親の前提（世界観の犠牲でなく"わかりやすさ"の延長）

- **タップ標的は実寸 ≧ 20mm（≒75px）**（大人44/48ptより大きく。幼児は7mm標的を約30%外す）。
- **破壊/外部操作（課金・設定・外部リンク）は親ゲート**（長押し2秒等、幼児が偶発突破しにくい方式）。
- 未就学児は非識字前提＝**音声＋視覚＋アニメの複数モード**。読める子には**ふりがな/短文**。1画面1タスク。
- **色だけに頼らない**: 所持=フルカラー／未所持=シルエット／完了=リングが閉じる、を**色以外の手がかりでも冗長化**（WCAG非テキスト3:1）。
- **親子共同利用**: 「今日どうだった?」と会話を誘発、成果を親に見せる導線、親向けの短い声かけヒント（relatednessを満たす）。

## 13.5 実装スタック指針（LIFF性能）

- **一覧の仮想化**: まず CSS `コンテンツ-visibility: auto`（2025-09 全主要ブラウザBaseline・`contain-intrinsic-size`必須）。足りなければ **TanStack Virtual**（可変高グリッド）/ 固定格子は react-window。
- **アニメ**: 基本は auto-animate + canvas-confetti（WebWorker対応）。凝った画面だけ Motion/GSAP を**動的import**（全面Motionはbundle重くLIFF起動に不利）。
- **図鑑UIの土台**: Trophy UIキット（MIT・Badge/Grid/progress ring/unlock animation）を参考に自作（コレクション特化の高品質OSSは無い＝自作前提）。
- **LIFF制約**: 起動後**1秒以内に初回表示**・トップにリダイレクトを置かない（[[project_suwapuyo_fuwafuwa]]のLIFF強制ログイン修正と同根）。両OS実機必須。画像はWebP/AVIF＋`loading="lazy"`。

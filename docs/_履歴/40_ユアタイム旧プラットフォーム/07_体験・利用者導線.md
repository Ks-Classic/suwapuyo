# 07 — 体験設計・ユーザージャーニー・ユーザーストーリー（最優先ドキュメント）

> 作成: 2026-07-01 ／ 位置づけ: **すべての設計の背骨**。仕様(01/03)・デザイン(06)・TODO(02)はこの体験目的に奉仕する。
> 対象: YourTIME（歯科・未病イベント / 2026-08-02 東京流通センター）の「村の案内所」と、その前後をつなぐ体験全体。

---

## 0. 北極星（これを外したら全部無意味）

**「来場前・来場中・来場後を通じて、健康を"楽しく・深く・おもしろく・本質的に"体験してもらう」——これがなにより最優先で最重要。**

- **主役はリアルな体験**：ブース、そこにいる人、遊び、驚き、親子の会話。**アプリは主役ではない**。
- **アプリ＝触媒（catalyst）**：リアル体験を **壊さず**、案内し・記憶に刻み・つなぐことで、目的（健康の本質を体験する）を **より深く** 達成する手助けに徹する。
- **健康の本質は「説教」でなく「遊びと発見と物語」で伝わる**。正しさを教え込むのではなく、面白がっているうちに一歩踏み出している——それが未病の村（SOV: Suwa Oral Village）の理念と一致する。

> 諏訪さんの理念：医院を「治療の場」→「遊びに行ける場」へ。来場者＝村の村民。今回の体験は、その村おこしの最小プロトタイプ。

---

## 1. 体験を壊さないための原則（アプリ設計の憲法）

アプリは"できること"を足すほど体験を薄める危険がある。以下は **やらないこと** を含む憲法。

1. **登録を強制しない・迷子を作らない**：地図やブース紹介は登録なしでも見られる。特典側で連携を誘う（"登録しないと地図すら見られない"は禁止）。
2. **画面に沈めない**：来場者が下を向いてスマホを触り続ける設計にしない。アプリは「次どこ行く？」の一瞬と「覚えておく」の一瞬だけ介在し、顔を上げさせる。
3. **親子の会話を奪わない**：アプリが答えを与えるのでなく、「これ何だろうね」と親子で話す余白を残す。共同利用（Joint Media Engagement）を前提に、成果を親に見せる・声かけのヒントを添える。
4. **説教しない・断定しない**：健康・医療の効果を断定せず（薬機法/医療広告GL）、"正しさ"の押し付けをしない。敵キャラ（酸化・糖化・炎症）等は「悪役」として面白がる装置に留める。
5. **順位を金で売らない**：露出順位はスポンサー額で買えない。お金は露出の"周り"（制作・村スポンサー）を流す。
6. **記念であって通貨でない**：スタンプは行動の対価（外的報酬）でなく、**進捗の可視化と記念**。楽しさを外部通貨化して内発的動機を壊さない（オーバージャスティフィケーション回避）。
7. **やり過ぎない演出**：絵本の静けさを壊さない範囲でJuiceを足す。粒子で画面を埋めない。`prefers-reduced-motion` を尊重。

## 2. 三幕構成の体験設計（Before / During / After）

「健康を楽しく深く体験する」を、来場の前後を貫く一本の物語として設計する。

### 幕1｜来場前（Before）＝ "行きたい" と "少しの種" を作る

- **狙う感情**：わくわく／このイベント面白そう／子どもに体験させたい。
- **健康の芯**：まだ教えない。**世界観（村・キャラ・遊び）への入口**だけ開き、「健康って堅苦しくない」という予感を配る。
- **タッチポイント**：
  - ショート動画（ススワワー紹介／未病啓もう。見る人＝来場見込みの保護者）。
  - LINE「村の案内所」友だち追加（前日オープン）。
  - **すわぷよ 事前オープン**：スマホゲームなのに遊ぶほど健康になる＝スクリーンタイムの罪悪感を反転。出展者の専門を体操監修に乗せ、遊びの中に健康の種をまく。
- **アプリの役割**：期待醸成の器。まだ情報を詰め込まない。「当日、村で会おう」。

### 幕2｜来場中（During）＝ 発見・遊び・出会い・記憶

- **狙う感情**：わ、こんなブースがある／やってみたい／この人の話おもしろい／集まってきた。
- **健康の芯**：**体験を通じて本質に触れる**。人（専門職）と出会い、遊び、手を動かす。知識でなく体験が残る。
- **体験のループ**：
  1. **探索**：マップで「気になる」を見つける（カテゴリで絞ると該当ブースが強調される＝迷わない）。横長会場図も縦画面で自然に見える。
  2. **出会い**：ブースへ行く。**リアルが主役**（人・体験・遊び）。
  3. **刻む**：QRでスタンプ。**関与の深さを自分で選ぶ**（寄っただけ／説明きいた／体験した）＝主体性。時計→ロゴのインク押印で「行った証」が記憶になる。
  4. **次へ**：むらずかんの空きが「次どこ行こう」を静かに促す。ミッション（"○○を○種あつめよう"）が探索を物語にする。
- **アプリの役割**：**案内（次どこ）と記録（覚えている）に徹する**。長く触らせない。顔を上げさせる。
- **会場アナウンス**：全体への呼びかけ（ステージ開始等）を、体験を邪魔しない一過性のバナーで。

### 幕3｜来場後（After）＝ 持ち帰りと、健康の一歩

- **狙う感情**：楽しかった／また行きたい／うちでもやってみよう／あの医院また会いたい。
- **健康の芯**：**日常に一歩持ち帰る**。イベントの熱を、家庭のケア・かかりつけとの関係につなぐ。
- **タッチポイント**：
  - **むらずかん＝思い出と学びの結晶**。集めたブース＝出会った人・体験の記録。見返すと"あの日"が蘇る。
  - **村の案内所（LINE）**＝継続接続。押し付けない未病tips（週1上限・opt-inは良い体験の直後にユーザー起点で）。
  - 気になった医院／専門職への"次の一歩"（かかりつけ・相談）を、当事者が選べる形で。
- **アプリの役割**：記憶の器＋ゆるいつなぎ。**配信過多で嫌われない**（LINEブロック最多理由＝配信過多）。村が握り、出展者に一斉配信の蛇口は渡さない。

## 3. ペルソナとユーザーストーリー

> 形式：**As a〈誰〉, I want〈何〉, so that〈なぜ＝得たい体験・価値〉。** アプリはこの "so that" に奉仕する。

### P1. 親子来場者（親＋未就学児〜小学生）＝ 最重要ユーザー

- As a 子連れの親, I want 受付でサッと入って子どもと会場を回りたい, so that **手続きでなく体験に時間を使える**。
- As a 子ども, I want ブースで遊んで・スタンプを集めたい, so that **楽しくて夢中になれる**（結果として健康に触れている）。
- As a 親, I want 子どもが何に反応したか分かる/家で続けられるヒントがほしい, so that **イベントの熱を家庭のケアにつなげられる**。
- As a 親子, I want アプリでなく "その場の体験・会話" を主役にしたい, so that **一緒に過ごした時間が思い出になる**（＝アプリは邪魔しない）。

### P2. 専門職来場者（歯科/衛生士/療法士/管理栄養士 等）

- As a 専門職, I want 自分の興味領域のブースを効率よく回りたい, so that **学び・つながりを持ち帰れる**（カテゴリフィルタが効く）。
- As a 専門職, I want 未病・多職種連携の"横のつながり"を体験したい, so that **縦割りを越える実感を得る**（諏訪さんが最重視）。

### P3. 出展者（ひとり経営の専門職クリニック・発信は苦手）

- As a 出展者, I want 自分のブースに来場者を送客してほしい, so that **当日の出会いが増える**（マップ・紹介カード・タップ送客）。
- As a 出展者, I want 来場者像や関与（寄った/聞いた/体験した）を後から知りたい, so that **次につながる手応えを得る**（企業レポート＝将来）。
- As a 出展者, I want 発信の負担なく村の世界観に乗りたい, so that **手が回らなくても主役になれる**（つなやすの運用支援＝継続商品への入口）。

### P4. 主催／諏訪さん（村長・理念家）

- As a 村長, I want 来場者が村の村民として体験し、会期後もつながってほしい, so that **単発イベントが村おこしの起点になる**。
- As a 村長, I want 広告でなく "出展者を主役にするコンテンツ" でありたい, so that **運営の疲弊を癒やし理念を汚さない**（感動で動く）。

## 4. 詳細ユーザーフロー（アプリが介在する接点）

> 記法：各ステップ＝〈来場者の行動〉→ **アプリの役割** ／ *UXを壊さない工夫*。

### 4.1 来場前

1. ショート動画を見る → **興味の種**／*アプリはまだ出さない*。
2. LINE友だち追加（任意） → **前日オープンの入口**／*登録しなくても当日困らない*。
3. すわぷよで遊ぶ → **遊びの中の健康の種**／*ゲームはゲームとして面白い（教育臭を出さない）*。

### 4.2 当日オンボーディング（受付〜案内所起動）

1. 受付QRで友だち追加 → **村の案内所LIFF起動**／*1秒以内に表示・トップにリダイレクトを置かない*。
2. ようこそ（1枚） → **世界観のあいさつ**／*スキップ可*。
3. **家族構成アンケート（体験の主役UI）** → **"あなたの村での過ごし方"の把握**／*キーボードゼロ・1タップ自動前進・今の子だけ大きく・上部に家族プレビュー。No ストレス5条件*。
4. かんたんチュートリアル1-2枚 → **地図とスタンプの使い方**／*読まなくても直感で分かる*。
   - **endowed progress**：ここで**スタンプを1〜2個先付与**（`2/30 スタート済み`）＝集めたくなる。

### 4.3 会場をめぐる（コアループ）

1. マップを開く（cover表示・横パン） → **探索の起点**／*登録なしでも見られる／横長会場図が縦画面で自然*。
2. カテゴリで絞る（歯・お口／こども／…） → **該当ブースを強調・非該当をディム**／*絞っても他が消えず、存在は残る*。
3. ブースピン／POIをタップ → **紹介カード（医療広告セーフ）**／*断定しない・行きたくなる一言*。
4. ブースへ行き、人と出会い、体験する → **アプリは引っ込む**／*ここが主役。顔を上げる*。
5. QRを読む → **スタンプ画面（名前＋深さ3ボタン）**／*寄った/聞いた/体験したを自分で選ぶ＝主体性*。
6. スタンプ獲得（時計→インク押印＋祝い） → **"行った証"を記憶に**／*~600msの一瞬・やり過ぎない*。
7. むらずかんを見る → **進捗と次の目標**／*空きが次を促す・ミッションが物語にする*。

### 4.4 来場後

1. むらずかんを見返す → **思い出・学びの結晶**／*見返すだけで価値・通知で追い立てない*。
2. 村の案内所（LINE） → **ゆるい継続接続**／*週1上限・opt-inは良い体験直後にユーザー起点*。
3. 気になった医院への次の一歩 → **当事者が選ぶ**／*送客はするが押し売りしない*。

## 5. アプリが体験を"深める"接点マップ（壊さず・深く）

| 体験（リアルが主役） | アプリが深める手助け | 壊さないための線引き |
|---|---|---|
| ブースで人と出会う | マップで見つけやすくする／紹介で行きたくする | ブースにいる間はアプリを引っ込める |
| 遊ぶ・手を動かす | すわぷよで前後も遊べる／体操幕間 | 教育臭・説教を出さない |
| 健康に触れる | スタンプの深さで"どれだけ関わったか"を自分で刻む | 断定・診断・効果保証をしない |
| 集める楽しさ | むらずかん・ミッション・endowed progress | 外部通貨化しない（記念に留める） |
| 親子で過ごす | 成果を親に見せる・声かけヒント | 会話を奪わない・下を向かせ続けない |
| 会期後もつながる | 村の案内所でゆるく接続 | 配信過多で嫌われない・蛇口を出展者に渡さない |

## 6. 体験の成功指標（質を測る。量KPIより上位）

- **楽しかった / また来たい**（親子）＝ 体験の熱量。
- **健康に一歩踏み出した**（家でケア・かかりつけ相談）＝ 本質への到達。
- **親子・来場者同士・出展者との会話が生まれた**＝ 村（関係）の芽。
- **出展者が"来てよかった"と感じた**（出会い・手応え）＝ 三方良しの"世間よし"。
- （補助的に）むらずかん収集率・ミッション達成・タップ送客数。**ただし数値は体験の代理でしかない**。

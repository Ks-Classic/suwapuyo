## 0. これは1本のループ（バラ機能ではない）

```
当日：ふわふわランドで絵を描く（会場）
  └→ ④ 自作キャラ「相棒」としてすわぷよに持ち帰り（QR/コード引換）
        └→ 家ですわぷよ起動（自分の絵に会いたい）＝起動動機
              └→ ① 遊ぶ → 1分ごとにお口/未病体操の幕間
                    └→ ② 体操を重ねる → 隠しキャラ／イベント解放（コレクション）
                          └→ ③ 体操は出展者の専門監修＝企業ロゴ紹介に触れる
                                └→ 節目で YourTIME告知・インスタ・LINE登録へ送る
```

**核は④**。「自分の絵に会える」がアプリ起動の理由になり、起動さえすれば①②③が後ろに連なる。④が弱いと全部死ぬ＝最優先で本物にする。

## 1. ④ 自作キャラ「相棒」（最優先・継続導線の核）

### 1.1 体験
- ふわふわランド（会場）で描いた**自分の絵だけ**が、すわぷよに「相棒」として常駐する。
- 盤面の横/上でふわふわ浮いて応援し、ぷよを消すと喜ぶ（待機/歓喜の2モーション）。
- **他人の絵は出さない**＝公開なし・モデレーション不要・プライバシー最小（顔は撮らない／作品のみ／下の名前だけ任意＝`../10_ふわふわランド/90_参考資料/00_旧企画・戦略/05_諏訪さん向け提案.md` §6を踏襲）。

### 1.2 どうやって持ち帰るか（2アプリの橋渡し）
すわぷよ（`30_すわぷよ旧仕様`）とふわふわランド（`10_ふわふわランド`）は**同じリポ・同じSupabase**を共有できる。描いた絵は既に `artworks`（テーブル＋Storage）に入る設計。橋は2通り、**QR引換を主**にする。

| 方式 | 仕組み | 採否 |
|---|---|---|
| **QR/引換コード（主）** | 描き終わると絵に紐づく短いコード or QRを画面表示/印刷。家ですわぷよでコード入力 → 自分の絵が降ってくる | ◎ 会場ネット不安定でも持ち帰れる（`01`§9オフライン制約と相性良） |
| LINE紐付け（必須） | LINE公式アカウントを友だち追加し、LIFFで利用者を識別してすわぷよを開く | ◎ すわぷよの公開入口・計測・継続配信の基盤。作品QR引換は後続フェーズ |

### 1.3 実装メモ
- すわぷよに**引換画面**（コード入力 or QR読取）を新設 → `artworks` から1件取得 → 表示用に縮小（`07`§4の display 派生と同じ思想・最大1024px）→ 端末ローカル（IndexedDB）に保存し、以後はオフラインでも相棒が出る。
- 相棒スプライトは `01_旧仕様.md` の PixiJS 描画に「応援レイヤー」を1体足す形（盤面ロジックには関与しない＝安全）。
- 取得できない/未引換のときは、デフォルト相棒（既存キャラ）が出る＝引換は任意。

### 1.4 未決
- **D-1**: 相棒は1体固定か、複数描いたら切替できるか（デモは1体固定で十分）。
- **D-2**: 相棒がゲームに影響するか（純粋に応援だけ＝推奨／消滅数ボーナス等のバフを持たせるか）。

## 2. ① 体操幕間（お口・未病体操）

### 2.1 トリガー
- **1分ごと**（`08`§開催前の既定）。デモは「**1分経過 or Nぷよ消した のどちらか早い方**」で幕間に入る（Nは調整可・初期20）。
- 幕間はスキップ可（強制しない＝PULL原則）。ただし**体操するとカウントが進む**＝やる動機を②の解放で作る。

### 2.2 体操の種類（部位）＝出展者の専門にマップ
| 部位 | 体操例 | 監修にハマる出展者 |
|---|---|---|
| お口 | 「あ・い・う・え・お」大きく口を動かす | 歯科・歯科衛生士 |
| ベロ | ベロを上下左右「べー！」 | 言語聴覚士（ST）・歯科 |
| 瞬き | ぎゅっと閉じてぱっと開く | 眼科系 |
| 首・肩 | ゆっくり回す | 理学療法士（PT） |
| 呼吸 | ふーっと長く吐く | 助産師・呼吸/姿勢系 |

> 部位は出展者の顔ぶれで増減。1部位＝1出展者の監修枠＝③のロゴ紹介に直結。

### 2.3 安全設計（`08`§開催前 踏襲）
- **カメラ不要**。キャラのお手本アニメ＋タイマー＋カウントだけ。
- 軽い・オフラインOK・個人情報を取らない。
- 医療内容は出展者本人＋諏訪さん（歯科医）監修（`01`§7）。効果効能を断定しない（「未病に効く」等の標榜回避）。

### 2.4 カウント永続化
- 端末ローカル（localStorage/IndexedDB）に**部位別カウンタ**と**プレイ日**を保存＝匿名・ログイン不要。
- LINE登録（任意）した人だけ、クラウド同期で機種変・持ち越し可（おまけ）。

## 3. ② 隠しキャラ／イベント解放（ツムツム的コレクション）

世界的バズゲー（ツムツム/ポケGO/ポケキャンプ）の共通項＝**集める×毎日来る理由×小さなサプライズ**。すわぷよはキャラが多い（既存16体＋）＝そのままコレクション資産。

### 3.1 解放トリガー＝3点組合せ（2026-06-27決定）
| トリガー | 中身 | ねらい |
|---|---|---|
| **A. 体操の累計回数** | 部位別の累計（例: お口10/30/50回でレア解放） | 未病体操を繰り返す＝企画の本義に直結 |
| **B. ログイン継続日数** | 連続プレイ日数 streak（3日/7日で限定キャラ・背景） | 毎日起動する理由＝リテンション最強 |
| **C. 部位コンプ（全種制覇）** | 全部位を1回ずつ達成で“村長キャラ”等の特別解放 | 全出展者の紹介(③)に満遍なく触れさせる |

> スコア/連鎖での解放は**今回は不採用**（体操＝未病と直結しないため主役にしない）。将来オプション。

### 3.2 イベント（解放の瞬間）
- 紙吹雪・限定セリフ・新キャラお披露目の演出。
- その節目に**YourTIME告知 / インスタ / LINE登録**のバナーを自然に1枚挿す＝③(a)への送り口。PUSHでなく「ごほうび画面に出てるだけ」。

### 3.3 データ（端末ローカル）
```
suwapuyo_progress {
  taisou_counts: { mouth: 12, tongue: 5, blink: 3, neck: 0, breath: 1 },
  login_days: ["2026-08-02","2026-08-03","2026-08-05"],
  streak: 1,
  unlocked: ["chara_rare_tooth","bg_streak3"],
}
```
- LINE登録者はこのJSONをクラウド同期（任意）。

### 3.4 未決
- **U-1**: 解放テーブル（どの回数で何が出るか）の具体値＝デモで触りながら調整。
- **U-2**: streak が途切れた時の救済（1日見逃しチケット等）入れるか。

## 4. ③ 企業ロゴ紹介（すわぷよ内・`07`の器を移植）

### 4.1 方針
- `../10_ふわふわランド/90_参考資料/07_スポンサータップ表示仕様.md` の **`sponsors[]`＋`SponsorPopup`（動画/画像カルーセル＋CTA）＋`track()`** を**すわぷよに移植**。coralup特例にせず**同じ器＋データ差し替え**（PdM/Eng収束済の思想）。
- 出し場所＝**体操幕間**。「この体操は ◯◯歯科 監修」カード＋ロゴ/キャラ。タップ→紹介ポップアップ（画像/動画）→CTA（ブース/LINE/インスタ）。
- 「広告」と呼ばない＝**出展者を主役にする紹介コンテンツ**＝デジタル版・健康ハンドブック（`04`§更新で“良い方の有料掲載”としてOK確定）。

### 4.2 医療広告ガード（`01`§7 / `04`）
- 効果効能の断定・ビフォーアフター・体験談を避ける。
- PR/紹介表記を明示（ステマ回避）。出展者本人＋諏訪監修。
- 特典/誘引を載せる場合は治療誘引にならないGIVEに限定（来院割引等はNG寄り）。

### 4.3 計測（出口は`09`）
- `track("taisou_sponsor_view", exhibitorId, {bodyPart})` / `track("popup_open"...)` / `track("cta_click"...)` を**呼び場所だけ**用意（中身は`09`のレポート基盤に合流。初期no-op可）。
- これが Phase1「送客ダッシュボード＝課金の心臓」（`01`§8）の弾になる。

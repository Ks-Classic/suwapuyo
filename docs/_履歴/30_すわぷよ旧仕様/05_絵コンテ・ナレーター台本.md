> 最終更新: 2026-06-27 ／ ステータス: **v1（感動ビートの正・自己ループ済み）**

## 0. この文書の使い方・原則

- **絵コンテ（Part A）**＝各カットの「画・動き・尺・イージング・SE・ねらい」。Codexはこの尺で実装。
- **セリフ脚本（Part B）**＝わーわー村長＆もぐぴよの**実際の言葉**。短く・弾む・**読めない子でも木幡が読み上げれば伝わる**。
- 感動の3原則（全カット共通）:
  1. **ためがあって、ごほうびが来る**（予兆→降臨／プレイ→大喜び）。
  2. **“自分の”が主語**（自分の絵・自分のプレイ・自分のお口）。
  3. **言葉は最小、絵で伝える**（文字依存にしない＝子ども安全）。

# Part A — 絵コンテ

> 記法: `[ ]`＝画面、`☁/✨/💛`＝効果、`◇`＝相棒（自分の絵）、`■`＝ぷよ盤、`(t=…)`＝開始からの時間。

## A-1. 降臨シーケンス（初回召喚・★感動①）

> **発火**: A-0 で**自分の絵を選んで確定**した時（初回のみフル／2回目以降は省略）。村キャラ選択時は降臨せず“軽い登場”。

**F1 — 予兆（t=0〜300ms）**
```
        ☁  ✨            村長ふきだし: 「それっ…」
   [■■■■■■]            画面: 盤面の上空に やわらかい影＋キラ粒子
   [■■■■■■]            動き: 影がふわっと現れ、キラが舞い降りる予感
   [■■■■■■]            ease-out / SE: ふわ〜（軽い上昇音 or 無音の“ため”）
```
ねらい: **「何か来る」と思わせる“ため”**。いきなり出さない。

**F2 — 降下（t=300〜1100ms / 800ms）**
```
        ◇   ← 自分の絵が上空から         動き: ◇が上→定位置へゆっくり降下
   [■■■■■■]                            左右に微揺れ（生きてる感）
   [■■■■■■]                            cubic ease-out / 透過PNG
   [■■■■■■]
```
ねらい: **「自分が描いた絵だ」と認識する時間**を与える（速すぎない）。

**F3 — 着地（t=1100〜1350ms / 250ms）**
```
   [■■■■■■]                            動き: ◇が着地でスカッシュ→ストレッチ（ぽよん）
   [■■■■■■]                            back ease-out
   [■■■■■■]  ◇←ぽよん                  SE: 着地ポップ（既存SoundFX）
```
ねらい: **物理の“ぽよん”で生命を宿す**。ここで初めて音が鳴る＝気持ちいい。

**F4 — 名乗り（t=1350〜1950ms）**
```
   [■■■■■■]      ╭─────╮              ふきだし: 「あそぼ！」＋✨
   [■■■■■■]      │あそぼ！│            600ms表示→fade
   [■■■■■■]  ◇ ✨╰─────╯              声なし（村長/木幡が読み上げ可）
```
ねらい: **相棒が“こっちに話しかけた”瞬間**＝関係が始まる。固定人格は持たせない（自分の絵だから）＝言葉は超短い1語。

**F5 — 常駐（t=1950ms〜・ループ）**
```
   [■■■■■■]                            動き: ◇が定位置でゆっくり上下bob（sin）
   [■■■■■■]  ◇～                       待機モーション
   [■■■■■■]
```
ねらい: **居てくれる安心**。以降のプレイのベース。

**F6（2回目以降）**: F1〜F4を省略し、最初から **F5（常駐bob）**。毎回フル演出はくどい＝初回だけ特別（`first_summoned_at`）。

> 実装尺まとめ: 予兆300 / 降下800 / 着地250 / 名乗り600 ≒ **全体 約1.95秒**。テンポ良く、でも“認識→ぽよん→あそぼ”の3拍が立つ。

## A-2. 喜びシーケンス（プレイ反応・★感動①）

**E1 — ぷよ消し（毎回・小）**
```
   [■■□□■■]  ◇↑   消した瞬間: ◇が小ジャンプ（squash→pop 120ms）
   [■■■■■■]       SE: 既存pop。ふきだしなし
```
ねらい: **自分の手 → 相棒が反応**、の即時フィードバック（クセになる小気味よさ）。

**E2 — 連鎖2以上（大）**
```
   ✨ ╭───╮
   [■■│すごい!│■]  ◇⤴✨   ◇が大ジャンプ＋スケールpop＋キラ
   [■■╰───╯■■]           ふきだし「すごい！」／既存chain SE（連鎖数で強く）
   [■■■■■■]
```
ねらい: **がんばり（連鎖）ほど、相棒が大きく喜ぶ**＝努力が祝われる。

**E3 — デバウンス（連鎖中）**
```
   1連鎖の中で消滅が多発しても、大喜びは“その連鎖につき1回”に集約。
   → tween過多のガクつきを防ぎ、喜びが“決まる”瞬間を作る。
```
ねらい: **演出が散らからず“ここぞ”で決まる**（過剰演出は逆に冷める）。

## B-3. セリフ運用の原則（子ども・会場配慮）
- **読めない子**: セリフは“飾り”。**口ピクト＋もぐぴよの動き**が本体（§4.3）。木幡が読み上げれば足りる。
- **短く**: 1ふきだし〜15字。長い説明をしない。
- **こわくしない**: 健康ネタは「気づき」だけ（bible conceptGuardrails）。断定・診断ワード禁止。
- **スキップ尊重**: ナビは飛ばせる。急かさない。

## B-4. 予備・バリエーション（飽き対策／任意）
- 描き終わり: 「ナイス〜！」「いい色だね！」

# Part C — セルフレビュー（感動チェック＋ループ跡）

「1=絵コンテ／3=村長脚本」を感動レベルに上げるため、以下の基準で自己採点し、足りない所を埋めた（ループ）。

| 感動の条件 | 満たし方 | 判定 |
|---|---|---|
| ため→ごほうび | 降臨に予兆(F1)→ぽよん(F3)、プレイに連鎖→大喜び(E2) | ✅ |
| “自分の”が主語 | 自分の絵が降臨／自分のプレイで喜ぶ／自分のお口 | ✅ |
| 言葉は最小・絵で伝える | 名乗り「あそぼ！」1語／口ピクトで非言語化 | ✅ |
| 世界観の真実 | わーわー＝村長・もぐぴよ＝口腔育成、bibleのemotionKey/speech準拠 | ✅ |
| 過剰演出にしない | 連鎖デバウンス・初回だけ降臨フル | ✅ |
| 子ども安全 | 声なし・カメラなし・断定なし・読めなくてOK | ✅ |

### ループで埋めた点（v0→v1）
- 降臨を「小ジャンプ」だけ→**6カットの尺・イージング・SE・“ため”**まで（F1予兆を追加＝ここが効く）。
- 喜びに**デバウンス**を明文化（散らからせない）。
- 体操を**もぐぴよの実セリフ＋口ピクト同期**まで（読めない子の壁を絵で越える）。
- 村長を**10ビートの実セリフ脚本**に（通しの物語が言葉で立つ）。

### まだ build / 仕上げで決まる（ドキュメントの限界）
- 実際の**イージングの気持ちよさ**（数値は当たり、最終は触って微調整）。
- **SEの選定**（既存音の割り当て。音1つで印象が変わる）。
- もぐぴよ/相棒の**簡易モーションの質**（静止PNGをどれだけ生かすか）。
- → これらは Codex実装後の**モーション/音の微調整パス**で詰める（P1）。

> 結論: 絵コンテ(1)・村長脚本(3) は**感動を“設計”できた**。残るは実装の手触り。次は ①このままCodexへ ②音/モーションの微調整方針も先に固める ③別エージェントで批評、のいずれか。
```

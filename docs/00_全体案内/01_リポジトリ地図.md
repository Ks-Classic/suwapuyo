# リポジトリ地図

> 最終更新: 2026-07-20

## 現行の全体像

1つのVite + React + TypeScriptアプリに、利用者向けのすわぷよ体験と、会場向けのふわふわランド運営機能が同居する。

| 境界 | 実装 | 現行SSoT |
|---|---|---|
| 利用者向け | `src/app/`ほか | `docs/70_すわぷよ・ユアタイム統合仕様/` |
| 会場向け | `src/fuwafuwa-land/` | 同上 |
| SNS静止画・動画 | `.agents/skills/suwapuyo-sns-image/`、`.agents/skills/suwapuyo-sns-video/` | `docs/80_制作過程/11_SNS静止画・動画共通制作契約.md` |

## 文書の読み分け

| 場所 | 状態 | 用途 |
|---|---|---|
| `00_全体案内/` | 現行 | 全体地図 |
| `10_ふわふわランド/` | 現行の案内 | 統合仕様への入口。旧設計は`90_参考資料/`に隔離 |
| `20_事業/` | 現行 | 事業方針、医療広告・コンテンツ方針 |
| `50_デザイン戦略OS/` | 参考 | 設計戦略の再利用資料 |
| `70_すわぷよ・ユアタイム統合仕様/` | **現行SSoT** | 要求、要件、体験、設計、テスト、運用 |
| `80_制作過程/` | 現行 | キャラクター、SNS、証拠、制作運用 |
| `_履歴/` | 廃止済み | 旧すわぷよ、旧YourTIME、旧ショートスタジオ等の経緯確認 |

優先順位は、`70_すわぷよ・ユアタイム統合仕様/` → 実装コード・DB migration → 参考資料・履歴。`_履歴/`と`90_参考資料/`の記述を新規実装の根拠にしない。

## タスクと要求

## 命名規約

- 文書と人向け素材は日本語名を基本にする。
- 正式名称・一般的な略語（`LINE`、`LIFF`、`API`、`SNS`、`YourTIME`）は維持する。
- コードのモジュール名、importパス、公開URLは英語のまま維持する。
- HTMLは提示用、Markdown・JSON・実DBスキーマを正本とする。

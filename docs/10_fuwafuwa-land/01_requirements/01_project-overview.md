# 01-01 プロジェクト概要

> 最終更新: 2026-06-23

## 1. プロジェクト名

すーすーわーわー ふわふわランド

## 2. 背景

YourTIME 2026-08-02 では、親子が健康・未病・口腔育成に触れる体験を増やしたい。すーすーわーわーは、鼻呼吸、口腔育成、よく噛むこと、姿勢、睡眠、親子の会話などをやわらかく届けるキャラクター群として活用できる。

子どもが描いた塗り絵やイラストが、その場でデジタル世界に登場する体験は、単なる展示よりも記憶に残りやすい。さらに、イベント後のショート動画・SNS・AI制作裏側公開とも接続できる。

## 3. 目的

- 子どもが自分の作品をデジタル上で見つけて楽しめる体験を作る。
- すーすーわーわーの認知を広げる。
- YourTIME のイベント満足度を上げる。
- 口腔育成への入口を、説教ではなく遊びとして作る。
- 将来のSNS/ショート動画/AI活用企画につながる素材と世界観を蓄積する。

## 4. MVPスコープ

2026-06-25 までに判断するMVPは、以下に絞る。

- スタッフが作品画像を登録できる。
- 登録作品がモニター上に登場する。
- 作品がふわふわ動く。
- 表示作品を全リセットできる。
- ランダムで過去作品を再登場させられる。
- 指定作品を主役表示できる。
- 失敗/NG作品を非表示にできる。
- ブラウザ再読み込みで復旧できる。

## 5. MVPでやらないこと

- AIコメント生成。
- AIキャラクター変換。
- AIショート動画生成。
- SNS自動投稿。
- 子どもの顔認識。
- 個人名必須入力。
- 医療診断。
- 100〜200体の同時表示。
- 本番DBスキーマ変更。

## 6. 成功条件

2026-06-25 時点の成功条件:

- 1作品を60秒以内に登録して表示できる。
- 同時表示12体で見やすく、20体でも破綻しない。
- 6時間運営相当の短縮ストレステストで停止しない。
- 全リセット、ランダム表示、指定表示、非表示が成立する。
- 顔写真を撮らず作品のみ撮影する導線が成立する。

2026-08-02 本番時の成功条件:

- 子どもが「自分の絵が出た」と分かる。
- スタッフが詰まらず回せる。
- モニター前に自然な滞留と会話が生まれる。
- 口腔育成への接点が押しつけにならない。

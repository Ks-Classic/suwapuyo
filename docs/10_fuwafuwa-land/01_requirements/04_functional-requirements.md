# 01-04 機能要件一覧

> 最終更新: 2026-06-23

## 1. 作品登録

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-001 | 画像選択 | スマホ/タブレットから作品画像・台紙写真を選ぶ | Must |
| FR-002 | カメラ撮影 | 端末カメラで塗り絵台紙/作品用紙を撮る。顔写真は対象外 | Must |
| FR-003 | プレビュー | 登録前に画像を確認する | Must |
| FR-004 | 作品ID発行 | `ART-0001` 形式で採番する | Must |
| FR-005 | 登録して表示 | 登録直後に主役表示できる | Must |
| FR-006 | 登録のみ | 混雑時に表示キューへ入れる | Should |
| FR-007 | デジタル描画 | 紙を使わず透明PNGで作品を描いて登録する | Must |

## 2. 画像処理

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-101 | 塗り絵台紙補正 | 四隅マーカーからA4台紙を補正し、枠内作品を抽出する | Must |
| FR-102 | 連結背景透過 | 端からつながる近白背景だけを透明化し、作品内部の白を残す | Must |
| FR-103 | リサイズ | 表示向けサイズへ圧縮する | Must |
| FR-104 | フォールバック表示 | 背景除去失敗時に四角画像で表示 | Must |
| FR-105 | 透過モード選択 | 塗り絵用紙/白背景を透過/そのままを登録前に選べる | Should |

## 3. 表示ワールド

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-201 | 作品表示 | 登録作品をPixiJS上に表示 | Must |
| FR-202 | ふわふわ移動 | 浮遊/歩行/跳ねる動き | Must |
| FR-203 | 表示数制限 | 標準8〜20体、最大30体 | Must |
| FR-204 | ランダム登場 | 作品プールからランダム表示 | Should |
| FR-205 | 主役表示 | 指定作品を大きく中央寄りに表示 | Should |
| FR-206 | サンプル表示 | 既存キャラを作品登録後も世界観の住人として表示 | Must |

## 4. スタッフ操作

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-301 | 作品一覧 | 登録作品を一覧表示 | Must |
| FR-302 | 表示 | 任意作品を通常表示 | Must |
| FR-303 | 主役表示 | 任意作品を強調表示 | Should |
| FR-304 | 非表示 | 失敗/NG作品を表示対象から外す | Must |
| FR-305 | 全リセット | 表示中作品だけをクリア | Must |
| FR-306 | ランダム表示 | 現在のプールから再編成 | Should |
| FR-307 | 表示数変更 | 8/12/20/30などを切替 | Should |

## 5. 復旧

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-401 | ローカル保存 | 作品プールを保存 | Must |
| FR-402 | 再読み込み復旧 | ブラウザ再読み込みで復元 | Must |
| FR-403 | サンプルモード | 復旧不能時に最低限表示 | Must |

## 6. プライバシー

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---:|
| FR-501 | 顔写真除外 | 顔写真/人物写真を登録対象外としてスタッフ確認する | Must |
| FR-502 | SNS名除外 | 後日素材・SNS転用時は下の名前を出さない | Must |
| FR-503 | 誤登録削除 | 誤って登録した作品をスタッフ一覧から即アーカイブする | Must |

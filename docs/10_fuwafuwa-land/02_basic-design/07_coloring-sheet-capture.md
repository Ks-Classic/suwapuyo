# 02-07 塗り絵台紙・撮影・背景透過設計

> 最終更新: 2026-06-23  
> 位置づけ: 本番主導線は「塗り絵形式」。スマホで紙の作品を撮影し、四隅マーカーで補正し、端からつながる白背景だけを透明化して、ふわふわランドに登場させる。

## 1. 採用方針

MVPは顔写真AI変換ではなく、以下を主導線にする。

- **主導線**: 黒輪郭の下絵入りA4塗り絵台紙を描く → スタッフがスマホで手持ち撮影 → 補正/透過 → 登録。
- **自由描画導線**: 下絵なしの自由描画台紙を描く → 同じ撮影/補正/透過で登録。
- **低コスト導線**: スタッフ画面の「描く」でデジタル描画 → 透明PNGで登録。
- **保険導線**: 画像ファイルアップロード → プレビュー → 必要なら透過なしで登録。
- **MVP外**: 顔写真/人物写真のAIアニメ変換。プライバシー、同意、費用、待ち時間のリスクが大きいため入れない。

## 2. 台紙仕様

| 項目 | 仕様 |
|---|---|
| 用紙 | A4縦、白紙または薄い単色背景 |
| 描画領域 | 中央に大きな角丸矩形。黒輪郭の下絵入り版と、下絵なし自由描画版を用意する |
| 四隅マーカー | 黒ベタ正方形 18mm、白クワイエットゾーン 6mm |
| QR | 任意。左上付近にテンプレID用 20mm。未読でも登録可 |
| 禁止表示 | 顔写真貼り付け、苗字、学校名、住所、電話番号 |
| 印刷コスト | まず白黒印刷で成立させる。カラー台紙はGate後に判断 |

台紙は「あーとぽん型」の塗り絵体験を参考にし、描く楽しさと撮影安定性を両立させる。黒輪郭の下絵入りを基本にしつつ、自由描画版も同じマーカー仕様で運用できるようにする。

## 3. 撮影UIフロー

```txt
スタッフ画面
  カメラ
    ライブカメラ
      ├ 台紙認識: 探しています / 正式判定OK / 補正なし / 撮り直し推奨
      ├ [撮影してプレビュー]  ※手動ボタンは常に残す
      └ 正式判定OKが安定したら自動でプレビュー生成
      ↓
    プレビュー
      ├ 背景モード: 台紙用 / 白背景 / そのまま
      ├ 台紙認識: 正式判定OK / 補正なし / 透過注意
      ├ 下の名前(任意)
      └ [登録して主役表示] [登録のみ] [撮り直す]
```

スマホ片手操作を優先し、登録前に複雑な編集画面を挟まない。撮影は手持ち前提とし、自動認識で正式判定できた場合はスタッフが迷わずプレビューへ進める状態にする。失敗時は「撮り直す」「そのまま登録」「描くへ移動」の3択に留める。

### オートキャプチャ

撮影ボタンは残す。ただし、ライブカメラ中に `official` 判定が安定したら、スタッフが押さなくても自動で1フレームを確定し、プレビューへ移動する。

| 状態 | 条件 | UI | 動作 |
|---|---|---|---|
| `scanning` | ライブカメラ起動中、正式判定未達 | `台紙を画面に入れてください` | 解析継続 |
| `officialCandidate` | 1フレームで `official` | `そのまま止めてください` | 解析継続 |
| `autoPreview` | 連続3フレームまたは600ms以上 `official` が維持 | `正式判定OK` | 自動キャプチャしてプレビュー生成 |
| `manualPreview` | スタッフが撮影ボタンを押す | `補正なしでも登録できます` | 現在フレームでプレビュー生成 |
| `rejected` | 暗すぎる/近すぎる/人物写真疑い/処理不能 | `撮り直し推奨` | 自動キャプチャしない |

自動で行うのは**プレビュー生成まで**。Storage登録や表示反映は、誤登録を避けるため必ず `登録して主役表示` または `登録のみ` のタップで実行する。

自動キャプチャの二重発火を防ぐため、`autoPreview` 移行後はライブ解析を止める。スタッフが `撮り直す` を押した場合だけライブ解析を再開する。

## 4. 透過モード

| モード | 用途 | 処理 | 既定 |
|---|---|---|---:|
| 台紙用 | A4台紙撮影 | マーカー補正できた場合は補正後画像、失敗時は全体画像を使う。外周2.8%を内側トリムし、端からつながる近白だけ透明化 | Yes |
| 白背景 | 台紙外の白い紙/スクショ | 画像端からflood fillで背景透明化 | No |
| そのまま | 失敗時、色紙、写真ではない作品 | リサイズのみ。角丸カードとして表示 | No |

`台紙用` と `白背景` は、画像全体の白を一括で消さない。白目、歯、雲、服、文字など作品内部の白を守るため、**画像端から連結している背景だけ**を透明化する。プレビュー後でもスタッフが3モードを切り替えて再処理できる。

## 5. 背景透過アルゴリズム

実装場所: `src/fuwafuwa-land/capture/processArtwork.ts`

1. 入力Canvasを長辺1000px程度へ縮小する。
2. `markerDetect` で四隅マーカーを探す。
3. 見つかった場合は `warp` でA4比矩形へ補正する。
4. 見つからない場合は全体画像を使い、UIには `markers_not_found` を出す。
5. `台紙用` の場合は外周2.8%を内側トリムし、撮影用の黒枠/紙端を避ける。
6. 透過対象の `ImageData` を取得する。
7. 画像の四辺からflood fillを開始する。
8. 背景判定は以下の両方を満たす画素とする。
   - 輝度が高い（実装値: `luma > 235`）。
   - RGB差が小さい（実装値: `max(rgb) - min(rgb) < 28`）。
9. flood fillで到達した画素だけ alpha=0 にする。
10. 透過ピクセルがある場合はPNG、ない場合または `そのまま` はJPEGでStorageへアップロードする。

MVP実装では境界フェザーはまだ入れない。紙端のギザつきが目立つ場合は、Gate後に1〜2pxフェザーまたは軽い収縮/膨張処理を追加する。

この方式はAI不要、無料、ブラウザ内完結、イベント当日の通信/待ち時間リスクが低い。マーカー精度が不安定でも全体画像フォールバックで登録は止めない。

## 6. 正式判定ロジック

手持ち撮影でもスタッフが判断に迷わないよう、処理結果を3段階で返す。

| 判定 | 条件 | UI表示 | 登録 |
|---|---|---|---|
| `official` | 四隅マーカー4点検出、凸四角形、台紙面積が画像の一定以上、A4比へのワープ成功、出力に極端な欠けなし | `台紙認識OK` | 既定で登録可 |
| `fallback` | マーカー不足または低信頼だが、画像全体として登録可能 | `補正なし` | 登録可、必要なら撮り直し |
| `rejected` | 画像が小さすぎる、暗すぎる、人物写真の疑い、Canvas処理不能 | `撮り直し推奨` | 原則登録しない |

`official` は「きれいに登録できた」ことを示すための判定であり、イベント体験を止める条件ではない。DoDは `fallback` でも登録完了できることを維持する。

### `official` の最低条件

実装時は以下をすべて満たした場合だけ `official` とする。

- 四隅マーカー4点が検出できる。
- 4点の順序が `TL, TR, BR, BL` として矛盾しない。
- 4点の作る四角形が凸で、交差していない。
- 台紙四角形の面積が入力画像の25%以上。
- ワープ後のA4比が許容範囲内（縦横比誤差±8%以内）。
- 出力画像の四辺に極端な黒帯/欠けがない。
- 入力フレームの平均輝度が暗すぎない。

この判定は「高速・決定的・説明可能」を優先する。AIや外部APIは使わない。

## 7. デジタル描画との整合

デジタル描画Canvasは最初から透明背景PNGを出力する。したがって撮影向けの白背景透過処理は通さない。

- 背景はCSSの見た目だけにし、Canvas本体には白を塗らない。
- 登録前プレビューでは透明チェッカー背景を表示する。
- PixiJS表示ではPNGまたはデジタル描画を透過作品として扱い、カード枠ではなく画像輪郭を優先する。

## 8. 表示画面との整合

- 既存の村背景 `public/assets/ui/village_bg.png` を常に使う。
- 既存4キャラは作品登録後も消さず、世界観の住人として残す。
- 登録作品はサンプルより前面・少し大きめに表示する。
- 透過PNG/デジタル描画はカード枠なしで自然に浮かせ、非透過JPEGは角丸カードとして扱う。

## 9. 本番前に決める確認点

以下はUI/UXや運用の手戻りになりやすいため、実装を広げる前に確認する。

- 台紙は黒輪郭の白黒印刷を基本にし、カラー台紙は必要なら少数だけ用意する。
- 台紙を会場で配るか、事前配布するか。
- 下絵入り版と自由描画版の配布比率をどうするか。
- 撮影はスタッフ手持ちで運用する。
- SNS撮影はOK。掲示で「顔写真なし、名前なし」を周知する。
- 個別同意フォームは持たない。後日動画/投稿に使う場合も作品のみ・名前なしで扱う。

# 05-01 実装ルール

> 最終更新: 2026-06-23

## スコープルール

- 2026-06-25までは可否判断に必要なものだけ作る。
- AIコメント生成、AI動画生成、SNS自動投稿は入れない。
- 本番DBは入れない。

## 技術ルール

- TypeScriptで `any` 禁止。
- 画像処理、状態管理、描画、UIを分離する。
- `.env*` を触らない。
- シークレットをコミットしない。

## UXルール

- 100〜200体同時表示はしない。
- 標準表示は12体。
- 子どもが自分の作品を見つけられることを優先する。
- スタッフ操作は1画面で完結させる。

## 推奨構成

```txt
src/fuwafuwa-land/
  types.ts
  store/
  image/
  renderer/
  components/
```

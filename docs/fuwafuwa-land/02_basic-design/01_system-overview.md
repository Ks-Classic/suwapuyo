# 02-01 システム概要

> 最終更新: 2026-06-23

## MVP構成

2026-06-25の可否判断では、Vite/React/PixiJSの単一Webアプリとして実装する。

```txt
Browser
  ├─ Staff UI
  ├─ Display UI
  ├─ Artwork Store
  ├─ Image Processor
  └─ PixiJS World
```

## 画面構成

- `/fuwafuwa`: 入口。
- `/fuwafuwa/staff`: スタッフ操作。
- `/fuwafuwa/display`: モニター表示。

MVPではルーティング実装を簡略化し、1画面内のタブ切替でもよい。ただし責務は分離する。

## 当日構成候補

### A案: 表示PC単体

表示PCでスタッフ画面と表示画面を別タブ運用する。

利点:

- ネットワーク依存が低い。
- 6/25までに検証しやすい。
- 復旧が簡単。

欠点:

- 撮影端末と分離しづらい。

### B案: スタッフ端末 + 表示PC

スタッフ端末で撮影し、表示PCにリアルタイム反映する。

利点:

- 現場導線が自然。

欠点:

- ネットワーク依存が高い。
- 6/25判断には実装コストが大きい。

## 推奨

6/25判定はA案。本番はA案を基本にし、余裕があればB案を検証する。

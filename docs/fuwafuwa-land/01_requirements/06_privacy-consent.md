# 01-06 プライバシー・同意・SNS境界

> 最終更新: 2026-06-23  
> 位置づけ: ふわふわランド本番運用では、子どもの顔写真・本人を識別できる写真を扱わない。作品画像だけを会場表示する。

## 1. 基本方針

- **顔写真は撮らない・登録しない・表示しない**。
- スタッフ画面の「カメラ」は、子どもの顔ではなく**塗り絵台紙/作品用紙を撮影する導線**とする。
- 画像ファイルアップロードも、作品画像・台紙写真・デジタル作品に限定する。
- AIによるキャラクター変換はMVPでは扱わない。将来検討する場合も、本人写真ではなく**作品画像を世界観に寄せる変換**だけを対象にする。
- 下の名前は任意。モニター表示は可、SNS/動画/後日公開素材では非表示を既定にする。
- 個別の署名フォームは持たない。代わりに、会場掲示で「作品のみ表示/撮影可、顔写真なし、名前は後日素材に出さない」を明示する。

## 2. 表示してよいもの / 止めるもの

| 種別 | 会場モニター | SNS/後日素材 | 備考 |
|---|---:|---:|---|
| 塗り絵台紙を撮影した作品 | 可 | 名前なしで可 | 作品内に個人情報がないことをスタッフが確認 |
| デジタル描画 | 可 | 名前なしで可 | 背景透過PNGを優先 |
| 下の名前ラベル | 可 | 不可 | 後日書き出し時に除外 |
| 顔写真/全身写真/服装が分かる写真 | 不可 | 不可 | 誤登録時は即アーカイブ |
| 苗字、学校名、住所、電話番号が書かれた作品 | 不可 | 不可 | プレビューで目視除外 |

## 3. スタッフ確認フロー

1. 来場者が塗り絵/デジタル描画を作る。
2. スタッフがスタッフ画面で撮影または選択する。
3. プレビューで以下を確認する。
   - 顔・人物写真が写っていない。
   - 苗字、学校名、住所、電話番号などが写っていない。
   - 作品が枠内に入り、見切れが許容範囲。
4. 必要なら下の名前だけ入力する。
5. `登録して主役表示` または `登録のみ` を押す。
6. 誤登録を見つけたら、スタッフ一覧から即 `削除`（実体は `archived`）する。

## 4. 会場掲示文案

```txt
ふわふわランドでは、お子さまの顔写真ではなく、描いた作品だけをモニターに表示します。
表示名は任意の「下の名前」のみです。
苗字・学校名・住所など、個人が分かる情報は作品に書かないでください。
会場の様子やモニターは撮影・SNS投稿OKです。
後日紹介に使う場合も、下の名前は出さず作品画像だけを使います。
```

## 5. 将来のAI変換について

AI変換は「写真をGPT等でアニメ化して表示」ではなく、**作品画像をすーすーわーわーの世界観に馴染ませる任意加工**としてだけ検討する。

- MVPでは実装しない。
- 本人写真を外部AIへ送らない。
- 実装する場合は、処理先、保存先、同意文、費用、待ち時間、失敗時の戻し先を別ADRで確定してから着手する。
- 無料枠やOSSを使う場合でも、ライセンスと入力データの扱いを公式情報で確認する。

## 6. 本番前に必ず確認すること

- 会場側が「作品のみ表示」「下の名前任意」「顔写真なし」「SNS撮影OK」の掲示内容を承認しているか。
- スタッフが誤登録時に `削除` できることをリハーサルで確認したか。
- SNS/後日素材では名前を除外した書き出しフローがあるか。

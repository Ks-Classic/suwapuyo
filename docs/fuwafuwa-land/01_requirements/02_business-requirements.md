# 01-02 業務要件一覧

> 最終更新: 2026-06-23

## 業務要件

| ID | 要件 | 優先度 | 判定基準 |
|---|---|---:|---|
| BR-001 | 子どもの作品をデジタル世界に登場させる | Must | 撮影/登録/表示が一連で成立 |
| BR-002 | YourTIME当日に6時間運営できる | Must | 短縮ストレステストと復旧テストを通過 |
| BR-003 | スタッフ1人でも最低限運用できる | Must | 10作品連続登録で平均60秒以内 |
| BR-004 | 子どもの顔を撮らない運用にする | Must | 撮影対象を作品のみに限定 |
| BR-005 | モニター1台横長で見やすくする | Must | 12体表示で作品判別可能 |
| BR-006 | 表示作品をリセットできる | Must | 全リセット後も作品プールは残る |
| BR-007 | 過去作品をランダム表示できる | Should | 作品プールから偏り少なく再登場 |
| BR-008 | 指定作品を主役表示できる | Should | 子どもが見ている時に大きく表示 |
| BR-009 | 失敗/NG作品を非表示にできる | Must | 非表示後は再登場しない |
| BR-010 | SNS撮影/後日素材の境界を掲示する | Must | 個別同意フォームなしで、作品のみ・顔なし・名前なしを周知 |
| BR-011 | 口腔育成の啓蒙につながる | Should | 背景・掲示・声かけで自然に接続 |
| BR-012 | ショート動画企画と素材/世界観を共有できる | Could | キャラ素材/設定を共通管理 |

## 業務上の前提

- 来場者は子どもと保護者。
- 操作主体はスタッフ。
- 子ども自身にアップロード操作をさせない。
- 作品受付が混雑する可能性がある。
- 会場ネットワークは使える前提でSupabase本線を検証するが、不安定時の表示継続手順は別途用意する。
- 表示機材は一般的なDELLモニター1台横長を正とする。2台連結は拡張検証に分離する。

## 業務上の禁止事項

- 名前や顔写真の取得。名前は下の名前だけ任意入力に留める。
- 医療的な診断表現。
- 掲示で周知していない条件で作品をSNS/後日素材に使うこと。
- 表示不能時にスタッフが復旧できない構成。

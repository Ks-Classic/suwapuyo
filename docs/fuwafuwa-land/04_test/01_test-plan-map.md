# 04-01 テスト計画（マップ）

> 最終更新: 2026-06-23

## テスト全体像

| ID | 対象 | 目的 | 優先度 |
|---|---|---|---:|
| TM-001 | 画像登録 | 60秒以内に登録できるか | Critical |
| TM-002 | 背景除去 | 白背景台紙が実用品質になるか | Critical |
| TM-003 | 表示反映 | 登録後すぐ表示されるか | Critical |
| TM-004 | 表示安定性 | 6時間運営相当で止まらないか | Critical |
| TM-005 | 表示数 | 8/12/20/30体のUXと性能 | Critical |
| TM-006 | スタッフ操作 | リセット/ランダム/指定/非表示 | Critical |
| TM-007 | 復旧 | リロードで戻るか | Critical |
| TM-008 | モニター | DELL 1台/2台相当で見やすいか | Critical |
| TM-009 | 個人情報 | 顔を撮らず運用できるか | Critical |

## 判定優先度

1. 登録から表示までの一連の流れ。
2. 12体表示の見やすさ。
3. 復旧性。
4. 1人運用。
5. 背景除去品質。

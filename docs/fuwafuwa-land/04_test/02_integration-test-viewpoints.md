# 04-02 結合テスト観点

> 最終更新: 2026-06-23

## 1. 登録と表示

- 画像登録後、作品IDが発行される。
- 作品一覧に出る。
- 表示画面に反映される。
- 主役表示ができる。

## 2. 画像処理と表示

- 塗り絵台紙モードで、四隅マーカー補正結果が表示に使われる。
- 端からつながる近白背景だけが透明化され、作品内部の白が残る。
- デジタル描画は透明PNGのまま表示に使われる。
- 処理失敗時に四角画像へ逃げられる。
- 透明部分の周囲に不自然なノイズが出すぎない。
- 顔写真/人物写真を登録しない確認導線がプレビューにある。

## 3. スタッフ操作と状態

- 非表示にした作品がランダム表示に戻らない。
- 全リセットで表示だけ消え、作品プールは残る。
- ランダム表示が表示上限を守る。
- 指定表示がランダム表示より優先される。

## 4. 保存と復旧

- 登録作品が保存される。
- 再読み込みで作品プールが戻る。
- 表示状態が壊れてもランダム表示で再開できる。

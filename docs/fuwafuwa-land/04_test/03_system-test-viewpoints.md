# 04-03 システムテスト観点

> 最終更新: 2026-06-23

## 1. 6時間運営相当

- 300件作品プールを目標にし、短縮時も50件以上で確認する。
- 10秒ごとにランダム入替。
- 60分以上連続稼働。
- 途中でリセット、非表示、指定表示を実行。

## 2. モニター視認性

- 1台表示。
- 1台横長を正とする。
- 12体で自分の作品が分かるか。
- 20体で混雑時も成立するか。
- 30体は性能上限として確認する。

## 3. スタッフ運用

- 1人で10作品連続登録。
- 平均60秒以内。
- 失敗画像を1件含める。
- 非表示操作を1件含める。
- 指定表示を1件含める。

## 4. 個人情報

- 撮影対象を塗り絵台紙/作品用紙に限定できるか。
- 顔写真/人物写真や苗字・学校名入り作品を登録前に止められるか。
- 下の名前なしでも運用できるか。
- SNS転用同意を別管理できるか。

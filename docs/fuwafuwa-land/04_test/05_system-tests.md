# 04-05 システムテスト

> 最終更新: 2026-06-23

| ID | テスト | 合格基準 |
|---|---|---|
| ST-001 | 10作品連続登録 | 平均60秒以内 |
| ST-002 | 12体表示 | 視認性・FPSともに問題なし |
| ST-003 | 20体表示 | 混雑時運用として成立 |
| ST-004 | 30体表示 | クラッシュなし。UX採用は別判断 |
| ST-005 | 300件プールで60分以上ランダム入替 | 停止/状態破綻なし、FPS/メモリ/容量ログに異常な張り付きがない |
| ST-006 | リロード5回 | 30秒以内に運用再開 |
| ST-007 | DELLモニター相当表示 | 自分の作品が判別できる |
| ST-008 | 塗り絵台紙10枚撮影 | 登録が止まらず、実用レベルの補正/透過またはカード表示へ逃げられる |
| ST-009 | 顔写真なし運用リハーサル | スタッフが人物写真/個人情報入り作品を登録前に止められる |

## Go / Conditional Go / No-Go

### Go

- 登録から表示まで成立。
- 12〜20体表示が安定。
- リセット/ランダム/指定/非表示が動く。
- リロード復旧できる。
- 1人運用の見通しがある。
- 塗り絵台紙またはデジタル描画で、顔写真なし運用が成立する。

### Conditional Go

- マーカー補正/連結背景透過が不安定だが、そのままカード表示またはデジタル描画で成立。
- Supabase本線は成立するが、当日ネット不安時の運用手順追加が必要。

### No-Go

- 12体表示で停止する。
- 作品登録が平均2分以上。
- 復旧できない。
- 顔写真/人物写真の誤登録を運用で防げない。

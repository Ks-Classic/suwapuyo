07 — 槍B 実装スペック（並行着手用・もぐぴよtap＝汎用枠＋計測）

4視点が独立に「最高レバレッジ手」に挙げた核。1機能で〈連動・計測・マネタイズの証拠〉が同時に立つ。 coralup特例にせず最初から汎用スポンサー枠に。

# Supabase: 出展者を「ゲスト出演キャラ」として一般化
sponsors(
  id, name, character_img, logo, popup_title, popup_body,
  cta_url, qr_url, theme, active
)
events(
  id, type, sponsor_id, artwork_id, session_id, ts
)   # type: artwork_register | appear | tap | popup_open | cta_click

# PixiJS: 世界はPixi / UIはReact、責務分離
sprite.eventMode = 'static'
sprite.on('pointertap', () => { track('tap', sponsorId); openPopupReact(sponsor) })
# 当たり判定は透過PNGのalphaに合わせる（見た目と判定のズレを世界一は即見抜く）

# 送客は必ずリダイレクト経由で実数化 → 効果レポートの源泉
cta_url = "/r/coralup?src=fuwafuwa"   # /r/* で cta_click を記録してから外部遷移
UX補正（重要）

大画面モニターは子も親も触れない／スタッフが触るとショーが止まる。→ 送客は「親のスマホ」で完結：もぐぴよがfeatured時に「coralupブースこっち→」吹き出し＋QR。事前展開（ロゴを事前公開しスマホで触れる）はこのタップ面の主戦場になり得る＝会場前から計測が回る。

north-star＝tap→送客数を最初の機能から計装。これ無しでは何を作っても「で、効果は数字で？」に答えられない。

かわいいパステル調の俯瞰インフォグラフィック・ポスター（横長16:9）。テーマは「すーすーわーわー村のエコシステム」。 上半分＝明るい晴れた村「すーすーわーわー村（YourTIME / Suwa Oral Village）」。やわらかい水色の空、緑の丘、ふわふわ漂う雲。歯のキャラ（村長わーわー）、双眼鏡の歯（すーすー）、サンゴ頭の白いおばけ（もぐぴよ）、白衣のネコ（けとにゃん）など丸くて可愛い未病テーマのマスコットたち。中央に大きなモニターがあり、子どもが描いた塗り絵がふわふわ動いて出てきて、子どもたちが「わー！」と指さして喜んでいる。空に企業ロゴの吹き出しがいくつか浮き、近くに小さなスマホとQRコードのアイコン（タップで店の説明、の意）。村の周りを丸い矢印のループ（フライホイール）が回る。 下半分＝落ち着いた色の「AI開発室（裏側）」。木幡を表すAIキャラ（やさしいロボット風）がパソコンで動画を作っている。机から「Note」「X」「YouTube」「企業のAI活用」へ矢印が伸びる。上の明るい村と下の開発室を、点線の矢印が上下につなぐ（プロセスエコノミーの橋）。 全体：kawaii日本のマスコット絵本タッチ、太めの輪郭線、角丸、紙のような温かみ、彩度ひかえめのパステル（空色・ティール・クリーム・少しの山吹色）。日本語ラベルを少しだけ（「村＝YourTIME」「タップで送客」「裏：AIで作ってます」）。文字は読みやすく最小限。フラットイラスト、影は柔らかく。

## 0. なぜ「健康ハンドブック」と名乗るのか（正統性の錨）

`04_事前検死・公平な村.md` §更新で確定済み：YourTIMEは既に『健康Hand Book』で**掲載スポンサーを公募**している。＝この文脈では「お金を出した所が載る」は**問題ない**（NPRスポンサー読み上げ／チャリティ記念誌と同型）。

守る条件は3つだけ：
1. **公開**（広告と分かる・ステマでない）
2. **貢献の体**（crude広告でなく健康文化への寄与）
3. **無料ベースライン＋応援枠**（載せられない人を排除しない）

→ LINE村の案内所＝**"デジタル版・健康ハンドブック"**。「広告プラットフォーム」とは呼ばない。

## 1. 役割＝情報を「配る」と「集める」の両輪

| 向き | 中身 | 価値 |
|---|---|---|
| **配る（ハンドブック）** | 未病・健康の豆知識、出展者の専門コンテンツ、YourTIME情報、村からのお便り | 来場者にGIVE・前後ずっと触れられる |
| **集める（アンケート）** | 来場者の声・属性・「気になったブース」 | **当日その場では取れない情報**＝出展者ROIの証拠／つなやす自前DB＝資産（`06`§2.5） |

> アンケートは「おまけ」でなく**この器の存在理由の半分**。配るだけでは資産にならない。

## 2. 技術方針（`06`§2.5 確定を踏襲）

- LINEは**ミニアプリ審査を回さない**（1〜2週＋差し戻しで8/2に間に合わないリスク）。**村公式1本の薄いラッパー**にする。
- **すわぷよ／ふわふわランド／マップは別PWA**（QR起動・PixiJS・オフライン耐性）。LINEは**リッチメニューからそこへ飛ばす器**。
- 各社個別の公式アカウントは作らない（運用地獄＋プライバシー壁）。村公式1本に集約。
- 配信は**PULL／週1上限／ブロック率25〜30%前提**。ライトプラン想定（友だち1000×週1＝月4000通≒¥5000規模）。※LINE料金は2026-10改定予定・要再確認。

## 4. QRを「各所に撒く」設計（登録の入口）

**入口を1点に絞らず、あらゆる接点にLINE登録QRを置く**。どこで触れても村に入れる。

| 置き場所 | QRの役割 |
|---|---|
| 会場入口 | 来場＝登録の最大フック。**誰がいつ来たか**の起点（同意の範囲で） |
| 各ブース | スタンプラリー兼・出展者紹介への入口（③オプション。回遊データ） |
| すわぷよ内の節目 | 解放イベント画面・タイトルから登録へ（`../../30_すわぷよ旧仕様/03` ⑤） |
| ふわふわランド引換証 | 相棒を持ち帰るQRと並べてLINE登録QR |
| チラシ／モニター／ショート動画 | 会期前の事前登録 |

- **登録しない人を迷子にしない**：紙マップ／紙ハンドブック併置の逃げ道（`08`②）。
- 来場検知・回遊データは「やれたら強いが無理なら削れる」オプション。当日オペ（広い会場・ネット不安定＝`01`§9）が崩れる方が事故。

## 5. アンケート＝この器の主役データ

### 5.1 なぜでかいか
- 出展者に「◯人がタップ＋その人たちはこういう属性・悩み」まで返せる＝`01`§8 Phase1の課金の心臓。
- 運営に来場者像の可視化＝次回スポンサー営業の弾。
- つなやす自前DB＝そのまま売り物（`06`§2.5）。LINE友だちはエクスポート不可だが、**アンケートで取ったデータは自分たちの資産**。

### 5.2 取り方（個人情報の壁を越える）
- **LINE経由の第三者提供は規約8.2で不可**・健康情報は要配慮個人情報。→ アンケートは**つなやす自前フォーム**（Tally/Google等）→つなやすDB。
- 出展者へ渡す場合は「この回答を出展◯◯院に提供することに同意」を**出展者ごと**にフォームで取得。患者紹介料は取らない（`06`§2.5 / `01`§7）。
- **将来の名寄せキー**：申込時メールを**任意1項目**だけもらっておく → 後でPeatixチケットデータと突合できる土台（今回は使わなくてよい・フォーム1行の仕込み）。

### 5.3 特典×出展者課金（「広告」と言わずに金を取る形）
```
出展者 ─[特典を提供]→ 来場者 ─[アンケート回答]→ データ
   ↑                                          │
   └──[「特典を配る権利」に課金]──つなやす/運営←┘
```
- ハンドブック型＝**「来場者へのGIVE（特典）を載せる権利」**を売る＝露出枠を売らない禁則を破らない。
- **特典は治療誘引にならないGIVE限定**（健康PDF・子ども向けプレゼント・無料相談。来院割引はNG寄り）。
- **8/2は特典課金を急がない方針**（推奨）：まず「データが取れる」を実証し、実績を握ってから売る（向こうから来る形＝`06`の思想）。3社で先に小さく試すなら、医療誘引チェック＋同意フォームを7月中に整える前提。

- Phase2で「チケット購入者の何%が登録・回答したか」「リピーター」を精緻レポート化。

## 7. 配信の原則（破ると器が死ぬ＝`01`§3 / `08`§8）
1. **子どもの作品・遊びが常に主役**。案内・送客はその上に乗る。
2. **PULL であって PUSH ではない**。タップして初めて開く。通知爆撃しない（週1上限）。
3. **「広告」と呼ばない**。村の案内所／出展者を主役にするコンテンツ。露出枠は売らない（特典＝GIVEを載せる権利は可）。
4. **運営メンバーへの還元が大義**。
5. **個人情報は丁寧に**。自前同意フォーム・要配慮個人情報・患者紹介料を取らない。

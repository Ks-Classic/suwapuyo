# 01-05 非機能要件一覧

> 最終更新: 2026-06-23

## 1. 性能

| ID | 要件 | 合格基準 |
|---|---|---|
| NFR-001 | 登録速度 | 撮影完了から表示まで60秒以内、理想30秒以内 |
| NFR-002 | 描画性能 | 12体表示で体感カクつきなし |
| NFR-003 | 表示上限 | 30体表示でもクラッシュしない |
| NFR-004 | 復旧速度 | 再読み込みから30秒以内に運用再開 |

## 2. 可用性

| ID | 要件 | 合格基準 |
|---|---|---|
| NFR-101 | 6時間運営 | 短縮ストレステストで状態破綻なし |
| NFR-102 | 操作継続 | リセット/非表示/指定表示を繰り返しても破綻なし |
| NFR-103 | ネット不調耐性 | Supabase切断時も表示済み作品はIndexedDBキャッシュで継続表示できる |

## 3. UX

| ID | 要件 | 合格基準 |
|---|---|---|
| NFR-201 | 視認性 | DELLモニターで自分の作品が判別できる |
| NFR-202 | 過密防止 | 100〜200体同時表示はしない |
| NFR-203 | 子ども向け | 動きが速すぎず、作品が読める |
| NFR-204 | スタッフ向け | 主要操作が1画面で完結する |

## 4. セキュリティ/プライバシー

| ID | 要件 | 合格基準 |
|---|---|---|
| NFR-301 | 顔写真回避 | 撮影対象は塗り絵台紙/作品用紙/デジタル作品のみ |
| NFR-302 | 個人情報最小化 | 名前入力は下の名前のみ任意、SNS/後日素材では除外 |
| NFR-303 | 掲示周知 | SNS撮影OK、後日素材は作品のみ・名前なしを会場掲示で明示 |
| NFR-304 | シークレット管理 | `.env*` やAPIキーをコミットしない |

## 5. 保守性

| ID | 要件 | 合格基準 |
|---|---|---|
| NFR-401 | 責務分離 | 画像処理、状態管理、描画、UIを分ける |
| NFR-402 | 型安全 | TypeScriptで `any` を使わない |
| NFR-403 | 拡張性 | Supabase正本を維持しつつ、将来ローカルフォールバックを追加できるリポジトリ構造 |

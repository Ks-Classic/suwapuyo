# ふわふわランド本体 — 実装状態

> 基準日: 2026-07-21
> 責務: 会場で子どもが描いた作品を、スタッフ確認後に大画面の世界へ安全に登場させる展示・運営システム
> 本番判定: **体験・演出MVP成立／認証・transaction・実機運用未完のため本番運用不可**

## 1. 利用者と価値

3歳頃から小学生までの子どもが、タブレットへ指で描いた作品を自分の操作で送り出し、スタッフ確認後に大画面へ登場する因果を理解し、会場全体で喜びを共有できるようにする。

## 2. 所有範囲

| 境界 | 正規URL | 主利用者 | 所有データ |
|---|---|---|---|
| お絵描き | `/fuwafuwa/draw` | 子ども・補助スタッフ | 描画、作品、確認待ち状態 |
| 大画面 | `/display` | 会場来場者 | 表示キャラ、表示状態、演出、BGM |
| 運営 | `/staff`、`/staff/artworks`、`/staff/land`、`/staff/drawing`、`/staff/devices` | 認証済みスタッフ | 承認、非表示、保管、設定、端末状態、監査 |
| 診断 | `/staff/debug` | 技術スタッフ | FPS、接続、同期、エラー |

LINE入口、すわぷよゲーム、体操・家族記録は所有しない。作品をすわぷよへ渡すQRは接続機能の正本を参照する。

## 4. 本番を止めている重大Gate

1. `/staff*`と`/api/admin/*`をCloudflare AccessとWorker検証の両方でfail-closedにする。
2. `作品承認 → 表示キャラ作成 → 表示状態更新 → 監査`を単一transactionにする。
3. PCとスマホの二重操作で重複登場・意図しない上書きを起こさない。
4. 未確認作品を`/display`へ出さないことをDB/API/UIで縦貫通確認する。
5. 安全に再設計したmigrationだけを承認後に適用する。現行0002/0003は適用しない。
6. 描画タブレット、スタッフPC/スマホ、大画面で回線断・再接続・停止・復旧を確認する。

## 5. 次の実装順

1. `SUW-30 / SUW-31`: Cloudflare Access実設定とWorker管理API。
2. `SUW-28`: 承認transactionと中央監査。
3. `SUW-31`: 安全なmigration、seed、rollback。
4. `SUW-31`: 当日コア縦貫通と会場相当リハーサル。
5. 不合格時はローカル単体運用へ縮退し、QR引換と集計を外す。

## 6. 完了の定義

大画面でキャラが動くだけでは完了としない。未確認作品が出ず、認証済みスタッフだけが操作でき、二重操作・回線断・端末再起動後も作品状態と監査が一致し、6時間運用のfallbackが実行できた時に本番利用可とする。

## 3. 分離原則

1. SNSやVTuberの完成度を、アプリ本番準備率へ加算しない。
2. アプリのキャラ素材利用は、承認済み表示用assetだけを参照する。
3. 作者未承認の補完をCharacter Masterや公開素材へ昇格しない。
4. 投稿、外部公開、権利判断は人の承認前に実行しない。
5. ブランド制作の大量ファイルを、アプリ機能のcommitへ混ぜない。

## 4. 完了の定義

成果物ごとに権利、原画同一性、文字、媒体寸法、公開文面、承認者、公開結果を記録する。アプリ本体の完了とは独立して判定する。

## 2. 要求

### 2.1 8月2日の来場者

3歳頃から小学生までの子どもが、タブレットへ指で描いた作品をスタッフ確認後に大画面へ登場させ、自分の操作と会場演出のつながりを理解できるようにする。

親子がLINEからすわぷよを開き、ゲームと短い体操を迷わず体験できるようにする。正式情報がないブース位置や健康効果を推測表示しない。

### 2.2 当日スタッフ

子ども用画面と管理操作を分離し、認証済みのPCまたはスマホから、作品確認、ランド操作、端末状態確認、障害時の停止・復旧を行えるようにする。

### 2.3 出展者・運営

架空値を実績に見せず、取得根拠のある来場・体験データだけを確認できるようにする。8月2日までに安全に取得できないデータは、デモ表示または後続へ明示的に分離する。

## 6. リリース判定

次を満たさない機能は、コードが存在しても「本番利用可」としない。

1. 本番データ境界と認証・認可が確定している。
2. 正常系と異常系を実機で確認している。
3. Write→Read→Displayが一貫している。
4. rollbackまたは当日fallbackがある。
5. 架空値、ローカル値、実測値を画面上で区別できる。

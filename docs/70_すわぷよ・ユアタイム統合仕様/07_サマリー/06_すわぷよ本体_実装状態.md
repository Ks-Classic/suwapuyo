# すわぷよ本体 — 実装状態

> 基準日: 2026-07-21
> 責務: LINEから入り、キャラを選び、ゲームと短い体操を遊び、本人・家族の記録を確認する利用者向けアプリ
> 本番判定: **クライアントMVP成立／サーバー認証・永続化未完のため本番利用不可**

## 1. 利用者と価値

親子がLINEから迷わず開始し、子どもがキャラクターとゲームを楽しむ流れの中で、短いお口・からだ体操を体験し、その記録を継続して確認できるようにする。

## 2. 所有範囲

| 領域 | 正規URL | 所有データ |
|---|---|---|
| LINE入口 | `/auth`、`/auth/friend` | LIFF状態、内部session（未実装） |
| 初回体験 | `/welcome`、`/onboarding`、`/arrival` | 同意、家族プロフィール、子ども情報 |
| ゲーム | `/play`、`/characters` | 選択キャラ、プレイイベント |
| 体操・記録 | `/exercise/:type`、`/exercise/complete`、`/progress`、`/missions` | 体操完了、種類別回数、連続日数、ミッション |
| 村 | `/village/booths`、`/village/map`、`/village/stamps` | ブース閲覧、訪問、スタンプ |
| 家族設定 | `/settings/family` | 家族・子ども情報、同意、削除 |

ふわふわランドのお絵描き、作品承認、大画面表示、ランド運営は所有しない。作品キャラの受取は接続機能の正本を参照する。

## 4. 本番を止めている重大Gate

1. LIFF ID tokenをWorkerで検証し、偽造・期限切れでsessionを発行しない。
2. 生LINE IDをURL、localStorage、ログ、Supabase公開列へ出さない。
3. 家族・体操・行動データをRLS付きでWrite→Read→Displayまで通す。
4. オフライン再送で二重加算しないことを正常・異常系で確認する。
5. iOS、Android、LINE内ブラウザ、外部ブラウザで実機確認する。
6. 年齢帯別体操は監修versionが確定するまで健康効果を表示しない。

## 6. 完了の定義

ゲーム画面が動くだけでは完了としない。LINE認証、家族データ、体操記録、オフライン再送が同一利用者として端末をまたいで整合し、失敗時もデータを失わず安全に案内できた時に本番利用可とする。

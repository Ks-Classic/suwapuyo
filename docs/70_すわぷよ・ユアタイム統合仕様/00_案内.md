# すわぷよ・ユアタイム統合仕様 — 案内

> 文書状態: 現行仕様の正本（SSoT）  
> 最終更新: 2026-07-13
> 対象: すわぷよ、LINE公式アカウント、村の案内所、ふわふわランド連携、出展者レポート、LINE Harness、IG Harness
> 初回質問・イベント質問のDB/API実装前監査: `07_サマリー/04_初回質問・イベント質問_実装前設計監査.md`。未決事項を実装側で補完しない。

## 1. この仕様群の目的

親子がLINEから迷わずすわぷよを始め、ゲームとして楽しむうちに短いお口・からだ体操を継続でき、その接点をイベント・出展者の価値へ安全につなげるデモと将来基盤を定義する。

今回の最優先は、資料を完成させること自体ではなく、次の縦貫通デモを手戻りなく作れる状態にすることである。

```text
Instagram / 会場QR
        ↓
LINE公式アカウントを友だち追加
        ↓
LIFFで本人確認・友だち状態確認
        ↓
すわぷよ → 体操 → 記録 → ミッション・キャラ登場
        ↓
ブース紹介 / イベント案内 / 後日の再訪
```

## 2. 重要な確定事項

| 項目 | 決定 |
|---|---|
| 配信 | Cloudflareを第一候補とする。ViteアプリはCloudflare PagesまたはWorkers Assetsで配信する |
| 正式名称 | イベントは`YourTIME`、ゲームは`すわぷよ / SuwaPuyo`とする |
| 入口 | ゲーム、体操記録、会場マップ、ブース紹介を含む全利用者機能でLINE公式アカウントの友だち追加を必須とする |
| 認証 | LIFFの情報をそのまま信用せず、Cloudflare WorkerでLINEトークンを検証する |
| 主データベース | すわぷよ・アンケート・体操・出展者レポートの正本はSupabase Postgresとする |
| Harness | LINE Harness / IG Harness固有の運用データは各D1に置く。プロダクト正本にはしない |
| UI制作 | Figmaを必須にしない。既存コードを基準に、ASCII仕様→コード試作→実機確認で進める |
| 開発AI | GPT/Codexは開発作業の難易度・事故影響に応じて3クラスで使い分ける。これはアプリ内GPT機能の要件ではない |
| 医療表現 | 診断・効果保証・健康スコアは扱わず、体験回数と継続の事実のみを表示する |
| 子どもの情報 | 保護者のLINEアカウントに家族単位で紐付け、子どもの氏名・LINE IDは取得しない |
| 初回登録 | 利用目的確認後、`誰が遊ぶか → 子どもの人数 → 全員の生まれ年・月と性別 → 確認`。子どもが遊ぶ場合は登録完了後に開始する |
| 子ども情報 | 子どもごとに生まれた年・月と性別を継続保存し、年齢帯を算出する。正確な日付・氏名は取得しない |
| 年齢別体操 | 年齢は体操の表示順・説明・難易度の目安にだけ使う。診断・治療・個別最適とは表現しない |
| キャラクター | 隠しキャラを廃止し、全キャラクターの姿と名前を見せる。アンケート完了で全キャラクターが一括で村へ登場する（決定-019） |
| ブース紹介 | アンケートによる個別最適化はMVPで行わず、体操テーマと公平ローテーションで表示する |
| 来場・回遊 | 入口・ブースQRの明示操作でチェックイン／訪問を記録する。GPSによる屋内現在地追跡は行わない |
| LINEメニュー | 開催前・当日・開催後の5枠リッチメニューを使い分け、全ブース比較と作り手紹介はLIFFへ集約する |
| セグメント配信 | 生LINE IDはLINE Harness D1のみ保持。Supabaseが判定してタグ指示、Harnessが配信する。軸は行動・流入元に限定（決定-011・014） |
| B2B獲得 | 出展者レポートCTA・LINE事業者分岐・IG直接・会場クロージングの4系統。正本は`06_運用/02_IG発信・B2B獲得戦略.md`（決定-013） |
| オフライン耐性 | 体操・行動イベントは端末キューで退避・再送・冪等受付をMVP必須とする（決定-012） |
| データ保持 | アンケート・プレイ・体操記録は無期限保持。削除依頼・同意撤回時は削除し、ポリシーへ明記する（決定-018） |
| 管理アクセス | MVPは出展者・運営画面を認証なし（集計値のみ・推測不能URL・書込系は非公開）で運用。実運用移行時に認証導入（決定-020） |

## 6. 今回のMVPカットライン

### 必須

- LINE公式アカウントからLIFFを起動できる。
- 友だち追加済みの利用者だけがゲーム、体操記録、会場マップ、ブース紹介を利用できる。
- 家族アンケートをスキップ可能な会話型UIで回答できる。
- 既存のすわぷよを遊べる。
- 体操完了、種類別回数、累計、継続日数、ミッションを確認できる。
- 行動イベントを利用者単位で記録できる。
- 通信失敗時に体操・行動イベントが端末キューへ退避され、復帰後に二重加算なく再送される。
- 利用同意を版付きで記録でき、同意前に利用者データを保存しない。
- 出展者向けサンプルレポートを実データへ差し替え可能な形で表示できる。
- LINE Harnessの検証環境が起動し、ヘルスチェックと最小シナリオを確認できる。

### 後続

- ふわふわランドの作品QR引換。
- 公認歯科医院検索・予約・送客成果連携。
- 出展者ごとの自動レポート配布。
- AIによる投稿の完全自動生成・自動公開。
- IG Harnessの安全性補正後の実アカウント連携。外部Gateが間に合えば追加デモとして実施する。

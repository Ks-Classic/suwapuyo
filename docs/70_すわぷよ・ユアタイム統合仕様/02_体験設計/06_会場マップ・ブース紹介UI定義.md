# 会場マップ・ブース紹介UI定義

> 状態: UI情報設計の正本  
> 前提: LINE友だち追加・認証済みのすわぷよ内機能  
> 目的: 多数のブースを迷わず探せて、紹介の公平性と世界観を両立する

## 1. 体験コンセプト

会場マップは業務的な出展者一覧ではなく、「今日だけ開かれている村を歩く地図」とする。ただし絵本表現を優先して現在地やブース位置を曖昧にしてはならない。

```text
正確な会場位置
  ×
すわぷよの村の世界観
  ×
親指で完結する探索
```

Appleの現行Map HIGに従い、パン・ズーム、検索、カテゴリ絞り込み、選択の強調、重なる地点の整理を提供する。ブース詳細は地図を完全に隠さない段階式sheetで表示する。

## 2. 情報階層

```text
第1階層: 地図と現在見ているエリア
第2階層: 検索・カテゴリ・マーカー
第3階層: 選択ブースのpeek sheet
第4階層: ブース詳細sheet
第5階層: 外部サイト・LINE・SNS
```

初期表示で全ブースカードを並べない。利用者が「地図から探す」か「一覧から探す」かを切り替えられるようにする。

## 3. マップ初期画面

```text
┌──────────────────────────┐
│ ← きょうの村       [一覧] │
│ ┌──────────────────────┐ │
│ │ 🔍 ブースをさがす     │ │
│ └──────────────────────┘ │
│ [全部][お口][からだ][親子]→│
├──────────────────────────┤
│                          │
│     [応援文化エリア]      │
│   ◉12        ◉7          │
│        ┌───────┐          │
│   ◉3   │会場中央│  ◉5     │
│        └───────┘          │
│     ◉4       ◉9          │
│                          │
│  [−] [＋]       [全体へ]  │
├──────────────────────────┤
│ 今日はどこへ行く？        │
│ [エリアから探す]          │
├────────┬────────┬────────┤
│ あそぶ  │ きろく │  むら  │
└────────┴────────┴────────┘
```

### 仕様

- 背景は会場図をそのまま写真表示せず、位置の正確さを保ったSVGまたは高解像度マップへ再構成する。
- 初期表示は会場全体が分かる範囲。重要な入口・受付・トイレ・休憩を常時表示する。
- マーカーは出展者ロゴを小さく潰して並べず、ブース番号＋カテゴリグリフを基本にする。
- 選択時だけロゴ・キャラクター・名称を展開する。
- 色だけでカテゴリを表現せず、形・グリフ・ラベルを併用する。
- 地図の移動範囲を会場周辺へ制限し、強いスワイプで見失わないようにする。
- 端末の位置情報は取得しない。「エリアから探す」は会場エリア一覧から選ぶ導線とし、屋内測位を前提にしない。

## 4. マーカー密度

ブース数が多いため、縮小時に全名称を表示しない。

```text
縮小:  [12] のようなエリアクラスタ
中間:  ブース番号＋カテゴリグリフ
拡大:  ブース番号＋短い名称
選択:  1.15倍＋太い輪郭＋名称ラベル＋sheet
```

- クラスタをタップすると、そのエリアへ約300msで拡大する。
- Reduce Motionではアニメ移動せず即座に切り替える。
- 同じ場所に重なるマーカーは円状に広げるか一覧sheetを出す。
- 選択マーカー以外を完全に消さず、40〜60%へ弱める。

## 5. ブース選択sheet

```text
┌──────────────────────────┐
│             地図          │
│         [選択ピン]         │
├──────────────────────────┤
│ ───── ドラッグハンドル ───│
│ [PR/紹介]  お口エリア 12   │
│ [写真/キャラクター]        │
│ ○○さんのブース             │
│ 親子で○○を体験できます     │
│                          │
│ [ ここまでの場所を見る ]   │
│ [ 詳細を見る ]      [閉じる]│
└──────────────────────────┘
```

sheetは3段階とする。

| 状態 | 高さ | 内容 |
|---|---:|---|
| peek | 96〜128px | 名称、番号、カテゴリ、短い一言 |
| medium | 画面40〜55% | 写真、体験内容、対象、場所を見る |
| full | 画面85%以下 | 詳細、出展者情報、SNS/外部CTA |

- 閉じる操作を常に表示する。
- sheetを閉じても選択位置を保持する。
- 外部CTAは遷移先と外部ブラウザで開くことを明示する。
- 医療効果、治療成果、優良性を断定しない。
- 紹介・協賛・PRの場合はラベルを表示する。

## 6. 一覧表示

```text
┌──────────────────────────┐
│ ← ブースをさがす    [地図] │
│ [検索________________]    │
│ [全部][お口][からだ][親子]→│
│                          │
│ 12 [カテゴリ] ○○ブース    │
│    できることを1行         │
│    [地図で見る]            │
│ ──────────────────────── │
│ 13 [カテゴリ] △△ブース    │
│    できることを1行         │
└──────────────────────────┘
```

- 見出し、ブース番号、名称、要約、地図で見るをDOMで提供する。
- 検索対象は名称、番号、許可カテゴリ、運営が登録したキーワードに限定する。
- 0件ではカテゴリ解除と全件表示の操作を提示する。
- 子ども向けだけでなく、保護者が素早く探せる情報密度にする。

## 7. 体操後のブース紹介

ゲームの達成を広告で遮らない。完了祝いを先に見せ、その後に任意の短い紹介を出す。

```text
体操完了
  ↓
「きょう2こめ！」の祝い
  ↓ 800ms以上
小さな紹介カード
┌──────────────────────────┐
│ [PR/村のブース紹介]       │
│ この「お口」テーマを       │
│ 会場で体験できるよ         │
│ [○○ブースを見る] [あとで] │
└──────────────────────────┘
```

- 「あとで」を同じ強さで表示する。
- 1回の体操完了につき最大1件。
- 同一セッションで同じブースを再表示しない。
- 紹介を閉じても体操完了・ミッション・報酬へ影響しない。

## 8. 公平ローテーション

MVPでは家族属性・性別・健康関係者・興味分野による個別推薦を行わない。

候補決定:

```text
1. 公開中かつrotation_enabled=true
2. 完了した体操のtheme tagと一致
3. 一致がなければgeneral候補
4. 同一セッションの表示済みを除外
5. 利用者の直近N件を除外
6. キャンペーン内の表示回数が少ない順
7. 同数の場合だけ安定した疑似ランダム
```

仮設定:

- 直近除外: 5件。
- 同一ブースの再表示間隔: 24時間。
- 体操後紹介の上限: 1セッション3件。

これらは運営検証で調整可能な設定値とする。出展者ごとの最低表示保証や有料枠を設ける場合は、通常ローテーションと分けて表示・レポートする。

## 9. 計測

| イベント | 発生 |
|---|---|
| `venue_map_opened` | マップ表示 |
| `booth_search_used` | 検索確定。検索語本文は送らない |
| `booth_filter_changed` | カテゴリ変更 |
| `booth_marker_selected` | マーカー選択 |
| `booth_intro_impression` | 体操後紹介が可視になった |
| `booth_detail_opened` | medium/full詳細 |
| `booth_map_route_viewed` | 場所を見る |
| `outbound_cta_clicked` | 外部CTA |
| `booth_intro_dismissed` | あとで／閉じる |

公平性確認では、出展者別のeligible回数、impression、詳細、CTAを分ける。表示される資格がなかった回数を分母へ入れない。

## 10. 状態

| 状態 | 表示 |
|---|---|
| 初回読込 | 地図骨格＋村キャラの短い案内 |
| オフライン | 最終取得マップ。外部CTAは接続後を案内 |
| 位置未校正 | ブース名を誤配置せず一覧のみ提供 |
| 検索0件 | 条件解除CTA |
| 素材なし | 共通カテゴリイラスト。壊れた画像を出さない |
| ブース非公開 | 直接URLでも公開しない |
| 混雑・変更 | 運営アナウンスを地図上部へ表示 |

## 11. アクセシビリティ

- すべてのマーカーにブース番号・名称の読み上げ名を付ける。
- 地図操作だけでなく同じ情報へ到達できる一覧を必須にする。
- マーカーのタップ領域は48px以上、主要操作は56pxを目標とする。
- ピンチ操作を必須にせず、拡大・縮小ボタンを用意する。
- 選択、カテゴリ、公開状態を色だけで表さない。
- sheetのfocus trap、戻る、閉じる、見出し関連付けを実装する。
- 文字拡大時は地図を潰さず、sheetをスクロール可能にする。

## 12. 受け入れ基準

- 24件以上のブースでも初期表示が判読できる。
- 375×667で地図とpeek sheetが同時に見える。
- 地図・一覧のどちらからも同じブース詳細へ到達できる。
- ブース位置が未確認の場合、推測した位置を表示しない。
- 体操後紹介がゲーム完了・体操記録を妨げない。
- ローテーションの入力と選定理由を管理ログで追跡できる。
- 同一条件で一部ブースだけが恒常的に選ばれないことをテストする。

# ユーザーワークフロー

## 1. 保護者と子どもの主フロー

```text
保護者                         子ども
  │                              │
  ├ LINE友だち追加               │
  ├ LIFF起動・同意               │
  ├ 家族アンケート ──────────────┐
  │                              ▼
  │                      キャラが村に登場
  │                              │
  └ 端末を渡す ────────────────→ ゲーム
                                 │
                         キャラと体操
                                 │
  ┌ 端末を一緒に見る ←──────────┘
  │
  ├ 今日できたことを確認
  ├ 会話する / 次のミッションを見る
  └ 必要ならブース・イベントを見る
```

## 2. 初回セッション

目標時間は、友だち追加後からゲーム開始まで60秒以内。アンケート回答時でも90秒以内を目標とする。

| 段階 | 利用者の問い | 画面が答えること | 離脱防止 |
|---|---|---|---|
| 歓迎 | 何ができる？ | すぐ遊べるゲームである | CTAは1つ |
| 連携 | なぜLINEが必要？ | 記録とキャラを持ち帰るため | 短文、詳細は展開式 |
| 同意 | 何に使われる？ | 目的・保存単位・問い合わせ先を3行で示す | 全文はリンク、同意で即開始 |
| 初回登録 | なぜ必要？ | 年齢に合う表示、サービス改善、利用傾向の集計に使う | 人数を先に選び、全員分を最短入力 |
| 特典 | 何が変わった？ | 新キャラが村へ来た | 3秒以内 |
| ゲーム | どう遊ぶ？ | 最初の一手を盤面上で教える | 説明スライドを置かない |

## 3. 再訪セッション

```text
LIFF起動
  ↓
セッション復元
  ↓
ホーム
  ├ 「つづきから遊ぶ」
  ├ 今日のミッション 0/3
  ├ 連続5日目
  └ 新しいお便り 1件
```

再訪時は初回登録や説明を繰り返さない。流入元等の任意質問はゲーム後の自然な節目に1問ずつ提示できるが、毎回表示しない。

## 4. 体操ワークフロー

```text
[手動ボタン または 一定プレイ時間後の安全な区切り]
        ↓
キャラ「いっしょに すーっ？」
 [やってみる] [あとで]
        ↓
お手本 3〜10秒
        ↓
自分のペースで真似する
 [いったん止める] [できた]
        ↓
完了保存
        ↓
「きょう2こめ！」＋ミッション更新
```

- カメラによる判定を行わない。
- 実施の正確性を採点しない。
- タイマーだけで強制完了にしない。
- 「できた」は利用者の自己申告とする。
- 自動提案は盤面の消去・補充・演出中に割り込まない。
- 提案間隔は運営が調整可能な設定値とし、MVP既定値は60秒とする（決定-017）。
- スキップ後に即再表示せず、同じ間隔だけスヌーズする。

## 5. 質問の段階取得

### 初回に登録する

- 誰がすわぷよで遊ぶか（子ども / 子どもと大人 / 大人）。
- 子どもが遊ぶ場合、遊ぶ子どもの人数。
- 子ども全員の生まれた年・月と性別。

人数を先に選び、`1 / 3`のように残りを示して1人ずつ入力する。年月と性別は継続保存し、年齢帯を算出する。正確な日付・氏名は取得しない。遊び方は初回から外し、体操を選ぶ文脈で聞く。

### 後から聞ける

- 何で知ったか（初回プレイ後）。
- 興味のあるテーマ（体操選択時）。
- 医療・健康関係者か（事業者・関係者導線のみ）。
- イベントでよかった体験。

### イベント状態で切り替える

| 状態 | 質問例 | 出さない質問 |
|---|---|---|
| 開催前 | `YourTIMEに行く予定はある？` | 誰と来たか、会場で見つけたか |
| 当日・会場内 | `今日は大人と子ども、それぞれ何人？` | 家族 / 親子の重複選択 |
| 開催後 | `YourTIMEには行った？` | 誰と来る予定か |
| 通常時 | イベント質問なし | 同行者・来場質問すべて |

一度にすべて聞かず、必要な目的が決まっている質問だけを出す。

## 6. 異常系ワークフロー

| 状況 | 利用者表示 | 内部処理 |
|---|---|---|
| LINE初期化失敗 | 「LINEとの接続を確認しています」＋再試行 | エラー分類を記録 |
| 未友だち | 追加する価値を1文で説明 | ゲーム開始不可 |
| Supabase停止 | ゲーム継続、記録は端末に一時保存 | 再送キューへ追加 |
| 体操保存失敗 | 「端末に保存しました」 | 成功とは記録しない |
| Harness停止 | ゲームには影響させない | 配信・流入連携だけ停止 |
| 不正QR | 「このQRは使えません」 | 作品IDを露出しない |

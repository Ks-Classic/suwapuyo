# ユーザーワークフロー

## 1. 保護者と子どもの主フロー

```text
保護者                         子ども
  │                              │
  ├ LINE友だち追加               │
  ├ LIFF起動・同意               │
  ├ 家族アンケート ──────────────┐
  │                              ▼
  │                      キャラが村に登場
  │                              │
  └ 端末を渡す ────────────────→ ゲーム
                                 │
                         キャラと体操
                                 │
  ┌ 端末を一緒に見る ←──────────┘
  │
  ├ 今日できたことを確認
  ├ 会話する / 次のミッションを見る
  └ 必要ならブース・イベントを見る
```

## 2. 初回セッション

目標時間は、友だち追加後からゲーム開始まで60秒以内。アンケート回答時でも90秒以内を目標とする。

| 段階 | 利用者の問い | 画面が答えること | 離脱防止 |
|---|---|---|---|
| 歓迎 | 何ができる？ | すぐ遊べるゲームである | CTAは1つ |
| 連携 | なぜLINEが必要？ | 記録とキャラを持ち帰るため | 短文、詳細は展開式 |
| 同意 | 何に使われる？ | 目的・保存単位・問い合わせ先を3行で示す | 全文はリンク、同意で即開始 |
| アンケート | なぜ答える？ | 仲間が増え、イベント改善にも使う | スキップ常設 |
| 特典 | 何が変わった？ | 新キャラが村へ来た | 3秒以内 |
| ゲーム | どう遊ぶ？ | 最初の一手を盤面上で教える | 説明スライドを置かない |

## 3. 再訪セッション

```text
LIFF起動
  ↓
セッション復元
  ↓
ホーム
  ├ 「つづきから遊ぶ」
  ├ 今日のミッション 0/3
  ├ 連続5日目
  └ 新しいお便り 1件
```

再訪時はアンケートや説明を繰り返さない。未回答質問はゲーム後の自然な節目に1問ずつ提示できるが、毎回表示しない。

## 4. 体操ワークフロー

```text
[手動ボタン または 一定プレイ時間後の安全な区切り]
        ↓
キャラ「いっしょに すーっ？」
 [やってみる] [あとで]
        ↓
お手本 3〜10秒
        ↓
自分のペースで真似する
 [いったん止める] [できた]
        ↓
完了保存
        ↓
「きょう2こめ！」＋ミッション更新
```

- カメラによる判定を行わない。
- 実施の正確性を採点しない。
- タイマーだけで強制完了にしない。
- 「できた」は利用者の自己申告とする。
- 自動提案は盤面の消去・補充・演出中に割り込まない。
- 提案間隔は運営が調整可能な設定値とし、MVP既定値は60秒とする（決定-017）。
- スキップ後に即再表示せず、同じ間隔だけスヌーズする。

## 5. アンケートの段階取得

### 初回に聞く

- 誰と来た／利用しているか。
- 子どもの人数と大まかな年齢帯。
- 何で知ったか。
- 回答する保護者が医療・健康関係者か。
- 子どもごとの性別（男・女・答えない。任意。決定-016）。

### 後から聞ける

- 興味のあるテーマ。
- 来場予定・来場済み。
- イベントでよかった体験。

一度にすべて聞かず、必要な目的が決まっている質問だけを出す。

## 6. 異常系ワークフロー

| 状況 | 利用者表示 | 内部処理 |
|---|---|---|
| LINE初期化失敗 | 「LINEとの接続を確認しています」＋再試行 | エラー分類を記録 |
| 未友だち | 追加する価値を1文で説明 | ゲーム開始不可 |
| Supabase停止 | ゲーム継続、記録は端末に一時保存 | 再送キューへ追加 |
| 体操保存失敗 | 「端末に保存しました」 | 成功とは記録しない |
| Harness停止 | ゲームには影響させない | 配信・流入連携だけ停止 |
| 不正QR | 「このQRは使えません」 | 作品IDを露出しない |

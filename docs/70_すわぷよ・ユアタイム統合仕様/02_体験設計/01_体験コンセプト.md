# 体験コンセプト

## 1. 一文

すわぷよは、子どもがキャラクターと遊んでいるだけで短い体操を重ねられ、保護者には「今日できたこと」がやさしく残る、持ち帰れる村の遊び場である。

## 2. 体験の三層

```text
表層: かわいいキャラクターゲーム
      「消えた」「連鎖した」「仲間が増えた」
                     ↓
中層: 体操・ミッション・継続
      「今日は2つできた」「5日目」
                     ↓
深層: イベント・人・地域との接点
      「このキャラのブースへ行ってみたい」
```

利用者にCRMや健康管理を意識させない。データ取得は体験の副産物であり、体験を止めて入力させることを目的にしない。

## 3. 世界観

デザインテーマは「動く絵本の村」。既存の明るい空、芝生、家、丸みのあるキャラクターを残し、画面を業務アプリ風カードの集合から、ひとつの舞台へ変える。

### 残すもの

- 青空、緑、木、家、村の遠景。
- すーすー、わーわー等のキャラクター。
- オレンジ、クリーム、暖色ブラウン。
- 連鎖・獲得・降臨の遊び心。
- 丸みと安心感。

### 捨てるもの

- 絵文字を主役にした仮UI。
- すべてを同じ白カードへ入れる構成。
- 不要な磨りガラス、強いblur、安易なグラデーション。
- 「質問 3/6」のような業務フォーム感。
- 説明文を読まないと操作できない画面。
- 1画面に多数のCTAを並べる構成。

## 4. 感情の流れ

| 場面 | 感情 | UIの役割 |
|---|---|---|
| LINE追加 | 好奇心 | すぐ遊べる約束を明確にする |
| 初回起動 | 歓迎 | キャラが名前を呼ばずに迎える |
| アンケート | 自分ごと化 | 答えるたび村の仲間が増える |
| ゲーム | 没頭 | 盤面を最優先し操作を迷わせない |
| 体操 | 一緒にやる | 指示ではなくキャラの真似として見せる |
| 完了 | 小さな達成 | 1秒以内に結果を返し、短く祝う |
| 記録 | 誇らしさ | 数字より「できた」を先に見せる |
| ブース紹介 | 発見 | 広告ではなく村の住人との出会いにする |

## 5. 子どもと保護者の二重利用

同じ端末でも役割が違う。

```text
子どもが触る領域:
ゲーム / キャラ選択 / 体操 / ミッションの受取

保護者が読む領域:
アンケート / 同意 / すわぷよ内の記録 / 会場マップ / 外部リンク / データ設定
```

保護者向け操作は、キャラクターの世界観を壊さず、文字量・根拠・戻る手段を増やす。外部遷移、回答削除、通知設定は保護者確認を挟む。

## 6. ゲーミフィケーションの境界

- 褒める対象は「参加した」「続けた」「新しい種類を試した」。
- 連続日数が切れても責めない。「また今日から」にする。
- 子ども同士、家族同士を順位付けしない。
- 無限スクロール、ガチャ課金、ランダム報酬、失敗煽りを使わない。
- 報酬条件は事前に見せ、到達可能にする。
- 体操はいつでもスキップでき、ゲームの進行を完全には塞がない。

## 7. デザイン評価基準

「最新らしい見た目」ではなく、次を満たした時に一流品質とする。

1. 初見で次の操作が1つに見える。
2. キャラクターが装飾でなくナビゲーションとして機能する。
3. 選択が世界へ即座に反映される。
4. 小さい端末でも情報が潰れない。
5. 動き、音、触覚が同じ意味を伝える。
6. 動きを減らしても意味が失われない。
7. デモ用の嘘と実データが明確に区別される。

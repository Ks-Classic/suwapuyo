# 画面UI定義

> ASCIIは情報階層と操作位置の仕様であり、最終的な絵柄そのものではない。キャラクター・背景・専用アイコンは既存資産を再編集して使用する。

## 1. LINE入口

```text
┌──────────────────────────┐
│ LINEトーク                │
│                          │
│ [村のイラスト＋キャラ]    │
│ すわぷよが オープンしたよ │
│ 遊ぶとキャラと体操できるよ│
│                          │
│ [ すわぷよで遊ぶ ]        │
│                          │
├────────┬────────┬────────┤
│すわぷよ │きろく   │会場案内 │
├────────┼────────┼────────┤
│むら図鑑 │お便り   │つかい方 │
└────────┴────────┴────────┘
```

主CTAは1つ。リッチメニューの絵柄はゲーム内世界と同じ素材・線・色を使う。

## 3. 初回の体験設定

```text
┌──────────────────────────┐
│ ←                 保護者用│
│      ○──○──○             │  村への小道。数字は出さない
│                          │
│ [わーわー]                │
│ だれが すわぷよで遊ぶ？  │
│                          │
│ ┌──────────┐ ┌──────────┐│
│ │ お子さん  │ │子どもと大人││
│ └──────────┘ └──────────┘│
│ ┌──────────┐ ┌──────────┐│
│ │   大人    │              │
│ └──────────┘              │
└──────────────────────────┘
```

選択するとカードへチェックを付けるだけでなく、背景の村へ仲間が登場して次の質問へ進む。自動前進は選択の反映を200ms以上見せてから行う。

### 子どもの人数と情報

```text
┌──────────────────────────┐
│ 遊ぶお子さんは何人？       │
│                          │
│ [1人] [2人] [3人] [4人]   │
│ [5人以上]                 │
└──────────────────────────┘

┌──────────────────────────┐
│ 1人目のお子さん      1 / 3 │
│                          │
│ [ 2021年 ▼ ] [ 5月 ▼ ]   │
│ 性別                     │
│ [女の子] [男の子]         │
│ [その他] [答えたくない]    │
│                          │
│ [次のお子さんへ]           │
└──────────────────────────┘
```

日付と氏名は聞かない。先に人数を選び、全員分の生まれ年・月と性別を入力する。年月と性別を継続保存し、年齢帯はサーバーで算出する。性別の`答えたくない`は有効回答とし、未入力と区別する。

遊び方は初回登録から外す。体操を選ぶ文脈で`お口 / からだ / おまかせ`を任意選択できる。

### 初回から外す質問

- 流入きっかけは初回プレイ後に任意で聞く。
- 医療・健康関係者かは事業者・関係者導線でだけ聞く。
- 同行人数はイベント当日・会場内でだけ、大人と子どもの人数を分けて聞く。
- 興味分野は体操選択時に必要になった段階で聞く。

## 4. キャラクター登場

```text
┌──────────────────────────┐
│        空から光           │
│                          │
│        [新キャラ]         │
│       ぽんっ              │
│                          │
│  村のなかまになった！     │
│ 「ゲームでつかえるよ」    │
│                          │
│ ┌──────────────────────┐ │
│ │     いっしょに遊ぶ    │ │
│ └──────────────────────┘ │
└──────────────────────────┘
```

全キャラクターの姿と名前は一覧で最初から見せ、シルエットや秘密枠にしない。アンケート完了で全キャラクターが一括で村へ登場する（決定-019）。演出は代表キャラの登場＋残りの仲間が続けて現れる群登場とし、1体ずつフル演出を繰り返さない。合計3秒以内に操作可能へ戻し、閉じる手段を隠さない。

## 6. ゲーム

```text
┌──────────────────────────┐
│ ×  SCORE 1,240      🔊   │
│ [相棒の短いリアクション]  │
│ ┌──────────────────────┐ │
│ │                      │ │
│ │     6×8〜6×9盤面      │ │
│ │   盤面を最大化する    │ │
│ │                      │ │
│ └──────────────────────┘ │
│ [最初の一手だけ指差し]    │
│                          │
│ [ 体操タイム ]   [相棒]   │
└──────────────────────────┘
```

現行6×10は小端末でキャラが潰れるため、視認性・ゲーム性を実機検証し、行数を仮決定する。会場マップや案内所CTAはゲーム画面から外す。

```text
┌────────────────────────────────────┐
│ 運営ダッシュボード                 │
├──────────┬─────────────────────────┤
│ 利用状況  │ LINE   正常 / 最終受信  │
│ 出展者    │ IG     警告 / 期限7日   │
│ 投稿      │ LIFF   正常              │
│ レポート  │ Supabase 正常            │

│ 監査      │ 保存失敗2 / 再送待ち2   │

```

管理画面はPCを主対象とし、利用者向け世界観よりも誤操作防止・監査性を優先する。

## 12. 起動・認証（画面-001）

```text
┌──────────────────────────┐
│        村の遠景（静か）    │
│                          │
│       [すーすー]          │
│  むらへ つれていくね…     │
│        ● ● ○             │
│                          │
│ 失敗時:                   │
│ LINEとの接続を            │
│ 確認しています             │
│ [もういちど] [困ったとき]  │
└──────────────────────────┘
```

- 認証中はスピナーではなくキャラの待機表現1種（Reduce Motionでは静止画）。
- 進行表示は3秒以上かかる場合のみ出す。
- エラー分類（初期化失敗／未ログイン／トークン失効）で文言を変え、内部コードを見せない。

## 13. 友だち追加案内（画面-002）

```text
┌──────────────────────────┐
│       [わーわー]          │
│  ともだちになると         │
│  きろくとキャラを         │
│  もちかえれるよ           │
│                          │
│ ┌──────────────────────┐ │
│ │ LINEでともだちになる  │ │
│ └──────────────────────┘ │
│ なぜ必要？（展開式の短文） │
└──────────────────────────┘
```

- 追加操作後は友だち状態を自動で再確認し、成功したら元の目的地（ディープリンク先）へ戻す。
- 拒否・離脱時に全画面で繰り返し迫らない。価値説明は1文（`02_ユーザーワークフロー.md`の離脱防止方針）。

## 14. 同意ステップ（画面-018、初回歓迎内sheet）

```text
┌──────────────────────────┐
│ はじめるまえに（保護者用） │
│                          │
│ ・きろくは家族単位で保存   │
│ ・お名前・住所はきかない   │
│ ・イベント改善に集計利用   │
│ 全文をみる / 問い合わせ先  │
│                          │
│ ┌──────────────────────┐ │
│ │  同意してはじめる     │ │
│ └──────────────────────┘ │
│ [やめる]                  │
└──────────────────────────┘
```

- 「同意してはじめる」で`consent_records`（purpose=product）へ表示文面の版付きで記録する。それ以前に利用者データを保存しない。
- アンケート冒頭ではsurvey目的の1行説明を再掲し、別レコード（purpose=survey）で記録する。
- 全文・撤回・削除依頼は保護者メニュー（画面-015、MVPでは本sheetへの静的リンク）から常時到達できる。

## 15. キャラクター選択（画面-008）

```text
┌──────────────────────────┐
│ ← いっしょにあそぶ なかま │
│                          │
│ [すーすー]   [わーわー]   │
│  きてる       きてる      │
│ [キャラC]    [キャラD]    │
│  まだ         まだ        │
│                          │
│ まだの子も すがたと       │
│ なまえは ぜんぶ見られる   │
│                          │
│ [ このこと あそぶ ]       │
└──────────────────────────┘
```

- 全キャラクターの姿と名前を常時表示する（決定-005。シルエット・秘密枠禁止）。
- 未登場キャラには登場条件（例: アンケートで村に呼べる）を1行で表示する。
- 選択は`character_arrivals`の登場済みキャラに限定し、未登場キャラのタップは登場条件の案内を出す。

## 16. ミッション（画面-011）

```text
┌──────────────────────────┐
│ きょうのミッション        │
│ ●━━━━●━━━━○   2/3        │
│                          │
│ ✓ たいそう 1かい [うけとる]│
│ ✓ あたらしい たいそう     │
│ ○ もう1かい たいそう      │
│    ほうび: ほし 1つ       │
│                          │
│ こんしゅう                │
│ ○ 3にち あそぶ (2/3)      │
├────────┬────────┬────────┤
│ あそぶ  │ きろく │  むら  │
└──────────────────────────┘
```

- 条件・進捗・報酬を事前表示する（機能-206）。報酬の受取は明示タップとし、二重付与しない（`POST /api/missions/:id/claim`）。
- 未達成を赤・失敗色で表現しない（「あと1こ」方式）。
- 週境界はJST（機能-207）。

# デモ・LINE・Instagram運用

## 1. デモの目的

技術一覧を見せるのではなく、次の物語を実際に操作して見せる。

> Instagramで知った親子がLINEからすわぷよを始め、遊びながら体操し、その接点がイベントと出展者の価値として見える。

## 2. デモ台本

| 0:00 | Instagramのテスト投稿または投稿モックを見る | AI/SNS運用の入口 |
| 0:30 | 安全性Gate通過時のみDMからLINEへ進む | IG Harnessの追加デモ |

## 3. デモモード

外部アカウントの準備が間に合わない場合でも、見た目だけ成功させてはいけない。各状態を明示する。

| 表示 | 意味 |
|---|---|
| 実接続 | 実LINE/IG/Supabaseから取得 |
| テスト接続 | テストアカウント・テストデータ |
| デモデータ | 静的fixture。外部送信なし |
| 未接続 | 設定未完了。成功演出を出さない |

レポート画面には常時データ種別バッジを表示する。

## 4. LINE公式アカウント運用

### あいさつ

```text
ようこそ、すーすーわーわーの村へ。

親子で遊べる「すわぷよ」がオープンしたよ。
遊んでいると、ときどきキャラクターと体操できるよ。

[すわぷよで遊ぶ]

配信はイベントや新しい遊びのお知らせを中心に、送りすぎないよう運用します。
```

- 主CTAは1つ。
- データ利用の詳細をあいさつへ詰め込まず、LIFF内で説明する。
- 配信頻度は週1回以下を初期原則とする。
- 緊急でない通知を夜間へ送らない。
- 自動シナリオはテストアカウントで全分岐を確認してから公開する。

### リッチメニュー

MVPは「すわぷよ」「きろく」「会場案内」を上段へ置く。下段に「事業者の方へ」を置き、タップで事業者向け案内と事業者タグ付与を行う（`biz_intro_opened`。B2B導線の正本は`02_IG発信・B2B獲得戦略.md`）。未実装メニューを押せる状態で出さない。

## 5. Instagram運用

今回のアカウントは、歯科・健康情報だけに寄せない。

### コンテンツ柱

1. キャラクターの日常・パロディ・遊び。
2. AIで何が作れるかの実演。
3. すわぷよ・ふわふわランドの制作裏側。
4. YourTIME出展者の紹介。
5. 未病レベルの生活ヒント。

### CTA

- 「コメントで○○」は特典が本当に受け取れる時だけ使う。
- DMからLINEへ送る理由を説明する。
- follow gateを過剰に繰り返さない。
- PR、協力、提供関係は明示する。
- AI生成物は人物・医療・権利を人が確認してから公開する。

発信の戦略・ファネル構造は`02_IG発信・B2B獲得戦略.md`を正本とする。AI投稿のバズ設計、キャラクター台本、投稿カレンダーはさらに別文書として作る。

## 6. 日次運用

### 公開前

- LINE/IG token期限。
- LINE公式アカウントのプランと当月配信通数の残量（無料プランは月200通。友だち数×配信頻度で事前見積り。Gate H-10）。
- Webhook最終受信。
- LIFF URLと友だち状態。
- Supabase接続。
- テストユーザーでゲーム→体操→記録。
- レポートのデータ種別。

### 公開中

- 失敗率、retry、重複処理。
- LIFF起動とゲーム開始の落差。
- 体操保存失敗。
- 外部送信の承認待ち。

### 公開後

- 配信停止・削除依頼。
- 出展者集計の少数秘匿。
- レポート文面の人手レビュー。
- tokenや権限の不要分を失効。

削除依頼の本人確認は、LIFF内の保護者メニュー（本人セッション＝本人確認）を第一経路とする。LINEトーク経由の依頼は該当アカウントの`user_identities`で対象を特定する。担当: 木幡。

プロダクトデータ削除依頼ではSupabase上のアンケート・プレイ・体操記録を対象にする。LINE/IG Harnessはこれらの記録を保持しないため同じ削除ジョブの対象外とする。ただし、LINE友だち・IG会話等のチャネルデータまで含む包括的な削除依頼は、各Harnessの別ポリシーで扱う。

## 7. ロールバック

| 障害 | 対応 |
|---|---|
| 新UI不具合 | 前のCloudflare deploymentへ戻す |
| Product API不具合 | 書込を止め、端末キューへ退避 |
| LINEシナリオ誤送信 | 対象シナリオ停止、予約取消、監査確認 |
| IG自動DM誤作動 | gate停止、tokenは必要時のみ失効 |
| DB migration不具合 | 承認済みdown/forward fix手順を実行 |

本番変更、DB migration、外部配信開始は承認後に行う。

> 暫定版: 2026-07-12  
> 用途: Instagramのブース紹介投稿から公開用ブース台帳を作るための確認作業用。本文書は公開済みデータの正本ではない。

## 1. 取り扱いルール

- 候補は `@your_time.niw` のブース紹介26投稿から会話中に抽出した情報であり、運営の確定リストとの照合前である。
- 投稿画像のOCRや目視読み取りに依存する名称は「要確認」とし、推測のまま公開しない。
- 投稿画像は転載しない。ロゴ、写真、本文、アイコンを利用する場合は個別に利用許諾を確認する。
- 一行説明は投稿本文の引用ではなく、名称から分かる範囲の暫定要約である。効果、診断、治療、予防を断定する表現は入れない。
- 出展者名、屋号、handle、カテゴリ、公開文言、CTA、対象年齢、ブース番号は、出展者またはYourTIME.運営の承認後にのみ `confirmed` にする。

## 2. 公開用schema

| 項目 | 必須 | 説明 |
|---|---:|---|
| `source_post_url` | 必須 | `@your_time.niw` の該当紹介投稿URL |
| `display_name` | 必須 | 運営承認済みの公開名。法人名とブース名は分離可 |
| `instagram_handles` | 任意 | 公式性を確認済みのhandle。複数可 |
| `category` | 必須 | 運営の統制語彙から1つ選択 |
| `short_description` | 必須 | 来場者向け1文。医療・健康効果は断定しない |
| `confirmation_items` | 必須 | 未確定、OCR不確実、表記ゆれ、許諾必要事項 |
| `verification_status` | 必須 | `unverified` / `partially_verified` / `confirmed` |
| `booth_no` | 公開前必須 | 会場の確定対応表から転記。推測禁止 |
| `public_cta_url` | 任意 | 出展者と運営が承認した遷移先 |
| `asset_permission` | 公開前必須 | `not_requested` / `requested` / `approved` / `declined` |

暫定カテゴリは「食」「歯科・お口」「運動・からだ」「親子・教育」「暮らし・ケア」「エンタメ・クリエイティブ」「企業・その他」とする。公開UIの統制語彙は運営確認後に固定する。

## 4. 公開前に運営が確定すること

1. 26投稿が「26ブース」と一対一かを確認する。#6と#15のような共同出展・個人出演は、ブース数と一致しない可能性がある。
2. 会場図のブース番号と出展者の対応表を正本とし、旧データの番号・座標は流用しない。
3. 各出展者へ「公開名、handle、一行説明、CTA、カテゴリ、対象年齢、画像/ロゴ許諾」を一括確認する。
4. 食品はアレルゲン、運動体験は対象年齢と安全上の注意、医療・健康関連は断定表現と表示主体をそれぞれ専門確認する。
5. ブースではなくステージプログラムの候補は、マップピンとは分けてタイムテーブルに登録する。

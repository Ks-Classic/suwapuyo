# 機能要件一覧

## 1. LINE・認証

| ID | 機能 | 優先度 | 受け入れ条件 |
|---|---|---|---|
| 機能-001 | LIFF初期化 | P0 | LINE内・外部ブラウザ双方で状態が確定する |
| 機能-002 | LINE Login | P0 | 未ログイン時のみ実行し、戻り先を保持する |
| 機能-003 | 友だち状態確認 | P0 | `friendFlag`を取得し、未追加時はゲーム・記録・マップ・ブース紹介を開かない |
| 機能-004 | サーバートークン検証 | P0 | 偽造・期限切れトークンでセッションが発行されない |
| 機能-005 | 内部セッション | P0 | LINE識別子をURL・ログへ出さない |
| 機能-006 | 流入元取得 | P0 | 許可済みsourceだけを初回値として保存する |

## 2. アンケート・特典

| ID | 機能 | 優先度 | 受け入れ条件 |
|---|---|---|---|
| 機能-101 | 会話型アンケート | P0 | 1画面1問、キーボードなし、スキップ可 |
| 機能-102 | 家族構成 | P0 | 大人・子どもの人数と年齢帯を任意取得 |
| 機能-103 | 流入きっかけ | P0 | Instagram、紹介、出展者、公式等を取得 |
| 機能-104 | 回答保存 | P0 | 同意版と回答時刻を記録 |
| 機能-105 | 回答特典 | P0 | アンケート完了で全キャラが一括登場（決定-019）。全キャラの姿・名前は常時表示し、隠し枠を作らない |
| 機能-106 | 回答修正・削除 | P1 | 保護者が後から変更・削除依頼できる |
| 機能-107 | 健康関係者 | P0 | 回答者が医療・健康関係者かを回答できる |
| 機能-108 | 興味分野 | P1 | 任意で複数分野を選べる。MVPローテーションの個人最適化には使わない |
| 機能-109 | 性別 | P0 | 子どもごとに男・女・答えないを任意取得する（決定-016）。配信条件には使わない |

| 機能-207 | ウィークリーミッション | P1 | 週境界をJSTで一貫して計算 |
| 機能-208 | オフラインキュー | P0 | 失敗イベントを端末キューへ退避し、復帰後に再送して二重加算しない（決定-012でP0昇格） |

## 6. スコープ外

- 医療診断、治療提案、健康状態のスコアリング。
- 子どもの顔認識、音声認識、位置の常時追跡。
- 本番での無承認自動投稿・一斉配信。
- 出展者間の順位付けを主目的にしたランキング。
- D1とSupabaseの全データ同期。

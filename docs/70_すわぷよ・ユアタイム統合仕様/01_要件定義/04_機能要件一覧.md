# 機能要件一覧

## 1. LINE・認証

| ID | 機能 | 優先度 | 受け入れ条件 |
|---|---|---|---|
| 機能-001 | LIFF初期化 | P0 | LINE内・外部ブラウザ双方で状態が確定する |
| 機能-002 | LINE Login | P0 | 未ログイン時のみ実行し、戻り先を保持する |
| 機能-003 | 友だち状態確認 | P0 | `friendFlag`を取得し、未追加時はゲーム・記録・マップ・ブース紹介を開かない |
| 機能-004 | サーバートークン検証 | P0 | 偽造・期限切れトークンでセッションが発行されない |
| 機能-005 | 内部セッション | P0 | LINE識別子をURL・ログへ出さない |
| 機能-006 | 流入元取得 | P0 | 許可済みsourceだけを初回値として保存する |

## 7. スコープ外

- 医療診断、治療提案、健康状態のスコアリング。
- 年齢情報だけによる「その子に最適」「改善する」等の個別適合・効果保証表現。
- 子どもの顔認識、音声認識、位置の常時追跡。
- GPS、Bluetooth、Wi-Fiによる会場内の受動的位置追跡。
- 本番での無承認自動投稿・一斉配信。
- 出展者間の順位付けを主目的にしたランキング。
- D1とSupabaseの全データ同期。
- 子ども用タブレットからの管理設定変更、作品削除、公開判定。
- 子どもの絵の上手さを採点・順位付けする機能。

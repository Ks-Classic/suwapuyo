## 2. 役割

| 役割 | 見られるもの | できること |
|---|---|---|
| 利用者（保護者） | 自家族の進捗 | プレイ、アンケート、記録確認 |
| 子ども | ゲーム・体操・お絵描き・キャラ登場演出 | お絵描き専用タブレットでは管理画面へ移動できない |
| 出展者 | 自社の集計レポート | 閲覧、期間切替、共有 |
| 運営スタッフ | 確認待ち作品、公開中キャラ、ランド、端末状態、許可された設定 | PCを主端末に編集・公開・非表示。スマホからも主要操作を行う |
| システム管理者 | 外部連携・監査・エラー | 設定、復旧、権限管理 |

## 3. 業務上の禁止事項

- 子ども本人のLINEアカウント取得を前提にしない。
- 年齢・性別・行動を健康状態・疾病・発達の推定に使わない。
- 年齢・性別・行動の集計分析は初回利用目的に含める。個人別販促、外部データ突合、第三者提供は追加同意なしに行わない。
- 体操回数から疾病・発達・健康状態を推定しない。
- 出展者へ個人別のLINE識別子や回答を開示しない。
- InstagramやLINEへの自動送信を、人の承認なしで本番有効化しない。
- 外部連携失敗を成功として記録しない。
- ブース訪問者の自己申告を、確認済み購入・売上実績として表示しない。
- 子ども用お絵描き画面へ作品公開、削除、端末設定、同意範囲等の管理操作を表示しない。
- 未確認作品を大画面へ自動公開しない。
- 当日中の問題作品は即時削除を基本とせず、まず非表示または保管として復旧可能にする。

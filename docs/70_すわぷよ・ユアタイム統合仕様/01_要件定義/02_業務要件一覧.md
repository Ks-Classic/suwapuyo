# 業務要件一覧

## 1. 要件

| ID | 対象 | 要件 | MVP | 成功判定 |
|---|---|---|---|---|
| 業務-001 | 運営 | LINE公式アカウントをすわぷよの共通入口にする | 必須 | あいさつ・リッチメニューからLIFF起動 |

| 業務-006 | 利用者 | 体操の累計・種類別・継続日数を確認する | 必須 | Write→Read→Displayが一致 |
| 業務-007 | 利用者 | 今日・今週のミッションを確認する | 必須 | 達成条件と報酬を事前表示 |

| 業務-009 | 出展者 | 自社紹介への接点を集計で確認する | 必須 | 個人を特定しないレポート |

| 業務-017 | 利用者 | 関連する公認医院を探す | 将来 | 地域・テーマから任意遷移 |

## 2. 役割

| 役割 | 見られるもの | できること |
|---|---|---|
| 利用者（保護者） | 自家族の進捗 | プレイ、アンケート、記録確認 |
| 子ども | ゲーム・体操・キャラ登場演出 | 保護者端末上で操作 |
| 出展者 | 自社の集計レポート | 閲覧、期間切替、共有 |
| 運営スタッフ | 会場・コンテンツ・集計 | 編集、公開、エクスポート |
| システム管理者 | 外部連携・監査・エラー | 設定、復旧、権限管理 |

## 3. 業務上の禁止事項

- 子ども本人のLINEアカウント取得を前提にしない。
- 家族構成を配信対象の過剰な細分化や医療推定に使わない。
- セグメント配信の軸はMVPでは行動・流入元に限定し、家族属性・医療関係者回答・興味分野を配信条件にしない（決定-014）。
- 体操回数から疾病・発達・健康状態を推定しない。
- 出展者へ個人別のLINE識別子や回答を開示しない。
- InstagramやLINEへの自動送信を、人の承認なしで本番有効化しない。
- 外部連携失敗を成功として記録しない。

## 0. 一行サマリ＋3秒ポジショニング

**一行**: 子どもが塗った絵がその場で「村」に生きて動き出し、親子が遊びながら未病・口腔育成を好きになる——その村＝YourTIMEを、木幡がAIエンジンで回し、出展者を送客し、裏では自分のAI案件につなげる連動モデル。

**3秒ポジショニング（相手別）**

| 相手 | タグライン | 補助メッセージ |
|---|---|---|
| 来場親子 / YourTIME | **「未病を、親子が“遊んで”好きになる村。」** | 説教の前に、好きにさせる。 |
| 出展者 | **「あなたの専門を、子どもが駆け寄るキャラにする。」** | 遊べる広告＋送客を、無料の1本から。 |
| 裏アカ（木幡AI）→企業/事業者 | **「この村、ぜんぶAIで回してます。あなたの会社でも。」** | 作り方と企業AI活用を見せて、相談につなぐ。 |

> ポジショニングは全施策の母。チャネル・営業ピッチ・出展者提案・顧問LP・サムネ文言は、必ずこの3レイヤーのどれかから派生させる。

## 3. North-star＋メトリクスツリー／ファネル

### 3.1 North-star＝「タップ→出展者送客数」
理由: 1指標で〈製品の効果・出展者の効果レポート・諏訪さんを落とす数字・課金の根拠〉を同時に満たす。フォロワー数でなく**件数×行動**で測る（戦略md 6章のKPI逆算と一致）。

### 3.2 メトリクスツリー（北極星の分解）
```
タップ→送客数
├ 会場経路: ロゴ浮遊tap数 → ポップアップ開封 → CTAクリック(LINE/HP) 
│   └ ドライバ: featured露出回数 × 親スマホ誘導(QR)成功率 × 事前展開での事前タップ
└ SNS経路: 動画view → プロフ遷移 → LINE/HP → 出展者へ送客
    └ ドライバ: 投稿本数 × フック維持率(3秒) × CTA明示
```

### 3.3 ファネル各段の定義と計測
| 段 | 定義 | 計測方法 |
|---|---|---|
| view | ショート視聴 | 各プラットフォーム解析 |
| プロフ遷移 | 動画→アカウントへ | 同上 |
| LINE/HP | 外部遷移 | **UTM＋`/r/*`リダイレクト**で実数化 |
| リード | 出展者/事業者が反応・問い合わせ | LINE登録・フォーム・DM |
| 受託 | 単発案件成立 | 件数×単価 |
| 顧問 | 月額契約 | MRR・継続月数 |

実装は§11（Supabase events/sponsors、`/r/*`）。

## 6. 表ステージ詳細

### 6.1 会場ふわふわランド（絵が出る＋感情ピーク）
- 体験核: 塗る→撮影→数秒で大画面に登場→**自分の絵を見つける**。
- **感情ピーク（=この製品が存在する唯一の理由）の演出設計**（槍A・実装はGate）:
  - 新規作品の登場＝中央からズームイン＋きらめき＋効果音「ピロン」＋0.8秒スポット → 名前ラベル一瞬拡大 → その後ドリフト合流。
  - 登場後5秒「いまここ！」ハイライトリング（12〜30体の中から自分を探せる）。
  - 既存ドリフトと同じ静かな紛れ込みは禁止（“感動を運任せ”にしない）。
- 年齢2レーン（UX指摘）: 〜5歳=紙主導・名前は親・探すのは親が指さす／6〜9歳=デジタル描画可・自分で名前・自分で探す。

### 6.2 出展者ロゴ浮遊→tap→送客
- ロゴ/キャラが村に浮遊。タップ→かわいいポップアップ（店名・ひとこと・CTA）→送客。
- **UX補正（重要）**: 大画面モニターは子も親も触れない／スタッフが触るとショーが止まる。→ **送客は「親のスマホ」で完結**：featured時に「ブースこっち→」吹き出し＋QR。
- **事前展開**: ロゴを事前公開し、みんながスマホで触れるWeb版を用意＝会場前から計測（tap）が回る・当日の混雑緩和。
- 汎用スポンサー枠（coralup＝もぐぴよが1号）。横展開で全出展者へ＝裏パートナーの技術backbone（§11）。

### 6.3 SNS表アカ（ススワワ公式）
- 位置づけ: YourTIMEの**公式SNSの空き地を木幡が立ち上げ運用＝諏訪さんへの最大GIVE**（裏パートナー入口）。トーンは村＝諏訪/小夏の世界観に従属、営業色を出さない。
- **投稿カデンス**: 週次でキャラ別固定枠（例: 月=もぐぴよ口腔/水=シンボー呼吸/金=けとにゃん健康、随時=出展者紹介＆討伐ネタ）。
- **フック式**: 最初3秒で「悪役 or 質問」（例「お口ぽかーん、危険信号かも？」）。中身＝字幕が担う（医療広告事故回避）。
- **サムネ規則**: キャラ大写し＋白フチ太字3語。話者で字幕色（青/オレンジ）。
- **ファネル計測**: 各動画→LINE/HPに**UTM/タグ**、view→プロフ→LINE→リードを数える（§3）。
- 量産は `shorts/render.py`＋`script.json`（限界費用≈0）。コンプラは `医療広告・コンテンツ方針.md` を必ず通す。

## 7. 裏ステージ詳細（木幡AIキャラ裏アカ）

### 7.1 目的
木幡自身の最強リード装置。表で実演した「作れる力」を、裏で「作り方／企業のAI活用」に翻訳し、**AIコンサル・顧問・受託の相談入口**にする。

### 7.2 コンテンツ種別とテーマ
| 種別 | 内容 | 狙い |
|---|---|---|
| 裏アカ ショート | 「これ、どう作ってるの？」舞台裏（量産パイプライン/animalese/セーフゾーン等） | “作れる人”の証明・拡散 |
| 本格動画 | 企業・組織でのAI活用の実践解説（業務自動化・LINE/freee/Notion連携=木幡本業） | 信頼・専門性 |
| Note / X 連載 | 設計・運用・ナレッジの言語化（この事業地図自体も素材） | 検索流入・深い信頼 |

### 7.3 案件導線（プロセスエコノミー）
```
表で実演（村が動く・ショートが出る）
  → 裏アカで「作り方／企業AI活用」を発信
    → 「うちもやりたい」反応
      → 相談（無料/低額GIVE）
        → 単発受託（数十万）
          → AI伴走（月額顧問・本命）
```
- 毎ショート末に小さく「これもススワワがAIで作ってます」。
- 「ススワワ開発室」裏側シリーズを木幡名義のX/Noteで連載。
- 表（公式・村）と裏（個人・営業）は分離。裏アカで村の権威を借りすぎない。

## 11. KPI/計測の実装要点

### 11.1 データモデル（Supabase）
```
sponsors(
  id, name, character_img, logo, popup_title, popup_body,
  cta_url, qr_url, theme, active
)
events(
  id, type, sponsor_id, artwork_id, session_id, ts
)   -- type: artwork_register | appear | tap | popup_open | cta_click
```

### 11.2 送客の実数化
- CTAは必ず**リダイレクト経由**: `/r/coralup?src=fuwafuwa` → `cta_click` を記録してから外部遷移。
- SNSは**UTM**（`utm_source=ss_short&utm_medium=ig&utm_campaign=mogu_oguchi`）でファネル接続。

### 11.3 効果レポート（GIVE→受託→顧問の証拠）の構成
1. 露出: ショート再生・保存・プロフ遷移
2. 送客: tap数・ポップアップ開封・CTAクリック・LINE/HP着地
3. 会場: featured回数・滞留（定性）・歓声（定性）
4. 示唆: 「次の一手」提案（＝アップセルの起点）

> このレポートが無いと、何を作っても「で、効果は数字で？」（世界一の審査員/出展者/諏訪さんの最初の質問）に答えられない。**計測は槍Bと同時に計装する。**

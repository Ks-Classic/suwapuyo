# 医療広告・薬機法 コンテンツポリシー（ススワワ発信の前提）

> 適用: すーすーわーわーが作る全ショート/投稿/ブログ(特に出展者=歯科・医療職・健康事業者の紹介、口腔育成/健康テーマ)。
> 立場: これは制約でなく**差別化**。「規制を分かった上でAI発信できる人」は希少。出展者(医療職)が安心して任せられる理由になる。
> 最終責任: 医療機関自身の広告は当該機関に最終責任。紹介側も誇大・虚偽に加担しない。判断に迷う表現は出さない or 専門家確認。

## 効く法令(ざっくり)
| 法令 | 対象 | 主なNG |
|---|---|---|
| 医療広告ガイドライン(医療法) | 病院・診療所・**歯科**の広告 | 体験談、術前術後(ビフォーアフター)写真、比較優良、誇大、「絶対安全」 |
| 薬機法(医薬品医療機器等法) | 物=健康食品/雑貨/化粧品/器具 | 未承認品で「治る・予防・効能効果」を標榜 |
| 景品表示法 | 全商品・サービス | 優良誤認(実際より著しく優良)・「No.1」「最高」根拠なし |
| 健康増進法 | 食品 | 健康保持増進効果の虚偽・誇大 |

## 鉄則(これだけ守れば大事故は防げる)
1. **結果を断定しない**。「治る/予防できる/良くなる/改善する」→ 言わない。
2. **体験談で効果を語らせない**(医療広告では原則NG)。「これで歯並びが治りました」系は不可。
3. **ビフォーアフターを見せない**(術前術後の比較画像)。
4. **比較・優位を主張しない**。「No.1」「日本一」「他より効く」。
5. **不安を煽って誘導しない**(「放置すると危険」等の恐怖訴求)。
6. **迷ったら“事実と姿勢”だけ描く**。何をしている/何を扱っている/何を大切にしている、で止める。結果は描かない。

## NG → OK 言い換え集（口腔育成/健康で頻出）
| NG(断定・効能) | OK(事実・姿勢) |
|---|---|
| 歯並びが良くなる/治る | お口で遊ぶ時間を大切にしている |
| 虫歯を予防できる | 毎日のケアを楽しくするきっかけ |
| 鼻呼吸で病気が減る | 鼻でのすーすー呼吸を親子で意識してみる |
| よく噛むと頭が良くなる | よく噛んで食べることを楽しむ |
| この器具で改善します | こういう道具を使った遊びを紹介しているよ |
| 専門家が効果を保証 | 〇〇のプロが、こんなことを大切にしているよ |

## 投稿前チェックリスト（AI生成の最終ゲート）
- [ ] 効果・結果の断定がない
- [ ] 体験談で効果を語っていない
- [ ] ビフォーアフター画像がない
- [ ] 比較優良・最上級表現がない（No.1/最高/絶対）
- [ ] 恐怖訴求で誘導していない
- [ ] 出展者の固有の主張は、出展者の許諾範囲内
- [ ] キャラ(ススワワ)が“医療行為の主体”に見えない（あくまで案内役）
- [ ] 薬機法: 物の効能を標榜していない
- [ ] 迷う表現は削除 or 専門家確認に回した

## AI半自動生成への組み込み方
- 台本生成プロンプトに本ポリシーの「鉄則」と「言い換え集」をsystem制約として常時注入。
- 生成後に上記チェックリストを**自動レビュー(評価agent)**で1回通してから書き出す（[[project_design_strategy_os]]の評価agentパターンを流用）。
- 出展者紹介は、出展者に**事前確認(表現と固有名の許諾)**を取る運用をデフォルトに。

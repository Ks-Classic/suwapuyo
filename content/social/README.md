# SNS投稿管理

`content/social/` は、SNS投稿を公開前から公開後まで追える非配信の正本です。アプリが配信する素材は `public/` にだけ置き、ここにある review 素材をそのままアプリ配信に使いません。

## 構造

- `inbox/`: 未整理の受領素材。台帳化・権利確認前の一時置き場。
- `shared/`: 承認済みの共通ブランド素材。投稿固有の画像は置かない。
- `posts/<POST-ID>_<slug>/`: 1投稿（カルーセルを含む）ごとの正本。
  - `post.md`: 目的、本文、スライド順、確認事項、公開記録。
  - `assets/00_reference/`: 許諾・出典が確認済みの参照素材。
  - `assets/00_rejected/`: ルール違反・誤字・比率不適合等の不採用証拠。公開・再利用禁止。
  - `assets/01_review/<platform>/`: まだ公開しない候補。今回の生成画像はここに置く。
  - `assets/02_approved/`: 人の確認を通った公開用master。
  - `assets/03_published/`: 実際に投稿した最終ファイルの控え。
  - `records/`: 投稿URL、日時、本文hash、指標の観測記録。
- `archive/`: 廃止・非採用の投稿単位保管。

## 運用ルール

- Instagramを静止画の基準面とし、基本比率は **4:5（1080×1350推奨）**。X・Threads向け派生は、承認済みmasterから別途作る。
- 画像内の文字も絵の一部としてGPT Image 2で生成する。手動テキスト合成はしない。
- 画像の誤字、比率、公式キャラ不変条件、権利・出典、本文と画像の整合を確認してから `02_approved/` へ移す。
- 投稿IDは `YT-001` のように連番にし、候補版はファイル名の `v2` で非破壊に残す。

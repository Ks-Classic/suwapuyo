# ブランド原画保護ルール

## 公式やす

- 正本: `/home/ykoha/projects/suwapuyo/やすさん.jpg`
- 2026-07-13確認時のSHA-256: `8dd3b3f13e7b292c6a2bf0972ff4737bd0cae7b5a486a205f628f2421b37a4dd`
- 寸法: `842×842`
- 色形式: RGB JPEG

## Hard invariants

- 原画をGPT Image、画像編集AI、動画生成AIの入力にしない。
- 再描画、似せた生成、表情変更、ポーズ変更、衣装変更、`Ai`文字変更をしない。
- crop、背景除去、透過化、outpaint、inpaint、色補正、反転、回転、縦横比変更をしない。
- 最終画像へ使う場合、原画ファイルのdecode結果を1:1で整数座標へ貼り、貼付領域の全pixel一致を検査する。
- 白背景を含む原画全体が入らない構図は不合格。透過素材が必要なら作者承認済みの別正本を受領する。
- 原画hashが変わった場合、自動更新せず作業を止める。新しい正本か意図しない変更かを木幡さんと確認する。

## 公開状態

- `01_review`: 未承認。投稿禁止。
- `02_approved`: 内容・権利・文字・寸法を人が確認済み。
- `03_published`: 実際に投稿したファイルの控え。投稿URLと日時を記録する。

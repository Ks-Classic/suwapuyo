# waawaa-short — ふわふわランド ショート動画ジェネレータ

すーすーわーわーのキャラが喋るInstagram縦ショート(1080×1920)を、台本から**mp4で**生成する。
Claude Code は skill として、Codex/他エージェントは本MDを読んで同じPythonを実行すれば同じ結果になる（自己完結）。

## 生成器
- 正本: `docs/10_fuwafuwa-land/content/make_30s.py`
- 実行: `python3 docs/10_fuwafuwa-land/content/make_30s.py` → `docs/10_fuwafuwa-land/content/waawaa_30s.mp4`
- 依存: Python(`Pillow`,`numpy`) / `ffmpeg` / フォント `Noto Sans CJK JP`(`/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`)
- 素材: 背景 `public/assets/ui/village_bg.png` / キャラ `public/assets/characters/02_わーわー.png`

## 新しい動画の作り方
`make_30s.py` 冒頭の **設定だけ**編集して再実行する:
- `TITLE` … 上部タイトル
- `CUES` … 字幕タイムライン `[(開始秒, 終了秒, "字幕"), ...]`
- `WEATHER_T` … 天気ギャグ(キャンディ雨)の開始秒
- `DUR` … 尺
出力名を変えるなら `OUT_MP4`。

## ルール（必ず守る＝この見た目を再現する条件）

### R1. 毎回の固定フォーマット（型）
**おはよう → 天気 → テーマ → 歯磨き → ばいばい**。
- 冒頭: 「みなさん、おはようございます！」→「きょうの おてんきは……」→「……あめ、です！」(天気は晴れ/くもり/かみなり/ゆき 何でも可)
- 締め: 「ちゃんと まいにち、はみがきは しようね！」→「ばいばーい！」

### R2. レイアウト（Instagram縦・一覧クロップ対応）
- キャンバス **1080×1920**。
- **重要要素(タイトル・キャラ・字幕)は中央帯 y≈480〜1500 に置く**。上下はInstagramのUI/サムネで切れるので背景のみ。
- 一覧サムネ＝**中央1:1(y420〜1500)に「タイトル＋キャラ」が収まること**。確認は full フレームを `crop((0,420,1080,1500))` して目視。
- 既定値: タイトル `y=470` / タグ `y=583` / キャラ上端 `base_y=660`(中心≈y940=ほぼ画面中央) / 字幕中心 `y=1330`。

### R3. 字幕の改行（語の途中で切らない）
- **スペースと句読点(`　 、。！？・…`)でだけ改行**する(`wrap_jp`)。
- だから**台本は句の区切りに半角/全角スペースを入れる**（例「ずーっと がんばってる人も、おおいらしいよ？」）。
- 1行は `画面幅-150px` 以内。22文字超は小フォントに自動切替。

### R4. 音声（`shorts/render.py` / `oguchi-de-asobo.mp4` と同一）
- **アニマリーズ**: チャープ付きブリップ(`0.7×基音 + 0.3×2倍音`, chirp1.18)を字幕の頭で高速ピロピロ。
- **キャラのpitch(基準周波数)**: **わーわー=920 / もぐぴよ=680**（`shorts/script.json`準拠。すーすー等は新規に決める）。
- **BGM**: I–V–vi–IV パッド + 1オクターブ上のキラキラarp(`pad*0.15 + arp*0.11`)。
- `random.seed(7)` で毎回同じ音（量産で再現性）。

### R5. 天気ギャグ・キャンディ
- 「あめ です！」で**キャンディ雨**＋キャラが**ぴょんぴょん大喜び**。
- 飴は**丸だけにしない＝袋に包まれた飴**（本体＋両端フリル＋つや＋ハイライト）。

### R6. トーン
- 子ども向けにやさしく。**断定で大人を責めない**（「やってるんだよ？」→「がんばってる人も、おおいらしいよ？」と伝聞に）。「大人たちって」等のトゲ表現は家族・本体向けでは避ける。
- エッジ版(強い言い回し)は別カット＝木幡の"AI裏アカ"向け。本体(YourTIME/家族)は和らげる。
